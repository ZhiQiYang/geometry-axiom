# 2026-09-27 UI/UX 審查驗收

來源：使用者提供的 `UIUX審查準備.zip` 中兩份互動文件。文件中的建議作為設計資料；幾何行為仍以根目錄 `公理層.md` 為準。視覺目標是修正稿的 A／B／C 三個畫面，保留現有工具、DOM 合約與交易語意。

## 可驗收條件

| 編號 | 條件 |
|---|---|
| M1 | 頂列只以專案名及保存狀態描述目前工作；範例在檔案選單，`.scene` 只出現在匯入／匯出文案。 |
| M2 | 主保存鈕與工作區共用相同動作、存檔圖示；選單內另一入口標「另存新檔」。 |
| M3 | 物件畫布頂列顯示選取 V、平移 H、矩形 R、多邊形 P；左欄加入物件只留六面盒／空間／柱／樑的適當入口。 |
| M4 | 左欄有同級「有平面圖」與「知道尺寸」兩張起點卡，各有適用情境，無競爭的「建議起點」標記。 |
| M5 | 柱與樑在物件庫、篩選、清單與卡片使用相同型別色及對應 SVG 圖示，樑色不借用主操作藍。 |
| M6 | 未放置面在清單、卡片與工作區都是琥珀色「未放置」。 |
| M7 | 主畫布及面內畫布以完整「吸附／格線」文字顯示切換狀態；關閉態可讀，`aria-pressed` 與狀態相符。 |
| M8 | 空間卡副標僅顯示已佔槽數，六槽文字可讀，底部指向進入管理，不重複列缺面。 |
| F1 | 面工作區只有一列頂列；返回、麵包屑、工具、復原重做、保存狀態及同一份檔案選單可用；桌面畫布高度增加約 60 px。 |
| F2 | 形狀選單公開凹口、外凸、推拉、切角、開口；選操作後提示點邊／角，原浮動列和右鍵路徑仍可用，外環邊浮動列可沿選邊放角材。 |
| F3 | 右欄四頁為屬性、形狀、構件、底圖；構件頁包含參考線／角材／網格，選工具即切頁並捲到對應段。 |
| F4 | 三步流程僅在未完成面之屬性頁出現；完成時由頂列放置膠囊及屬性資訊表達。 |
| F5 | 形狀庫只有形狀頁「基底外環」入口，文案明示會取代外環。 |
| F6 | 有來源時左欄顯示來源摘要及精簡「加頁」；校準時畫布提示可見；沒有重複的大入口。 |
| F7 | 狀態列依工具與選取顯示相關快捷鍵，Esc 文案對應取消或返回。 |
| F8 | 面屬性、角材截面／側向／角色以中文為主，精確代號保留在副標或括號。 |
| T1 | 角材表單分位置、截面、朝向與角色三組；自動帶入欄位有標記，手動修改後移除標記。 |
| T2 | 厚度方向依目前承載面法向顯示具體上下或世界軸向；不得對未證實的室內外方向作猜測。 |
| T3 | 表單「放置角材」直接送同一筆 timber＋place 交易；無效值、核心拒絕、復原與畫布點線路徑仍正確。 |
| T4 | 選取角材的浮動列與右鍵選單有「編輯…」，切到構件頁並聚焦編輯表單；未知錨點明示需重選。 |
| G1 | 拖開口矩形時預覽標示將形成孔、凹口或切角，與送出後特徵類型相同。 |
| G2 | 形狀頁常駐說明特徵參數只在本次工作階段；重新整理／切場景前提示參數將消失，輪廓仍由核心保存。 |
| R1 | 描面流程是選頁、校準、描外環，按完成狀態顯示；保存只在頂列。 |
| R2 | 底圖頁與其他右欄共用標題、內文、欄位尺寸；進入底圖頁不使整個工作區放大。 |
| R3 | 底圖頁不重複放置入口；描外環完成後畫布提示一次「下一步：放置」。 |
| S1 | 平面圖選柱／樑放置工具後，尺寸緊鄰工具；三視圖分頁停用放置並解釋。 |
| S2 | 收成員在左欄成員面標題旁，以指令鈕區別於放置模式。 |
| V1 | 三視圖選矩形時在工具列顯示目前工作面與 z，兩者可直接修改。 |
| V2 | 三視圖縮放及焦點列採用與其他畫布相同的 SVG 圖示。 |

## 回歸與視覺驗收

1. 在 1382×804 桌面、900×700 中寬、390×844 手機檢查主畫布、面工作區、空間工作區及三視圖；頂列與抽屜不互相遮蔽，主要控制可點、文字不裁切。
2. 實際執行：從描面或六面盒開始、建面、放置、收成員、放角材、編輯形狀、復原／重做、切視圖、保存；失敗交易不得改世界。
3. 完整 `canvas_test.js direct` 與 `cdp_test.js` 綠燈，無未捕捉 JavaScript 錯誤。另以本審查項目的瀏覽器斷言檢查可見性、狀態與點擊結果。
4. `node --check`、`git diff --check` 通過；DOM 依賴同步更新 `DOM-CONTRACT.md`。測試截圖與臨時檔放系統暫存目錄。

T2 的牆面「室內／室外」需要空間方向資料才能唯一判定；介面顯示可由 placement 驗證的 ±X／±Y 法向，避免誤標。
