# GEO-209／GEO-212：畫布框選與多選

狀態：第一版與 GEO-212 方向框選已完成（2026-09-28）。

## 操作與範圍

- 物件畫布：在「選取 V」工具下，從空白處拖出選取框，依方向選取目前可見卡片。面、空間、柱、樑仍按原本類型與合法 ID 識別，不改各類型的編號規則。
- 面內編輯：在「選取 V」下從空白處拖框，依相同方向規則選取角材，包含合法的角材 ID 0。角材仍使用既有放置結果，不由選取框建立或裁切幾何。
- **向右拖：完整框住才選取（藍色實線）。向左拖：相交即選取（綠色虛線），碰到邊或角也算。** 判定比較目前終點與起點的水平位置，往上或往下都適用；水平位移為零時使用完整包含。拖過起點即時切換規則，放開時套用當時規則。
- 卡片以畫面上可見卡片範圍判定，角材以面內投影範圍判定。拖曳中的提示同步顯示目前規則；取消或完成後恢復兩種方向的操作說明。
- Shift＋點選物件加入或取消該物件；Shift＋框選保留先前選取並加入框內物件。一般點選維持單選。
- Ctrl／Cmd＋A 全選目前畫布可見的卡片，或目前面的角材；輸入欄位與對話框保留原本的全選文字操作。
- 空白鍵＋拖曳、中鍵或平移 H 工具仍可移動畫布。Esc、指標取消、視窗失焦或框選途中縮放／置中會取消正在畫的選取框，保留開始拖曳前的選取。
- 選取結果有高亮與已選數量；多選時不會把單物件編輯或刪除偷偷套用到其中一個。
- 第一版多選後可核對選取清單，再單選其中一個進行原有操作；卡片及角材的整組移動、批次修改與批次刪除尚未提供。拖曳已多選的卡片會顯示提示並保留位置。
- 切面及復原會清除多選；新建面返回畫布的單張卡片，以及復原後仍存在的單支角材，保留原本的單選操作。換專案一律清選，避免同編號的不同物件承接舊選取。
- 此次提供物件卡片及面內角材多選。邊、頂點等既有形狀編輯沿用單選；三視圖和 3D 預覽沿用原來的操作。

## 邊界與依據

這是檢視與選取功能，選取本身不修改場景、角材尺寸、引用、專案未保存狀態或復原歷史。R1 的單點拾取次序保持不變；不修改 `公理層.md`、核心或 `.gcanvas` 格式。不新增批次幾何編輯或批次刪除語意。

## 驗收

| 編號 | 通過條件 |
|---|---|
| S01 | 物件畫布向右只選完整包含、向左可選部分相交；兩種方向各涵蓋向上與向下。相交包含邊／角接觸及物件包住選框，分離則排除。 |
| S02 | 面內角材依 S01 相同規則選取，支數與高亮一致；框內沒有角材時得到空選取。 |
| S03 | Shift 點選可增減，Shift 框選只加入且不重複；一般點選可回到單選。Ctrl／Cmd＋A 可全選，表單文字及對話框不被攔截。 |
| S04 | 平移及縮放後，選取仍依畫面上真正的物件位置判定；空白鍵／中鍵／H 平移不觸發框選。 |
| S05 | 拖曳途中 Esc、pointercancel、blur 或縮放／置中取消選取框，保留原選取，無殘留框或拖曳狀態。 |
| S06 | 多選結果不顯示誤導性的單物件編輯／刪除操作；Delete 不會只刪其中一個物件。 |
| S07 | 物件清單、畫布高亮及數量一致；隱藏或被搜尋過濾的卡片不納入，合法的角材 ID 0 可選取。 |
| S08 | 選取不改核心 dump、專案未保存狀態及復原歷史；切面、換專案、刪除或復原不留下失效選取。 |
| S09 | 原來單選、雙擊、邊／角編輯、角材放置、圖面繪製與平移流程維持可用。 |
| S10 | 畫面有框選規則及快捷鍵提示；藍實線／綠虛線、文字隨拖曳方向即時切換。桌機及 390px 版面無水平溢出；至少有一個可直接試選的現成角材場景。 |

真實 `finishCanvasMarquee` 的 **32 個純函式案例**通過；以修改前的程式作負對照，向左相交案例確實失敗。這只證明範圍判定，瀏覽器事件與座標由上述專項另驗。

第一輪發現角材單選後浮動操作列擋住下一次拖曳的測試起點，使選取沿用前值。測試改用未被遮擋的空白起點，且精確外緣案例必須先證明實際畫出選框；一像素分離條件保持。沒有藉放寬判定把失敗改成通過。

獨立複核再將四象限案例也接到相同的實際選框前置檢查，避免相鄰案例期望相同時沿用前值。第一次完整執行為 **1061 通過、2 失敗、0 略過**：93 項框選（含加嚴後四象限）全部通過；兩項失敗出在原 P38 自動回報晚於六秒測試期限，晚到紀錄又污染下一負例的基準。測試改為等待完整回報，並把規則拒絕負例移到故意注入例外之前、觀察 30 秒，避開自動回報 20 秒節流可能造成的假通過。產品回報行為未修改，修正後完整執行另列結果。
