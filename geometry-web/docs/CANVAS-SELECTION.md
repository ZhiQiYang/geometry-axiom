# GEO-209：畫布框選與多選

狀態：已完成（2026-09-28；2026-09-27 開工）。

## 操作與範圍

- 物件畫布：在「選取 V」工具下，從空白處拖出選取框，選取完整落在框內的可見卡片。面、空間、柱、樑仍按原本類型與合法 ID 識別，不改各類型的編號規則。
- 面內編輯：在「選取 V」下從空白處拖框，選取完整落在框內的角材，包含合法的角材 ID 0。角材仍使用既有放置結果，不由選取框建立或裁切幾何。
- 向左上或右下拖曳使用相同的完整包含規則。只有碰到邊緣、未完整框住的物件不選取。
- Shift＋點選物件加入或取消該物件；Shift＋框選保留先前選取並加入框內物件。一般點選維持單選。
- Ctrl／Cmd＋A 全選目前畫布可見的卡片，或目前面的角材；輸入欄位與對話框保留原本的全選文字操作。
- 空白鍵＋拖曳、中鍵或平移 H 工具仍可移動畫布。Esc、指標取消或視窗失焦會取消正在畫的選取框，恢復開始拖曳前的選取。
- 選取結果有高亮與已選數量；多選時不會把單物件編輯或刪除偷偷套用到其中一個。
- 第一版多選後可核對選取清單，再單選其中一個進行原有操作；卡片及角材的整組移動、批次修改與批次刪除尚未提供。拖曳已多選的卡片會顯示提示並保留位置。
- 切面及復原會清除多選；新建面返回畫布的單張卡片，以及復原後仍存在的單支角材，保留原本的單選操作。換專案一律清選，避免同編號的不同物件承接舊選取。
- 此次提供物件卡片及面內角材多選。邊、頂點等既有形狀編輯沿用單選；三視圖和 3D 預覽沿用原來的操作。

## 邊界與依據

這是檢視與選取功能，選取本身不修改場景、角材尺寸、引用、專案未保存狀態或復原歷史。R1 的單點拾取次序保持不變；不修改 `公理層.md`、核心或 `.gcanvas` 格式。不新增批次幾何編輯或批次刪除語意。

## 驗收

| 編號 | 通過條件 |
|---|---|
| S01 | 物件畫布正向及反向拖框，可選取兩個以上完整卡片；僅部分相交的卡片排除。 |
| S02 | 面內可選取兩支以上角材，支數與高亮一致；框內沒有角材時得到空選取。 |
