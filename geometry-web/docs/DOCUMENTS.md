# 文件與案例閱讀指南

## 一個入口，不混淆文件身分

從「檔案 → 文件」進入文件庫。這個入口整合原來的公理閱讀器入口，沒有新增常駐工具列按鈕。正式公理卡片仍然開啟原本唯一的 `/axioms` 正典閱讀器，保留既有批註、追溯與完整性驗證。

產品願景及完成面依賴文件都是明確標示的探索草案，不是已採納公理、功能完成聲明或安全認證。文件庫不改寫 `公理層.md`，也不生成第二份公理閱讀器。

## 閱讀文件

可依分類或標題、說明搜尋文件。章節目錄會定位到標題；手機按「章節」展開目錄。「尋找」或 Ctrl／Command + F 可在文件內尋找，Enter 到下一項、Shift + Enter 到上一項；搜尋結果最多標示 2,000 項。

「閱讀設定」可調整字級、行距、行寬、明亮／紙色／深色主題。設定只影響文件閱讀器。內建文件可保存一個位置書籤，也會記住閱讀進度。「重設閱讀紀錄」清除本功能的偏好、內建文件進度與書籤。

Esc 關閉尋找列，再按 Esc 返回畫布；也可使用右上「返回畫布」。閱讀操作不修改場景、幾何、公理或復原紀錄。

## 開啟自己的文件

支援 UTF-8 的 `.md`、`.markdown`、`.txt`，以及 `.pdf`。文字檔上限 2 MB；PDF 上限 24 MB、500 頁。空檔、編碼不符、超過上限或損壞檔會顯示錯誤。密碼 PDF 請先用可信任的 PDF 工具解除保護。

Markdown 支援標題、段落、清單、引用、程式碼、基本表格及基本行內強調。HTML 只顯示文字；外部圖片不會載入。明確點選的 HTTP／HTTPS 連結會另開分頁。未支援的 Markdown 語法可能顯示原文，並非完整排版軟體。

PDF 使用專案既有 PDF.js，在瀏覽器內繪製目前頁面，可換頁及縮放。頁面文字依 PDF 擷取順序另列，尋找只涵蓋目前頁面；掃描影像沒有 OCR。PDF 的內嵌腳本、表單動作及附件不會執行。

本機檔案只在目前瀏覽器工作階段讀取，不上傳、不發送至模型、不加入 `.gcanvas` 專案，也不保存完整文件內容。關閉頁面後需重新選檔。偏好與內建文件位置保存在此瀏覽器的 localStorage；外部文件名稱與內容不在其中。

## 案例對照與建模筆記

「瀏覽案例資料夾」讀取本機資料夾內的 `case_index.json` 與其相對路徑資產。請選完整解壓縮後的資料夾；只有索引而缺少圖檔時會顯示缺檔，不會自動到來源網站下載。

案例依命名工程分組，保留平面、剖面、照片、來源、授權、尺寸證據、梁幾何評級與缺失資訊。可選同一案例的兩張資料對照及缩放；高像素原圖預設使用較小的檢視衍生圖。圖面對得上不代表已量測或具有安全認證，仍應逐項核查來源與限制。

筆記只留在本次工作階段，需使用匯出功能另存。案例素材與筆記不會公開發布至專案儲存庫。不支援的 TIFF、CAD 等原始格式只標示檔案資訊，不冒稱已正確解析；可用提供的 JPEG 衍生圖閱讀。

## 實作範圍與審查依據

使用者在 2026-10-02 明確要求於現有應用加入多文件介面、豐富閱讀器及本機開檔，並在案例素材整理後適配平面／剖面／照片的閱讀情境。本次是使用者明示授權的通用文件功能，不修改或另存正典公理閱讀器。

UI 減項：原「公理閱讀器」檔案選單入口合併為「文件」，正典卡片在文件庫內保留。所有額外閱讀操作只在閱讀工作區出現。

依本次發布的安全限制，不重新上傳可能含私人歷史的整份 BACKLOG；此聚焦文件與 PR 描述記錄範圍、原因及驗收結果，供獨立審查。

測試包括安全文字渲染、本機檔案與 manifest 驗證、搜尋／章節、閱讀設定範圍、關閉後場景不變，以及桌機／390px 手機版面。最終實際通過的測試與限制以 PR 的逐次驗證結果為準。
