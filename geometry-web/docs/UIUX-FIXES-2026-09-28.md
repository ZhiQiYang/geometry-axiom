## 驗證邊界

沿用 `cdp_test.js`，P73 由 `uiux_review_test.js` 執行，可用 `GEOMETRY_UIUX_FIX_ONLY=1` 單跑，也納入完整回歸。使用本輪獨立服務、TEMP 回報與截圖資料夾，不能對使用者服務執行 reset。相關保存／歷史單元測試與原工程、網格、組合畫布回歸保留。

`grid_workspace_draft_test.js` 延遲真正原生邊界查詢的回應送達，不偽造資料；在等待期間由實際輸入事件修改 cell，並核對退出／切換邊界時，頂點與擴大量草稿的取消／確認及原生世界逐字不變。P73 亦檢查實際計算樣式與祖先透明度，避免只從 CSS 前段規則推斷對比；篩選、吸附與格點關閉後仍可重新開啟。

本輪額外修正面畫布攔截縮放控制的 pointer capture；按鈕與格距等原生控制不進入畫布拖曳處理。`canvas_test.js` 的超長輸入案例也按現有橋接器命令容量重新取值，保留拒絕後世界不變與通道可繼續使用的驗收，沒有修改容量或核心。
