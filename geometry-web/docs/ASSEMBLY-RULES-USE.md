# 組構規則使用（authoring/1）

這是正式無限畫布的規則編輯與角材組合，不是構件生成器。#25 才處理由規則產生施工角材。

## 啟動

```sh
npm run build
npm run dev
```

預設連接埠是 `4173`。開啟後：建立物件 → 組構規則。

## 操作

1. 空白規則可新增角色、構件位置與局部接合。同角色可有多個位置。
2. 交接示意只表示誰連續、誰終止、端面止於哪個局部側面；示意座標不寫回定義。
3. 草稿可隨專案保存。發布走預覽再確認，不直接改已發布版本。
4. 由規則卡片建立組合。各角色獨立選角材版本、參數尺寸或明確毫米，並明選接觸面與截面方向。未選可保存，失效引用會被核心拒絕。
5. 本版不提供「已生成天花板／角材」的成功結果。

保存仍用既有專案保存鈕。含草稿或已發布規則的專案使用 `geometry-canvas/7` 與 `assembly-rule-authoring/1`。
