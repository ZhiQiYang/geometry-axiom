# 組構規則操作

Refs #19 #23. 能力 `assembly-rule-authoring/1` 只做規則編輯、驗證與角材來源綁定，不生成施工角材（#25）。

1. 正式畫布「建立物件 → 組構規則」。
2. 空白規則可新增角色、構件位置與局部接合。示意寫明只表示誰抵住誰，尺寸見材料配置。
3. 建立槽位後新增構件。同一槽位可有多個不同構件，接合只設定指定的局部交接。
4. 新增端抵側或正交分段接合。終止端顯示為起點或終點，目標側面顯示為右側、左側、上側、下側（資料仍是 +u、-u、+v、-v）。示意圖的側面也可點選或用鍵盤選擇。旋轉與縮放只改檢視。
5. 草稿才出現「預覽變更」。預覽通過後，底部只留「確認套用」與「取消預覽」，並直接寫出哪個槽位的截面或哪一版規則有變。完整 JSON 留在摺疊區。沒有待確認的變更時，不顯示這三個鈕。發布版本固定，後續編輯建立新版本，複製建立新規則。
6. 選取畫布上的發布規則，從檢查器按「建立材料配置」，或在發布版本的工作區選同一操作。引用固定為當時顯示的版本；若來源已變更或服務缺少核對能力，先拒絕並保留原工作區，再明確重選來源。各槽位分別指定 A/B 尺寸來源、接觸面與擺向。已發布的配置用槽位名稱顯示截面，並寫出已選的接觸面與擺向。未選完可保存；已選卻不存在或型別錯誤的來源會拒絕。
7. 改用另一版本時，先明確對應新版槽位，再預覽確認。取消預覽保留原正式配置。
8. 草稿留在本專案，可從同一入口的草稿清單繼續。使用視窗頂部共用「保存」寫入 `.gcanvas`，包含未完成草稿、全部版本與卡片位置。
9. 返回畫布後，規則與配置可搜尋、選取、拖曳。規則檢查器直接建立材料配置；雙擊規則卡片仍可完整編輯發布版本。配置可從檢查器再次開啟；復原與重做沿用畫布功能。

新增與複製會避開已發布和草稿預留的身分；規則版本達上限時，改用「複製成新規則」。材料配置草稿會保存新增或編輯的意圖。若預覽指出身分被占用或原配置已變更，草稿仍在：要新增請另建配置；要修改既有配置，從已發布配置重新開啟「編輯材料配置」並核對差異。舊專案沒有記錄編輯意圖時，也不會憑相同編號覆寫既有配置。

第一階段不生成施工角材。真手機鍵盤、系統檔案選擇器與下載目的地仍需實機驗證，390px 瀏覽器驗證不能替代這些操作。

橋接指令：`assembly-read`、`assembly-preview <file>`、`assembly-confirm <token>`、`assembly-cancel <token>`。

## 可重開範例

開啟 [assembly-rules-v1.gcanvas](../examples/assembly-rules-v1.gcanvas)，再到「建立物件 → 組構規則」。
裡面有兩個固定版本：完整配置固定引用第一版，未完成配置固定引用第二版；另有使用材料與參數的來源，以及尚未發布的草稿。
服務啟動後也可從 `/examples/assembly-rules-v1.gcanvas` 下載，以既有「開啟專案」載入。
範例由 `tests/build_assembly_example.py` 透過正式 bridge 建立；`--check` 驗證可重建內容。
啟動及編譯命令見 [驗收紀錄](ASSEMBLY-RULES-VALIDATION.md)。
