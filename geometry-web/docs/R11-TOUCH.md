## 2. 游標 v2 的完整行為

游標讀同一工作區、typed target、工具與既有命中結果，表達選取、拖曳、推拉、建立、平移。
意圖色同時配圖示與中文；量測由既有工具／模型取得，不自行重算一套幾何。
狀態改變展開說明 **1200ms** 後收成方塊；拒絕與忙碌狀態的原因持續可讀。
plain 模式的游標仍在原 client 熱點，不附長說明。
snap 標記畫在真正落點，對齊推斷線連回真正來源點，不能因圖示位移改寫放置錨點。

| 物件畫布命中 | 游標標籤 |
|---|---|
| `faces` | 物件面 |
| `v3-view` | 3D 檢視 |
| `space-plan` | 空間規劃 |
| `room-preview` | 房間 |
| `reference` | 參考圖 |
| 畫布空白 | 畫布 |

卡片內部空白、邊緣與子節點仍屬同一張卡，不隨 DOM 子節點換字。
面內選取工具顯示「面」，繪圖、角材、參考線等工具顯示「面 N」。
三視圖使用最後真實命中的 typed root；選取集合、第一張面、scene index 和 TimberFaceId
都不能冒充 D3 面 id。切工作區、revision 改變或目標消失就清除舊 hover 快取。

游標只表達目前工具，不切換或新增可寫工具。文字狀態、既有表單與鍵盤路徑仍可取得相同資訊；
裝飾用 SVG 不搶焦點，不以顏色或 hover 作為唯一可操作入口。

## 3. 單指長按與原滑鼠路徑

### 3.1 辨識時序

| 事件／條件 | 畫面與動作 | 對正式資料的限制 |
|---|---|---|
| 第一指 DOWN | 記錄原 client、typed target、工具、context／history 世代與本手勢快照 | 尚未判定時不先送建立／修改命令 |
| 持續 150ms，位移未超過 8 CSS px | 顯示長按進度環 | 不建物件、不增 history |
| 持續至 500ms，目標仍有效 | 進度環完成，對同一 target 開 sheet | 只開選單，不同時觸發原單擊 |
| 位移 >8 CSS px | 取消長按與環，接回原工具拖曳 | 保留原單指拖曳語意，不在稍後補開選單 |
| 未達長按的 tap／double tap | 沿原選取／建立／雙擊語意 | 依原工具，不以長按等待偷偷改成另一動作 |
| 長按後抬起 | 清觸控焦點與本手勢暫存，選單保持可操作 | 不補發 click 或建立 |
| 第二指加入 | 先取消／還原第一指自己的暫態，再進雙指 | 第二指所在卡片或工具不能開始另一筆單指動作 |

150／500ms 和 >8px 是既定 DP-11，不是新的偏好提案；12px 是移動取消驗收例。
select 工具的 150ms tap 只選取；其他工具仍依自己的單指語意。
例如後續面內角材 adapter 必須在同條件下與滑鼠送出逐字相同命令，包含 `at-line guide 2`。
不能為避免雙指誤放置，永久禁掉合法單指放置。

第一指保留 DOWN 當時的 typed 身分，不保存一個日後重新命中即可取代的 DOM 假權威。
按住期間重繪、卡片子節點移動或 overlay 出現，不得換成別的目標。
原生 revision、專案或操作世代失效後拒絕該 pin，不用當下新選取補位。
瀏覽器補發的 contextmenu 必須與已開啟的長按去重。

### 3.2 同一動作模型與 sheet

`CanvasContextMenu.captureTouchTarget(element, x, y)` 在 DOWN 保存 typed pin；
`openTouch(pin)` 沿同一 `stamp`／`current`、項目資格、`openingGeneration`、
nav／world 守門與執行入口開啟 `#canvasCtxMenu.fcm-sheet`。
選單顯示本身不建立；真正選項執行前仍重新核對原 pin 和當次開啟世代。
「在此建立」保留原 client 錨點，執行時才使用當下 transform，不能把開單時的舊世界座標寫回。

sheet 與桌面 card 共用標題、常用動作、搜尋、精簡清單、子選單、表單和原因區。
觸控呈現採原稿 **64px 常用動作方塊、至少 44px 清單列**；不可用項目仍有
`aria-disabled="true"`，點擊顯示既有 `.fcm-footer[role="status"]` 原因，不執行動作。
sheet 開啟不自動聚焦搜尋輸入、不因長按叫出軟鍵盤；使用者點搜尋時才沿正常輸入。
desktop card 的既有搜尋焦點與鍵盤流程保持。

原稿手機 frame 是 390×620 的示意，sheet 本身左右貼齊宿主、貼底、高度由內容決定；
不把示意 frame 當成產品固定寬高，也不另外發明 480px 上限。
原稿 B sheet 上方圓角 16px、常用方塊之間 6px、36×4px 的置中短 handle。
可用高度不足時內容需可捲動，搜尋、理由與動作均可達，不能產生水平捲軸。
視覺上的 handle 本身不宣稱新增向下滑關閉手勢。

## 4. 偏移準星

準星僅用於頂點拖曳、畫圖等精準定位。先保存 DOWN 命中的物件身分，跨過拖曳門檻後，
將手指 `{clientX, clientY}` 的候選落點改為 `{clientX, clientY - 56}`，單位為 **CSS px**；
再交該工作區既有 transform。不同 zoom／DPR 都維持螢幕上 56px，不將其當成 56mm。
snap、預覽、量測與最後提交必須使用同一候選點；不能只把準星畫高、實際仍提交手指下方。

tap、長按錨點、尚未跨過拖曳門檻的接觸，以及引用型角材放置不套此偏移。
不能因準星接近另一條線，就把原 DOWN 的具型別引用換成最近線。
啟用準星只更新候選，仍由原操作決定何時預覽及確認；第二指與取消回復自己的手勢快照。
鍵盤與無法精準拖曳的使用者沿已有數值表單、重畫數字＋方向鍵等路徑取得相同定義。

本片未將準星接入面內幾何事件；其圖形已存在不能算成此項交付或實機可用。

## 5. 雙指平移與縮放

第二指加入時，順序固定為 **停止長按 → 取消本手勢單指暫態 → 取得兩指相機基準 → pan／zoom**。
相機只沿既有 `panX`／`panY`／`zoom` 更新，不發幾何命令、不新增幾何 history。
第二指落在卡片上也不啟動該卡；剩一指後不補點選／拖曳提交。
全部手指抬起才允許下一個新 DOWN 開始單指動作，這是避免同一手勢被重新解讀的實作推論。

初始兩指距離為 `d0`、中點為 `m0`，目前距離／中點為 `d`／`m`；
使用比例 `d/d0` 縮放，並將原來位於 `m0` 的模型點移到 `m`。
中點與平移都先換算成同一宿主的 client 座標，縮放夾限後用實際比例計 pan，避免到邊界時漂移。
不合法或零距離不能產生非有限 camera 數值。

| 工作區 | 已定縮放範圍與驗收 | 本片狀態 |
|---|---|---|
| 物件畫布／面內 | 0.02..8；ratio 1.5±1%；中點誤差≤1px；平移 60±1px | 只接物件畫布，真 CDP 待驗 |
| 3D | 0.05..20；先取消本手勢的原生 history 群組 | 後續 adapter |
| 舊面內 zoom<0.02 | 縮小 k<1 不得被新下界抬高而反向放大 | 後續面內 adapter 的必要例外 |

後續工作區接入必須保有下列原始工具語意，不能只安裝共用 listener 就記完成：

| 工作區／工具 | 第二指的取消範圍 | 單指仍需保留 |
|---|---|---|
| 物件畫布卡片／矩形 | 回復本手勢的 card／rect 暫態及選取快照；不提交 D12 移動 | 原選取、double tap、卡片拖曳與矩形工具 |
| 面內選取／角材／參考線 | 不先 place；還原本次 edge／guide／候選操作 | 同條件滑鼠的命令、原前提與拒絕 |
| `fe.work`／繪圖草稿 | 回復 DOWN 前快照，保留草稿原有兩點 | 原新增點／拖曳及確認流程 |
| 底圖拖曳／校準 | `ulDrag` 回第一指前；`ulCalib` 回完整快照，不用 pop 猜點 | 原圖面定位與校準 |
| RoomOutline | 呼叫其 `cancelPointer`，只還原本次 owner | 不撤銷他人已確認操作 |
| 網格標籤／證據框選 | 各 owner 公開取消自己的 pointer 操作 | 原標籤拖曳／框選 |
| 空間平面圖 | 兩指不建柱／樑、清本次草稿 | tap 一柱、拖曳一樑與原生守門 |

純觸控仍保留 pan 工具與既有說明中的「雙指」提示；後續 K4 第 40 項優先於早期原稿的不設 pan 工具文字。
保留 H／空白暫時平移、可聚焦的＋／−／100% 按鈕，以及 F 顯示全部／1 回到 100% 等既有操作。
多指手勢不成為唯一檢視入口；本契約沒有聲稱已具純鍵盤方向鍵平移。

## 6. 取消、鍵盤與可及性

`pointercancel`、失焦、工具／workspace／project／connection 世代改變時，
清除計時、pointer capture、進度環、準星與自己的暫存，讓晚到回覆失效。
只有本手勢擁有且仍屬原上下文的暫態可以回復；不將舊專案狀態寫進新專案，
不 abort 別的工作區，也不清掉已存在的整份草稿。controller 的 `cancel()`／`sync()`
供工具與導航退役使用；正式 World、dirty、配號與 history 不因取消增加變更。

物件畫布的 ContextMenu／Shift+F10 與滑鼠右鍵、長按共用同一 target／action model。
鍵盤沿 shell 的 ↑↓、Home／End、←→、Enter。Esc 關選單後返回原宿主焦點；
sheet 的回到原點、顯示全部、吸附／格點、定位、清除選取動作關單後，也同步返回宿主。
點擊外部關單保留新目標焦點；導航、開啟物件或表單沿原處理器接續焦點，不一律搶回畫布。
Esc 保留既有層次，先取消自己的表單、再關選單、再由工作區處理；不吞掉下一次工作區 Esc。
文字輸入與 IME composition 的 Enter／Escape／方向鍵仍由輸入法處理，
compositionend 後下一個獨立 Enter 才可執行一項動作。
面內／空間／三視圖的對應鍵盤入口要隨各 adapter 逐一驗證，不假定現已全部具備。

`.r11-press-ring` 為 `aria-hidden="true"` 的暫時圖形，不搶焦點，
不能成為 screen reader 唯一提示。sheet 保留 menu／menuitem 語意及拒絕理由，
不為觸控額外複製一組按鈕或候選確認。使用者可沿既有選單／表單操作，無須能長按才可使用動作。
游標、menu、ring、reticle、pointer 快照、hover、未提交候選不寫入專案；
原本屬 D12 的卡片位置仍循原保存路徑。

## 8. CDP 判準與目前證據界線

新瀏覽器測試必須由 `Input.dispatchTouchEvent` 進實際產品，而非直接呼叫 controller／adapter 代替使用者路徑。

| 判準 | 必須觀察到的結果 |
|---|---|
| 長按入口 | 150ms 環、500ms 同 target sheet；抬起不補 click；相同 contextmenu 不重開 |
| 超過門檻 | 12px 移動不開選單，原單指拖曳仍有對應效果 |
| 雙指 | 正確 ratio／中點／pan，無選取、double tap、建立或 D12 提交副作用 |
| 滑鼠等價 | 同目標、同動作的命令與正式結果相同；未 ready 不接手，busy 時保留原滑鼠允許的檢視選單，單指正式工具不繞過 DOWN／重播時的 busy；原拒絕與候選守門不放寬 |
| 取消／新鮮度 | 第二指、pointercancel、blur、轉場與失效 pin 不能誤提交；重繪保留 DOWN 身分 |
| 可操作性 | 390／1280px、44／64px、disabled 原因、不自動軟鍵盤、鍵盤路徑 |
| 撤回 | 指定撤入口／門檻／第二指取消／typed pin／current 守門，指定產品斷言紅，還原同案綠 |

時序等待必須等可觀察條件、保留原 timeout，不加入 sleep。
只把同案 baseline 0 → 指定產品斷言 1 → 還原 0 當具名撤回證明；
瀏覽器啟動、no CDP、fixture、transport、崩潰或無關失敗不算 kill。
完整 `cdp_test.js` 無 scope／shard 的零失敗序列才可產生 golden，既有段與斷言不得改寫遮掩失敗；
段歸屬、完整 coverage、架構與突變產物依原工具生成。

**2026-11-15 本輪狀態：真 CDP 測試尚未跑到產品斷言，具名 runner 與 0／1／0 待正式可執行環境。**
執行環境的 Chromium 在 AF_UNIX socket 得到 `Operation not permitted`，正式升權嘗試遭自動核准審查拒絕；
未繞過該限制。獨立 native 服務可啟動不代表瀏覽器驗收通過，Browser plugin 亦不提供本測試所需 CDP 入口。
本輪沒有有效先紅／後綠、具名 killed、完整 canvas golden 或段計數生成收據，不以 VM／靜態檢查冒充。
因此原 golden、衍生帳本與架構收據不手寫，整合驗收仍阻擋。
