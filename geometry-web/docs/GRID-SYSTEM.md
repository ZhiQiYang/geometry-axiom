# 畫布上的網格系統

本功能依 `公理層.md` D29／I37／R32 與 `geometry-core/GRID-SYSTEM-PROPOSAL.md` 實作。驗收狀態見 BACKLOG GEO-214。

## 建立與保存

在物件畫布選「網格系統」，輸入名稱、兩軸排法與可選主支方向。每軸可選未設定、指定座標、等距、面材＋縫，至少設定一軸。預覽後確認，網格會成為可選取、移動、編輯的獨立卡片。

名稱可以包含中文和空白，最多 96 個 UTF-8 bytes。等距排法由起點、間距與有限條數決定；面材排法明設板寬、縫及相對起點。尚未套用時，卡片顯示排法示意，面材模式沒有實際格線條數。移動卡片只整理工作區。

用正式「保存」下載 `.gcanvas`。未套用的系統也會保存；重開可繼續編輯名稱與排法。

## 套用與共用來源

在網格系統的編輯區選擇已存在的承載面和兩軸原點，再預覽並確認。可以將同一系統套用到多個面；各次套用保留自己的主格編號與原點。

第一版兩軸對應承載面的同名軸，不旋轉或鏡射。指定座標和等距的全部座標必須落在所選面的外接範圍，超界會拒絕；可見線段按真實輪廓扣孔。面材模式按當次範圍決定條數，起點來自系統相對起點加套用原點，不隨面邊改動偷偷重排。

修改系統會影響所有引用它的主格，以及後續子格、參考線與角材。先查看影響預覽，確認後一次更新；取消或有任何錯誤都保留原世界。復原／重做以完整交易為單位。

被使用的系統不能直接刪除。可在套用清單按「解除套用」，預覽並確認移除該面的主格；若仍有子格、參考線或角材依賴它，核心會拒絕並保留原世界。來源系統仍留在畫布，全部解除後才能刪除來源。系統來源的主格須回到系統編輯；普通面內數值編輯和工程綁定不能蓋掉來源。已有工程綁定的主格也不能直接轉成系統來源。

## 第一版界線

系統支援三種直接數值排法；系統內的材料／做法版本選取、旋轉、鏡射及巢狀組合尚未提供。既有面內網格與工程來源流程仍保留，不自動遷移。網格不會自動建立角材；結構拓撲與構件生成另行定義。

## 核心保存範例

```text
grid-system 7 name-hex 343030206d6d main-along u u series 400 400 4 v series 400 400 4
grid 1 on 1 from-system 7 origin 0 0
grid 2 on 2 from-system 7 origin 200 200
canvas-pos grid-system 7 120 80
```

名稱的編碼只供協定安全保存，介面顯示原名稱。保存的是系統引用，沒有將展開格線另存為第二份來源。
