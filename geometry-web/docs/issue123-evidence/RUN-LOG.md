可用記憶體在 266–830 MB 間波動，**所有逾時／緩慢先歸因於機器負載，不列為產品缺陷**；
其中是否有產品因素，需有人在低負載環境複測才能判斷。

   首次啟動因匯出遺漏 `geometry-guide/docs/` 檔案而失敗，補齊後成功。
2. **explore1 / stage_f2_explore2**：建立範例場景、走 File 選單確認 3D 建模入口；
   F1 的 hit-test 在此完成。
3. **stage_f**：3D 建模四視窗量測（F1/F5/F6）+ Tab 巡覽。一次完成。
4. **stage_x1**：主畫布／三視圖／面內四視窗量測（X6）+ 面內首次進入 B6 + 選取狀態。
   面內角材放置嘗試因 `tbLen` 欄位未出現而未放置（該流程依賴既有 3 支範例角材，
   不影響 B6 的 0 選／多選量測）。
5. **stage_g 第 1 次（未完成）**：建立網格來源時，「預覽並建立」後 2.5 秒內
   預覽未完成、`#igClose` 持續 disabled，腳本逾時離開 dialog。
   **歸因：等待不足＋機器負載；未確認是否有產品因素。**
   副作用：留下未提交草稿於該 profile。
6. **stage_g 第 2 次（受阻）**：同一 profile 再開工作區時，產品跳原生 confirm
   （保留草稿確認），自動化預設關閉導致工作區未開啟。**這是產品預期行為**，
   改用全新 profile 解決；服務同時重啟以清掉未完成的 pending 世界狀態
   （只停自己服務的 PID 及其子程序）。
7. **stage_g 第 3 次（成功）**：網格來源建立（預覽→確認對話框→關閉）、
   G3 四視窗量測、G4 檢查器來源文字、配置模式文字。最後一步
   「雙擊面卡進面內」逾時（卡片滾動／命中受阻，機器負載可能因素），
   面內構件頁文字改由 stage_h 取得。
8. **stage_h 第 1 次（受阻）**：範例載入後雙擊面卡未進入面內工作區
   （等待不足）。第二次加長等待＋先單擊選取再雙擊後成功，
   取得 B6 多選量測與 G4 面內構件頁文字。
9. **收尾**：關閉自己的服務（PID 3584 及其 bridge/conhost 子程序），
   確認 port 8851 無監聽、無殘留 process；既有 QA 服務（8837）仍在運行。
