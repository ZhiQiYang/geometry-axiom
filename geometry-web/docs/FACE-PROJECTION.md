# 面物件的平面投影定義

版本：2026.09.27「平面投影設定版」。同一個構形 Canvas 內的功能，沒有另一套應用程式。

## 指定自己的面

1. 選取面，從屬性中的「設定平面投影」進入；面內工作區也有相同入口。
2. 選擇要使用的放置面。它必須已放置為水平面；圖面高度直接顯示該次放置的 z 座標。
3. 用途選「空間邊界的平面投影」，選擇「俯視」或「仰視」。投影縮圖會依所選方向顯示。
4. 確認「輪廓內代表室內淨空，材料牆厚向空間外側增加」，按「套用定義」，或直接「保存定義並建立空間」。
5. 保存 `.gcanvas` 專案；再次開啟時保留定義。`.scene` 只保存核心幾何，不包含這份投影用途設定。

已定義的面會在卡片、屬性及面內工作區顯示用途與觀看方向；定義對應的放置面編號及 z 亦可查看。尚未指定的面不會因名稱為「天花」或具有 z 座標，就自動被當成室內平面投影。

## 每個欄位的意思

| 欄位 | 定義 |
|---|---|
| 空間邊界的平面投影 | 使用輪廓作為生成周邊空間邊界的依據；原面維持原位置。 |
| 俯視 | 從世界 +Z 側往 −Z 方向看。 |
| 仰視 | 從世界 −Z 側往 +Z 方向看。 |
| 輪廓內為室內淨空 | 輪廓表示空間淨範圍；材料牆向輪廓外增加，保留室內尺寸。 |
| 圖面 z | 圖面所在高度，由放置資訊讀取；牆底標高及牆高仍另外填寫。 |

「室內」指輪廓內所代表的空間範圍。觀看方向描述如何查看投影，不指定相機站在房間內的某個位置。面內的輪廓編輯畫面保持局部座標 u 向右、v 向下；投影縮圖與 3D 的俯視／仰視提供世界方向檢視。改變觀看方向不會翻轉原始輪廓、移動放置面或改變牆厚方向。

第一版支援室內淨輪廓及向外加厚。牆中心線、牆外輪廓等其他解讀尚未提供，不能用這個選項代替。

## 接著建立空間

可直接從面工作區按「建立空間」。尚未定義的水平面會在建模視窗內提供觀看方向與用途說明：選擇俯視／仰視，確認輪廓內為室內淨空、材料牆朝外，再按「確認用途與觀看方向」。不需先跳到另一個視窗；按下確認前，面仍維持原用途，預覽與建立保持停用。

已有定義時會直接顯示摘要。原本的「依此平面建立空間」及定義視窗的「保存定義並建立空間」仍可使用；建模視窗的完整投影設定入口也保留，可修改定義或編輯圖面 z。

填入牆底標高，牆高預設 3000 mm、材料牆厚預設 100 mm。若牆底從 z=0 開始，可按「牆底設為 0 mm」；不能把圖面 z 自動當成牆底或牆高。核對邊界摘要，必要時展開「調整輪廓邊、底面與頂面」；按「更新預覽」，在建立按鈕旁核對摘要與確認，再建立空間。孔洞須明確指定用途，FREE 邊初始不納入並顯示提醒。

建立的模型保留當時的投影定義及幾何輸入。日後修改來源面的定義會使尚未提交的預覽失效；已建立模型保持保存時的內容。修改已建模型牆高仍沿用保存的來源定義。較早的模型若沒有保存投影定義，會明示缺少該資訊，仍可查看及修改牆高，不替它補猜俯視或仰視。

## 修改圖面 z

在投影定義視窗按「編輯 z／放置」，會返回該放置面的表單並聚焦 z。修改後按「更新放置」。若同一面有多個放置，先在「來源放置」選對編號，返回的表單標題會顯示同一編號；其他放置不會被一起修改。若投影定義尚有未套用修改，先套用或取消，再切到放置編輯。

## 保存與驗證契約

- 這份設定是專案中的建模用途與觀看資訊；不新增或修改公理、核心幾何、D3 分類或 D21 殼朝向。水平適用性仍依 D4 frame 與 R9 判斷。
- 同一輪廓可有多個放置位置，因此依「面實例＋放置面」保存。不同放置面的觀看方向可分別設定；刪除後重用同一數字 ID 不繼承舊設定。
- 設定、修改與清除支援復原／重做。修改輪廓或移動水平面仍保留用途；刪除放置面、改綁其他面或改成非水平放置時，原定義不再適用，復原可恢復。
- 有面投影定義或模型來源投影快照的專案使用 `geometry-canvas/3`，清單增加 `faceProjections: [{bid, placement_id, projection}]`。舊 `/1`、`/2` 仍可開啟；舊程式會拒絕 `/3`，避免重新保存時悄悄丟失設定。
- `projection` 為 `{kind: "space-boundary-plan", view: "top" | "bottom", region: "interior", wallSide: "outside"}`。z 不重複儲存；模型的 `source.projection` 保存建立時的定義。
- 匯入時驗證所有列舉值、面與放置面引用及水平框架，並沿用既有模型驗證；驗證通過後才替換目前專案。

定義契約測試記錄於 `BACKLOG.md` GEO-207；同視窗確認與流程簡化的新增驗收及結果見 GEO-210（2026.09.28）。
