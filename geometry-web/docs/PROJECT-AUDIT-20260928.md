# 專案缺口檢查與補齊紀錄

本文件保留前輪功能交付紀錄。後續「測試本身是否可信」的審查、反例與最新執行結果，見 [測試可信度審查](TEST-RELIABILITY-AUDIT-20260928.md)。加嚴後單次完整畫布回歸為 **1040 項斷言通過、0 失敗、0 略過群組**。以下數量是不同層級的測試或斷言，不代表相同數量的完整使用者流程；GDI 新測試的 Windows 執行阻擋另列，沒有算成通過。

本輪從使用者「工程規格不能套用至網格」的實際流程，檢查正式畫布、原型、核心、保存、建模、規格與操作文件。未將原型畫面或未執行測試算成已完成功能。工程條文依使用者核准的 `geometry-core/ENGINEERING-SPEC-PROPOSAL.md`，並包含另行核准的 R13 拆面來源保留修訂。

## 驗收清單

| 流程 | 查出的缺口 | 修補／驗收要求 |
| --- | --- | --- |
| 工程規格 | 原型與正式画布各自獨立；網格只能填數字 | 正式「檔案 → 工程規格」與面內網格入口，核心保存固定材料／做法版本及来源 |
| 套用至面 | 缺少材料長寬、縫寬、角色截面引用 | 面套用、主網格與明確勾選的既有角材綁定；只改指定物件，保留位置引用及角色 |
| 修改工程 | 缺少整批影響預覽、覆寫與升級 | 整批候選世界驗證，任一失敗整批拒絕；單次確認／復原；舊預覽不可套用 |
| 已有套用的面 | 「只提供後續新建預設」可能重算既有引用，名稱誤導 | 只對尚無套用／來源的面提供純新建預設；已有來源明示「更新本面做法與既有引用」並保留完整預覽 |
| 預覽定位 | 錯誤列的定位按鈕未接到畫布 | 核心有明確物件編號才定位該物件；其餘明示「查看本次目標」，保留草稿且不套用候選；同輪廓多個放置要開啟正確放置 |
| 舊編輯器 | 字面量重新宣告可能抹掉来源 | 已綁定物件明示来源與生效值，導向工程來源／物件覆寫入口；核心拒絕直接覆蓋 |
| 刪除與拆面 | 附屬綁定殘留會阻擋合法刪除；拆片可能失去套用所屬面 | 同交易清除被刪物件的附屬定義；拆面保留來源及起點，整組移片時套用隨行，同套用跨兩片則明確拒絕 |
| 保存 | 正式專案沒有工程來源與草稿契約 | `.gcanvas/5` 保存完整來源、全部已發布版本及獨立未發布草稿，未知能力先拒絕 |
| 工程包 | 原型 JSON 不能當正式工程交換 | `engineering-package/1` 內容由核心核對指紋，同版本不同內容拒絕；匯入先預覽 |
| 空間建模 | 新來源格式／公理雜湊可能破壞既有模型 | 原生模型保留工程來源；已知舊模型仍可驗證，未知雜湊拒絕；保存快照與目前工程分開 |
| 參考線 | 同線段數但端點移動未在預覽清楚列出 | I8a 顯示各段前後端點；LOCAL 可編輯引用式，DATUM 導向共用基準 |
| 共用基準 | 沒有可用的未引用基準刪除入口 | 未引用可刪且可復原；被引用時說明原因並禁止刪除 |
| 角材編輯 | 原定位、選段與自訂優先序未帶入 | 從核心原定義回填，不由座標反推；小數優先序拒絕 |
| 確認操作 | 忙碌樣式使影響確認視窗也不能點 | 真滑鼠可點確認／取消，其餘交易操作維持暫停 |
| PDF／保存 | 延遲切頁、寫檔途中改資料／換專案誤標保存 | 保存使用一致快照，等待當前頁選取；舊回覆不清除新資料的未保存狀態 |
| 復原／草稿 | 純註解製造假歷史；超過前端快照窗口丟草稿 | 不新增假核心步；草稿保持獨立且可跨核心歷史窗口保存 |
| 核心命令 | 未知參數與非法 benchmark 次數未拒絕 | 明確報錯、非零退出；`--help` 不建立輸出 |
| Windows 繪圖 | 不合法色值、極小版面、失敗資源釋放 | 色值檢查、尺寸不為負、GDI 失敗路徑完整釋放 |
| SVG 匯出 | 寫入失敗仍可能回報成功 | 檢查寫入與關檔錯誤，只移除一般半成品，不刪裝置 |
| 文件與版本 | 舊工作流、過期工單與不同服務版本混淆 | 正式入口、操作說明、服務版本與啟動器對齊，測試服務與使用者服務分開 |
