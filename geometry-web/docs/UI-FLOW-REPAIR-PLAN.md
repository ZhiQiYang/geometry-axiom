# GEO-197：建立面與放材流程修正

依 2026-09-26 介面審查中使用者圈選的四項實作。沿用現有版面、公理層與核心驗證。

## 實作與驗收

1. **連線狀態**：載入中與失敗時不顯示空場景；失敗保留最後成功讀取的物件，明示畫面可能過期、暫停編輯並提供重試。HTTP 403、非 JSON 與服務中斷都要有可理解的訊息。重試只讀取世界，不重送失敗操作，也不放寬來源驗證。
2. **外環草稿**：保留 GEO-186 的先建預設矩形再重畫流程。新面標示預設輪廓，重畫時標示草稿尚未套用、尺寸與面積屬於原面；清楚說明返回會保留此面。沿用 Esc 階梯，完成後才取代原輪廓。
3. **游離面放材**：角材工具、畫布提示與右欄一致說明必須先放置面；提供可直接到放置表單的按鈕。未放置時不顯示材料預示，不送放材指令。
4. **放材角色**：表單初始值與改定位引用時採用點線入口的同一份方向／角色推導。手動選角色後保留使用者設定，並提供重新套用建議入口；深度與截面不被建議覆寫。修正自動換角色後的錯誤標示殘留。

## 驗證

- `app.js` 語法檢查與 `cdp_test.js` 全套；加入以上四項的操作回歸。
- 以隔離的測試服務與暫存回報目錄執行，不更動使用者的場景。
- 桌面與窄螢幕實際檢視新增提示和按鈕；既有 32 組角材情境需保持通過。
- 測試產生的既有截圖還原；不修改公理、核心或正典閱讀器。
