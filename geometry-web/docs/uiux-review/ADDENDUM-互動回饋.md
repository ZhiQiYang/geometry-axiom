## 修正原則(併入 S3 面內工作區規格)

1. **任何工具在任何輸入下都要有可見反應。** 不符合手勢的輸入一律 toast(錯誤色)並說明正確手勢,不得靜默 return、不得只寫 `#status`。
2. **工具切換即模式回饋**:狀態列左側顯示工具名+手勢說明(參考線「水平或垂直拖曳畫線,點一下可選方向」、開口「拖出矩形」、凹口「點在邊上」、角材「先填長度 L,再點面內」、外環「依序點頂點,回起點閉合」);游標依工具改變(crosshair / copy / cell);切換時清掉上一個工具的訊息。多步工具(外環、多邊形)才顯示畫布浮條。
3. **點擊要有意義**:參考線點一下 → 彈出「u 方向線 / v 方向線」小選單,選後以點擊座標建線;角材 L 空白 → toast 並把 `#tbLen` 標紅聚焦,或自動帶入從點擊點到邊界的距離。
4. **Esc 一次離開**:有進行中草稿時第一次 Esc 清草稿並 toast「再按 Esc 返回」,否則直接離開。
5. **測試**:cdp_test.js 對每個工具的「錯誤手勢」都要驗到 toast 出現;參考線點一下選 v 後 `dump` 出現 guide;Esc 兩次內離開工作區。
