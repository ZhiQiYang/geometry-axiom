## 採納與責任邊界

依現行 SSOT D19a/I25a/R32、`geometry-core/GRID-SUBDIVISION-NATIVE-CONTRACT.md`，只支援雙軸無 stagger REPEAT、一層 all-cells 或單 signed cell，規則新增/改名/編輯/刪除均走既有真 native candidate。REPEAT_PANEL、缺軸、legacy-finite、stagger 的既有來源仍可看，不為啟用規則改寫它們。沒有新公理、第二套求解器、額外 query API、巢狀/override 或自動構件生成。

沿既有來源→2a 定義表單→同來源規則區，保留 first-pointer DOM；新增的是情境式來源 section，不另建管理器。沿原參數軸、選格資訊與 U/V 命名共用輸入/尺寸摘要，收斂重複等分說明；手動子格、規則繼承的正式不同定義保留，後續切片才接面內共用入口。

共同來源 baseline、inspector key、影響摘要須包含 rules/highwater；rule 以 source ID + ruleKey 定位，不以名稱/列表位置。signed cell 以 decimal string/BigInt 處理。native 在候選配 key；草稿不保留正式 key 或 token。一次確認＋收起對應 raw draft 沿 ContextHistory 同一步，取消/拒絕保留 World 與 raw。

保存沿現有 `grid-draft` kind，有限 `grid-editor-draft/2` schema/capability 增一份 active raw-rule editor 設定，不擴大 active draft 數量；舊 `/1` 讀取/原樣保存仍支援。raw 欄位容納未填/不合法字串；source/rule baseline 能力不足不能自動重關聯。新格式使用未佔用 `geometry-canvas/13`，兼容既有 /10、native /11、evidence /12，不能降低 required-capability 守門。格式號是本輪共享 store owner 的工程分配，不是新公理。

原生 query 只讀目前 World，沒有 pending 候選模式。本 slice 的 preview 規則差異與摘要只讀 native preview 的 before/after 定義；不把 World query 的線當候選線。下個 display/pick slice 以已確認規則的真 query 接線。
