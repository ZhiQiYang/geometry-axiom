## 設計稿問題與處理

| 問題 | 實作決定 |
| --- | --- |
| 面外線保留、只是不顯示，與 I10 不符 | 表單列出可用範圍，拒絕越界；不靜默裁掉定義 |
| 等差來源容許負間距，部分情形容許零間距 | 所有等差來源一律要求正整數間距 |
| 面材奇數縫寬用四捨五入，末端生成條件不同 | 畫布、逐線標籤取核心唯讀推導；5 mm 縫採下界中心，不自行展開 |
| 面材負縫寬、起算點、條數上限未完整阻擋 | 每欄驗證與具體修正訊息；合法零條結果可套用 |
| 點邊尺會自動改成明寫 | 等差／面材先顯示來源轉換說明，按「轉成明寫並新增」才改草稿 |
| 刪網格可能被理解為確認後可連坐刪角材 | 明確列出引用角材；I23 禁止的刪除不能確認放行 |
| 草稿條數混進已套用網格清單 | 清單僅讀場景；草稿狀態、預覽與專案保存分開 |
| 手機固定桌機寬度、拖曳沒有取消、僅 hover 才可操作 | 滿寬設定／畫布切換；44 px 表單控制；鍵盤逐線編輯；Esc／pointercancel／失焦可取消拖曳 |
| 子網格尚無定案條文 | 保留收合的待定說明與停用按鈕；不加入模型行為 |

## 驗收條件

1. 所有入口（工具 G、空清單、既有網格列、構件分頁）顯示同一份草稿；文字、線數、角色與畫布一致。
2. 圖形方向選擇對應正確：沿 u 的主支來自 v 座標線；沿 v 的主支來自 u 座標線；主支卡在前。
3. 明寫／等差／面材可切換、回填，輸入保留；格線位置及單位明確。舊網格未設方向不自行猜測。
4. 預覽、拖曳、來源轉換及重設不改場景、不新增 undo；套用才提交一筆交易，undo 可完整恢復。
5. 已套用、草稿、檢查中、錯誤與提交中均有明確狀態；連點提交不重複寫入；過期非同步結果不能覆蓋新草稿。
6. 亂序、重複、非整數、面外座標、非正間距、超量、負縫寬、錯誤起算點與缺少主支軸來源在欄位旁說明；提交聚焦錯誤欄位，其他輸入保留。
7. 畫布標籤可拖曳並吸附格距：明寫改該座標；等差第一條改起點、其他條改間距；面材改起算。鍵盤 Enter 可開啟數值編輯。
8. 既有角材角色不被主支方向改寫。位置變更沿既有 I8a 影響預覽確認；消失的引用索引及帶引用刪除明確阻擋。
9. 網格線可沿既有角材工具命中；顯示角色預設、截面及厚度方向，明確覆寫沿用既有核心驗證。定位引用依物件／軸分組。
10. 390×844 手機無水平溢出，表單控制至少 44 px，設定與畫布切換保留草稿及捲動位置。全圖含座標標籤，回報鈕不遮套用。
11. 桌機維持原工作區架構；主／副支以色彩、線型與文字同時區分；密集格線僅疏開畫布標籤，右欄仍可逐線查閱。
