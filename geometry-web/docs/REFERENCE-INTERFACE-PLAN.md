# 參考描面介面更新

依使用者選定的第 1 個設計：三欄工作區、右欄校準、固定專案保存列。

## 範圍

- 物件畫布提供「從 PDF／圖片描面」與直接建立入口。
- 面與空間工作區保留既有工具，增加名稱、保存狀態、保存與檔案操作。
- 底圖頁優先顯示校準；對位、來源、紀錄、放置可展開。
- PDF 選頁預設適合整頁；取景與校準仍使用固定來源座標。
- 窄螢幕取點時收起檢查器，第二點完成後回到距離輸入。
- 實際模型決定放置標籤；未知高度不從示意圖補入。

## 保留條件

無限畫布、直接建面、輪廓驗證、角材與空間操作、復原重做、場景及專案格式沿用原實作。
公理、幾何核心與正典閱讀器不變。外環或校準草稿尚未套用時提示並阻止保存，避免誤認為草稿已保存。
直接寫檔完成才顯示已保存；下載只顯示已產生下載，保留離開提醒。

## 驗收

完整瀏覽器回歸、來源保存測試、服務端測試；增加整頁預覽、手機取點、保存狀態及草稿阻擋驗證。
在實際瀏覽器操作匯入、校準、描面、返回畫布，檢查桌面與窄螢幕。
視覺對照與驗證結果記錄於根目錄 design-qa.md。
