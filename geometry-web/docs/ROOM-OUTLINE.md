# 來源房間輪廓候選（Issue #54）

在既有「底圖 → 描外環」內取得本地半自動候選。向量或暗線不代表牆體語意，也不是精確量測。

## 操作

1. 匯入 PDF／圖片，選頁或取景，加入既有面／描繪用面。
2. 在底圖選兩點，輸入圖上已知距離，再套用校準。初始矩形與適合畫面的比例不算重建完成。
3. 按「描外環」或展開「房間輪廓候選與人工修正」。PDF 預設原始向量優先；圖片使用本地影像輔助。線寬與最短線門檻使用固定頁面單位／原圖 px。
4. 點房間內空白處，或拖框限縮搜尋範圍。框中央須在目標區域內；框選不建立矩形。選點落在線上、區域連到取景邊緣、輪廓分岔或超出容量時明示失敗，正式面保留。
5. 疊圖核對室內淨範圍、凹口與門洞。連通房間需分開時，明確畫水平／垂直分隔，再重取；分隔只約束搜尋，不建立牆。
6. 選邊、輸入圖上標註／人工核對的整數 mm 尺寸，再按「將核對尺寸寫入候選」。展開局部修正，在同一外環草稿的頂點序列插入正交整數點，可補邊或凹口。每次修正清除核對勾選；點列改動也清除舊邊號的入值標記，尺寸變形後只保留此次明確入值的核對邊。
7. 逐邊核對尺寸、範圍、連通關係與警告，勾選核對，再確認。候選交既有核心驗證，有依賴時沿用 I8a 確認。取消／拒絕保留原場景與可修正草稿；成功可完整復原／重做。
8. 保存 `.gcanvas`，重開後對照來源。放置、投影用途及牆底／牆高／厚度仍需明確設定，不由輪廓推測。

「人工逐點描繪」保留原外環及鍵入長度備援；完成後按「已逐邊核對室內淨輪廓與尺寸」記錄此次來源核對。H／空白鍵平移及縮放保留候選；確認或取消後可切換其他幾何工具。

公開資料：[自製五頁 PDF](fixtures/issue54-public-rooms.pdf)。第 1–3 頁為矩形、L 形、凹口，第 4 頁含原頁 90° 旋轉，第 5 頁只有掃描影像。前 3 頁校準點 `(30,30)`、`(230,30)` 使用測試距離 2000 mm；不是私人圖面或施工尺寸。

## 候選與保存契約

`room-outline-candidate/1` 僅存當次面內工作階段：來源 hash 關聯頁 id、面實例、專案代次、取得方式、來源輪廓、局部推估、原面指紋、校準／對位依據、警告、整數修整最大座標偏差及人工入值紀錄。點只保存在既有 `fe.draft`；正式幾何只有核心場景。

PDF 使用 `getViewport({scale:1})` 座標，含 CropBox 與原頁旋轉；向量經 viewport × CTM 換算。影像／顯示解析度及相機不改來源座標。底圖的整頁中心旋轉、左上對位及比例再轉為面局部 mm。正交候選才允許整數修整，最大偏差可見；斜邊與退化邊不偷偷改直角。自交與孔環關係交核心拒絕，未簡化成外接框。

取點／取得中與草稿阻擋保存。取消、離開面或重新載入放棄候選，不跨次保存，正式面保留。來源頁、校準、取景、對位或原面變更使候選失效；晚到 PDF 結果不能復活舊草稿。人工分隔也綁定同一依據。

確認後保存 `reconstructionReviews[]`：`bid,pageId,basis,geometry,method,warnings,confirmedAt`。`basis` 編碼來源 hash／頁 id／頁碼／原頁尺寸／crop／比例／x,y／旋轉／校準，`geometry` 編碼核心 ordered loops `[verts,fixity]`。這是人工核對收據，不是另一份幾何。依據或幾何不同顯示「需要重新核對」；重新校準不縮放正式面。透明度、顯示鎖定及相機不影響核對有效性。

含收據使用 `geometry-canvas/9`，保留原有模型、投影、工程、參數、組構與能力檢查；/1–/7 舊包可讀，未知版本拒絕。/8 留給進行中 PR #53，這次未採入其公理或功能。舊讀取器拒絕 /9，避免靜默丟收據。頁／面引用、數值、校準比例與完整性先驗證，才替換世界。

## 方法與限制

- PDF.js 6.3.289 `constructPath` 是 DrawOPS，使用獨立 OPLIST 資料；重用長正交描邊內緣及單一正交填色障礙。文字、細尺寸線、虛線分格與曲線排除。裁切路徑、複合填色或不支援變換明示／影像備援；非等比例描邊不猜內緣。
- 影像在本地取長且夠厚的正交暗線，以座標壓縮的連通區外環保留轉折。不補洞／補牆／平掉凹口；孤立文字或障礙不猜成柱／孔，明示只取外環。大圖分析最大邊 1800 px，降解析度時警告薄牆與小凹口可能遺漏。
- 不自動判定牆中心線／內緣／外緣。細牆與尺寸線同寬、破損掃描、斜／弧牆、複雜填色或多個可能範圍，可能失敗或取錯區域；須調門檻、分隔、修正或人工描繪。
- 沒有 OCR 尺寸入值、雲端辨識、付費 API、全屋還原或自動牆高。標註／人工入值與校準推估分開，最終尺寸由使用者核對。

實測、操作次數與畫面見 [驗收證據](ISSUE54-VALIDATION.md)。
