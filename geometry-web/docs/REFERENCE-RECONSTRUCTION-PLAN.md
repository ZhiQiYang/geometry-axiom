- 支援選頁、附近縮圖、放大、取景、多頁關聯、兩點校準（mm／cm）、來源與缺值紀錄。

- 案例關聯第 6、8、10、52、53 頁。CH265／245 與窗簾盒 CH260 作來源紀錄；RC 高度保留 `null`。

## 第一個可交付版本

## 分批順序

### A. 來源保存與重新開啟

先讓現有圖片底圖的工作能跨次延續，為 PDF 共用同一機制。

建議增加可攜的專案包，包含原有 `.scene`、來源檔案與參考資料清單；舊場景的開啟、匯出能力保留。
封裝與版本規則已於第一批定案（見 `REFERENCE-PROJECT.md`）。來源資料記錄檔案身分、頁面、關聯物件、位置／旋轉／比例、
校準兩點與實際距離、顯示設定；幾何仍取自既有場景與核心。

本批驗收：

- 已校準圖片、面與畫布擺位保存後可完整還原；未校準資料明確標示。
- 在兩份具有相同面 id 的不同場景間切換，不會串接錯誤底圖。
- 載入失敗或取消保留原場景；保存失敗不得顯示成功。
- 更換來源或重新校準會標示需重新核對的對應關係，不自動改寫已確認幾何。
- 舊 `.scene` 可照常開啟；幾何匯出仍不含來源圖片或待補紀錄。

**需明訂的規格差異**：GEO-190 的「僅本次工作階段」約定需擴充為可選的專案包保存；
不把底圖寫入 `.scene` 或 localStorage。使用者核准本計畫後，此擴充已生效。

### B. PDF 選頁、校準與描面

在既有底圖／物件工作區接入 PDF 選頁。第一版由使用者核對並描繪，沿用原有輪廓編輯與正交限制。
PDF 呈現採本地 PDF.js 6.3.289；版本與來源完整性資訊隨 vendor 檔保存。

本批驗收：

- 多頁 PDF 可選頁、預覽，確認後用作底圖；取消不改動既有幾何。
- PDF 與圖片使用相同校準與保存機制，來源頁碼及檔案身分可追溯。
- 使用者能描面、返回無限畫布，繼續編輯該面或組成空間。
- PDF 讀取失敗有明確提示，既有圖片與純手動入口照常使用。
- 使用已知尺寸的矩形與 L 形參考夾具，驗證校準、核心座標與重新開啟後的對位。
- 掃描圖的量取值與標註尺寸可分辨；不宣稱圖片像素能保證精確尺寸，也不將斜牆偷偷改成直角。

A、B 完成後，才算第一個可交付版本通過。

### C. 高度、樑柱與待補資訊

以既有物件為入口，逐項顯示已知值、來源與缺值。樑底高度、樑頂標高與樑深分開表達。
本批已可保存自由來源紀錄；下一批需定義結構化高度欄位、構件與来源關聯，不能用紀錄跳過核心驗證。

本批驗收：

- 柱截面已知、柱高未知時保留已知資訊，明示缺值，不建立猜測高度的柱體。
- 已知平面可繼續編輯；補高度後沿用原物件關聯，不要求重畫已確認的平面。
- 可推導值標示依據；衝突資料要求核對，不能靜默覆寫已確認值。
- 完整資料走現有構件建立與影響確認路徑；現有手動樑柱操作保留。

### D. 部分空間建模與核對

接入既有建模執行器。先明訂既有場景物件與 D21／D22 定義的映射、引用、版本及保存方式；
D5 舊空間與 D22 複合空間不能混用 id 或封閉判定。前端不另算一份權威幾何。

本批驗收：

- 按 D24 區分已定面、封閉空間與可求值實體，依請求顯示缺少的條件。
- 合法開放面可呈現；未知高度、牆厚或障礙物不以預設值補齊。
- 資料齊全後才提供相應體積或淨空結果；不把空間體積、淨空與材料體積混稱。
- 平面／立面／3D 選取可對應既有物件與來源，支援投影疊圖核對。

自動辨識可在上述人工核對流程成立後，作為增加候選幾何的入口；確認後仍走相同核心驗證。
