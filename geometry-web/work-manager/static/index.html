    操作方式、截圖與重啟

    畫面唯讀。dot 透過同一份 CLI 匯入證據、登記派工與回收交付；建議下一步不會自動批准、派工或合併 PR。

    在 repository 根目錄執行。JSON 輸入需符合工具的 schema；備份包含私有工作資料及 checksum，請保存在私有位置。

    python3 geometry-web/work-manager/cli.py --data-dir geometry-web/work-manager/.local import-snapshot SNAPSHOT.json
python3 geometry-web/work-manager/cli.py --data-dir geometry-web/work-manager/.local reconcile
python3 geometry-web/work-manager/cli.py --data-dir geometry-web/work-manager/.local list-ready
python3 geometry-web/work-manager/cli.py --data-dir geometry-web/work-manager/.local list-alerts
python3 geometry-web/work-manager/cli.py --data-dir geometry-web/work-manager/.local record-assignment ASSIGNMENT.json
python3 geometry-web/work-manager/cli.py --data-dir geometry-web/work-manager/.local record-result RESULT.json
python3 geometry-web/work-manager/cli.py --data-dir geometry-web/work-manager/.local export BACKUP.json
python3 geometry-web/work-manager/cli.py --data-dir geometry-web/work-manager/.local restore BACKUP.json
python3 geometry-web/work-manager/cli.py --data-dir geometry-web/work-manager/.local serve --port 8765

    截圖：使用瀏覽器擷取畫面；390px 驗證可在開發者工具設定寬度後擷取。「列印／存檔」可保留目前畫面及展開的證據。自動截圖指令見工具 README。

    服務只在雲端環境執行期間可用，重啟後需重新啟動。環境可保留的檔案以平台規則為準；以匯出備份和 checksum 驗證恢復，不宣稱全天常駐。
