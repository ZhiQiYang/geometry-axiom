# 材料規格與工程做法：本輪原型設計

日期：2026-09-27。範圍：獨立工程規格原型；不修改正式場景、核心或 `公理層.md`。

## 1. 使用者回報與修正目標

使用者在「面材規格來源」視窗看到固定的 2400 × 1200 × 6 mm，只有返回設定入口，無法設定自己的規格。這暴露出三個流程缺口：

| 問題 | 修正 |
|---|---|
| 未經確認就填入錯誤的長寬，且尺寸寫死 | 採使用者確認的工作預設，提供常用選項、具來源的型錄帶入與自訂欄位 |
| 來源只供檢視，缺少修改規格的入口 | 材料列、規格庫及來源檢視能進入編輯；修改儲存為新版本 |
| 做法只是假資料，重整丟失設定 | 材料與做法各有版本引用；本機保存及完整 JSON 匯入／匯出 |

原始回報畫面保存在 `design/audit-user-reported.png`。既有圖像的版面方向仍保留；其中的尺寸與唯讀流程由本文件及使用者指示修正。

## 2. 常用設定與資料來源

- **工作預設：915 × 1830 × 6 mm，依寬 × 長 × 厚標示。**
- **常用替代：910 × 1820 mm；厚度另提供 9 mm。** 長、寬、厚皆可自訂。
- 使用者說明：天花幾乎均使用 6 mm、牆面約 95% 使用 6 mm，少數為 9 mm；約 15% 案件使用 910 × 1820 mm。這是使用者工作經驗，用於決定操作預設與常用選項，不作市場調查結果。
- 不從上述經驗推導牆面／天花的強制尺寸、支撐間距或結構規則。
- 不預設角材截面、品牌或型號；邊界材、主支、副支用料分別選定，未選時顯示未設定。

廠商快速帶入依 2026-09-27 查核的公開資料：

| 來源 | 型號 | 長寬選項（寬 × 長，mm） | 厚度選項（mm） |
|---|---|---|---|
| [南亞](https://www.nanya-decoration.com/calcium-silicate-boards.html) | 0.8FK / 3WCBX、1.0FK / 3WBBX | 915 × 1830、1220 × 2440 | 6、8、9、10、12 |
| [日建 NIKKEN](https://www.tck.tw/product/19) | 0.8FK | 915 × 1830、1220 × 2440 | 6、9、12 |

廠商選項是表單填寫捷徑，使用者仍可修改。來源 URL、品牌及型號一併保留；使用者提供的 910 × 1820 mm 不冒用上述來源。型錄不是庫存確認或施工驗證。

## 3. 資料與更新關係

```text
使用者輸入或廠商型錄
  → 材料版本（面材長／寬／厚，或角材 A／B）
  → 工程做法版本（面材 + 邊界／主支／副支用料 + 排板預設）
  → 目標面的草稿與局部覆寫
  → 新舊差異、子格及格線檢查
  → 明確套用至所選面
```

### 材料版本

材料有穩定身分、遞增版本、名稱、尺寸及選填的來源／品牌／型號／備註。已儲存版本維持原內容；「編輯」產生新版本，「複製」產生新材料身分。版本清單可查看舊版。

面材寬、長及角材 A／B 必須是幾何支援的正整數 mm，不靜默取整。面材厚度是材料資訊，可記錄正小數；厚度不參與此原型的二維排板公式。角材長度不作材料輸入。

### 工程做法版本

每份做法明確引用面材版本，邊界材、主支、副支各自引用角材版本。縫寬、長邊對應方向與主支方向是做法的預設。未選角材的做法可用於排板預覽，必須標示用料尚未設定；介面不可暗示已建立骨架。

材料新增版本不改既有做法。使用者在做法編輯器選新材料版本並儲存後，也不立刻改現有面。面仍引用先前做法，直到明確選新版、預覽並套用。

### 套用與覆寫

面設定保存所選做法版本與局部覆寫。預覽解析引用後顯示新舊尺寸和格線，並列出會阻擋套用的子格條件。任一選中面失敗，整批不變；返回修改後必須重新預覽。改主支預設不追改既有構件角色。

## 4. 保存、匯入與分頁保護

本輪原型把材料庫、做法、面設定及面草稿保存在同一份第 2 版原型資料中。瀏覽器本機保存用於重整後繼續；完整 JSON 匯出用於備份與移轉。

- 載入及匯入檢查格式、材料與做法版本、引用、三個面及數值。不接受舊版僅含固定示例的格式，也不猜測遷移內容。
- 完整匯入替換原型資料，不是跨專案做法包合併。正式 ID／版本內容指紋衝突協定仍屬正式功能範圍。
- 已套用資料與材料引用必須有效；未填完或超範圍的數值草稿可保存供繼續修正，不妨礙合法材料版本保存。格式損壞的資料不覆寫先前有效資料。儲存不可用時顯示錯誤，讓使用者匯出當前設定。
- 若本機保存內容已被另一分頁更新，本分頁停止覆寫，提示重新載入或先匯出本分頁內容。
- 本機保存屬目前瀏覽器、目前網址；正式 `.gcanvas` 仍未接入。

## 5. 本輪驗收條件

這是原型測試清單；通過與否、截圖及測試證據由 `design-qa.md` 記錄，列在此處不代表已通過。

| 編號 | 操作 | 預期結果 |
|---|---|---|
| P01 | 首次開啟／新增面材 | 預設為 915 × 1830 × 6 mm；寬、長、厚標籤順序一致 |
| P02 | 選常用替代與自訂值 | 910 × 1820 mm、9 mm 可選；自訂有效值可儲存，不受預設清單限制 |
| P03 | 使用廠商快速帶入 | 尺寸及厚度來自對應型號選項，來源可追溯；不把 910 × 1820 mm 標成已查核型錄 |
| P04 | 輸入零、負數或幾何小數 | 錯誤對應欄位並阻止儲存；不截斷、不四捨五入；正小數厚度可保存 |
| P05 | 從來源入口編輯材料 | 能抵達可編輯表單，儲存產生新版本；原版本、原做法及面均不暗改 |
| P06 | 建立角材與工程做法 | 三個角色可選不同版本；面材引用有效；未選角材明確顯示未設定 |
| P07 | 升級面材引用 | 新做法選新版材料後，先改草稿；預覽與套用前已套用面維持舊版 |
| P08 | 多面預覽其中一面失敗 | 顯示具體阻擋與定位入口；整批套用停用，面設定不變 |
| P09 | 成功整批套用再復原／重做 | 每次處理整批目標；其他面的未提交草稿保留 |
| P10 | 重新整理 | 材料版本、做法引用、已套用設定及有效面草稿一致 |
| P11 | 匯出再匯入 | 完整原型資料可還原；格式錯誤、缺依賴或非法值不取代既有資料 |
| P12 | 另一分頁已更新 | 本分頁不靜默覆寫新資料；使用者能選擇重新載入或匯出保留當前設定 |
| P13 | 桌機與 390 px 手機編輯 | 表單可完成、錯誤可見、內容無水平溢出，動作不遮住欄位 |
| P14 | 僅改面材厚度 | 材料版本及顯示厚度更新；相同長寬、縫寬與方向推導相同二維格線 |

## 6. UI/UX 審查修正驗收（2026-09-27）

使用者批准修正全部審查問題並提交、合併。沿用畫布內套用的版面，採用可恢復編輯草稿及材料改版後接續目前工程做法的設計。

| 編號 | 操作 | 預期結果 |
|---|---|---|
| R01 | 修改材料後以 X、Escape、遮罩關閉，再開啟或重整 | 同分頁完整編輯草稿恢復，未發布版本不當作已發布；明確捨棄才清除 |
| R02 | 做法中新增材料，編輯中斷再恢復 | 原做法欄位、角色與材料草稿皆保留；返回時不丟失原做法 |
| R03 | 從目前面修改引用的面材並儲存 | 接續目前做法的新版本草稿，新面材已選入；既有做法與面維持原引用，選用後仍需預覽確認 |
| R04 | 初次套用、僅改縫寬、材料同尺寸改版本 | 初次套用明示；摘要只突出變更；版本引用改變不得因尺寸相同而漏列 |
| R05 | 桌機與手機閱讀來源、狀態、聚焦控制 | 一般小字對比至少 4.5:1、自訂焦點至少 3:1；主要文字及狀態使用共用語意色彩 |
| R06 | 鍵盤及手機操作畫布 | 可聚焦畫布，以方向鍵平移；手機保留模式切換，拖動中斷後不黏住，關閉平移可捲動頁面 |
| R07 | 載入材料列表 | 56px 縮圖使用適當尺寸的 WebP，不載入兩張共 2.58MB 原圖 |
| R08 | 選擇厚度 6、9、自訂或留空 | 快捷選項與欄位同步，可輸入有效小數；長寬及原版本不被改寫 |
| R09 | 桌機、390px 手機及中間尺寸 | 新提示、預覽及固定操作列不溢出、不遮擋，能完成材料到套用流程 |

草稿保留在目前分頁工作階段，重新整理可恢復；已儲存材料、做法、面設定仍使用原本瀏覽器本機保存及匯入／匯出。關閉整個分頁不作跨裝置備份承諾。若草稿保存失敗，必須告知並防止無提示離開。

驗證以獨立瀏覽器環境進行：先跑模型與儲存回歸，再一次檢查桌機／手機畫面及操作，若發現缺陷統一修正後做一次確認。測試包含非法欄位、巢狀返回、儲存失敗及手勢中斷等非成功路徑。實測結果記於 `design-qa.md`。

本輪驗證規格編輯與引用的操作流程，不改正式場景協定。正式材料與做法身分、參數引用、交易、序列化、完整 World 容量及引用鏈檢查、舊專案遷移，仍須依 `../../docs/ENGINEERING-SPEC-PLAN.md` 取得逐條公理核准後實作。規格封存、正式做法包合併及實體構件綁定不由本輪原型代替。
