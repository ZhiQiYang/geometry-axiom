# 工程規格：畫布內套用原型

使用者選定第 2 張設計方向。預覽網址：<http://127.0.0.1:8810/>。

## 可試用流程

1. 預設客廳縫寬覆寫為 4 mm；按「預覽套用」會看到父格不能整數三等分。
2. 返回設定，按「恢復沿用」改回 3 mm，重新預覽後可套用。覆寫為 6 mm 也可通過此示意檢查。
3. 選木作天花 A 的 v2，預覽含子格的面會被父格線數變更阻擋；沒有子格的臥室可接受新版。
4. 在「套用至」勾選多個面，預設保留其他面已套用的局部覆寫。任何一面被阻擋，整批不變。
5. 套用後使用頂部復原／重做；一次處理整批，其他面的未提交草稿保留。
6. 材料列與「檢視做法」可查看固定來源版本。圖層顯示、現有／預覽、縮放、平移、底格及座標讀值均可操作。
7. 手機以「工程規格」／「查看畫布」切換；長表單可捲動，主要動作固定在底部。

## 範圍

這是設計驗證用的 React 前端。3 個面共享相同的示意尺寸及洞口，不讀取實際工程。材料與做法是固定示例；尚無型錄編輯、正式材料引用、核心 API、完整容量驗證、持久保存、匯入或施工檢核。重新整理會重設。儲存只下載原型 JSON，不是正式 `.gcanvas`。

局部子格數學、孔洞裁切與主網格座標用於讓示意互動可信；正式行為仍以 `公理層.md` 和完整引擎為準。功能規劃見 `../../docs/ENGINEERING-SPEC-PLAN.md`。

## 開發

```text
npm install
npm run dev -- --host 127.0.0.1 --port 8810 --strictPort
npm run build
```
