## 層級定義(回報一律寫層級)

| 層級 | 意思 | 要附的證據 |
|---|---|---|
| L0 | 已記下 | 使用者原話或決策出處 |
| L1 | 規格已經使用者拍板(條文或設計) | 決策佇列條目或拍板留言，寫明版本 |
| L2 | 已有實作 PR,待審查與驗收(PR 存在不代表程式完成) | PR、head SHA、審查與驗收狀態 |
| L3 | 已進 main | merge SHA |
| L4 | **使用者在 App 裡用得到** | App 裡的操作路徑(點哪裡),經實際操作核對 |
| L5 | 使用者驗收過 | 使用者的確認 |

「完成」「做好了」只能用在 L4 以上。一項功能分成幾個切片時，每個切片各寫層級，不合併成一個含混的進度。
