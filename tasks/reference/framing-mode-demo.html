下角材模式 Demo:在既有平面圖上指定一個封閉面,套用模式

點選某間房的天花面 → 按「下角材」。板從起鋪角的兩面牆開始整片鋪,裁切只留在對面的牆;牆和柱子四周先放沿邊料;板的長邊縫下放主支;固定好的主支上以模數畫記號(間距上限 450 → 一個完整格 1830 + 2 = 1832 分 5 段,約 366),副支照記號接,間距都在上限以內。每支角材的端面都頂在角材上,不直接頂 RC。

規則來源

規格已有公理層裡已定義、demo 照做的
  • D14 RC 樑:沿 x 或 y 的長方塊,底 = 頂 − 深。PF-0 的 R41:樑伸進哪一層(面材層 / 角材層)那層就被裁切,否則從下方通過。
  • D10a 面材排法:從起算點一片接一片排,縫中心線就是格線;末端放不下整片就是裁切片。→ 起鋪牆整片、裁切在對牆。
  • I19/I20/I21 角色:與主支垂直的外牆放邊界材(主支端頭坐在它上面),與主支平行的外牆放邊界主支;副支頂在主支側面。
與規格衝突木工做法和現行條文不同,要回頭處理條文
  • 柱子四周要有沿邊料:角材端面要頂到角材才能固定,不能直接頂 RC。I19 卻寫「孔邊與柱面不在此限」,允許任何角材端面直接頂柱面,理由是「端面不提供固定」;PF-0 的建議規則(R45)也寫明孔環上的邊不產生邊料。
木工模板提案規格目前沒有,這個 demo 依木工做法補上
  • 主支上等距記號(模數):真正的規則是「副支中心距 ≤ 間距上限」(防垂上限 450)。一個完整格 = 板 1830 + 縫 2 = 1832,⌈1832 ÷ 450⌉ = 5 段、中間 4 支,模數 ≈ 366。記號從縫中心線起算、取整數 mm(366 / 367 交錯,差 1 mm 不影響,都在上限內),每支主支同一組,副支照記號接;每第 5 個記號正好落在板端縫上,不累積偏移。規格的 D19 是每格 n 等分、n 要人填,沒有「由上限推等分數」也沒有「模數延續到裁切格」。
  • 斷面設計(給定完成面 → 結構):斷面輪廓、構件剖面在輪廓內、不重疊、沿 L 直線拉伸,是規格 D35–D37 已有的。「由完成面自動長出結構」(面材貼內側、轉角與端點放縱向料、橫撐接在縱向料之間)與「橫撐沿 L 每隔一段重複」是依你的 SketchUp 圖整理的模板規則,規格沒有;D37 的拉伸件是整支連續,不會沿 L 重複。
  • 完成面降到樑下:完成面取最低限制(樑底)再往下扣板厚與角材高,讓骨架從樑下整片通過、主支不被樑切斷。規格(R41)允許樑切斷角材層,木工不允許;包樑(樑側、樑底另作完成面)這裡沒做。
  • 主支不可斷開:主支線碰到獨立柱就是排板衝突,要改起鋪角、板長方向或偏移(同開口:位置給定、不可切骨,反推起鋪)。規格允許主支端面直接頂柱面,不會擋。
  • 一鍵產生整面骨架。規格:子網格不自動產生角材;PF-0 只產生候選,要人逐支選,不補板中間的支撐。
  • 收邊太窄時往內挪:最後一道縫或最後一個記號離對牆不到 40.5,就挪到距對牆 40.5。
