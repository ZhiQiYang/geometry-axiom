## 模式 A:平釘天花下角材

**輸入**:使用者選一個水平、正交的面(天花完成面)。外圈是房間邊界,內圈是獨立柱。

**輸出**:
- 一個頂層群組「下角材 平釘 <時間>」,底下依角色分子群組:面材、沿邊料、主支、副支。
- 每支料是元件實例,帶屬性:角色、斷面、長度、產生它的規則。
- 圖層依角色分。
- 整個動作是一個 `start_operation`,可一步復原。

**規則**(摘要;以 demo 為準):
1. **排板**:從起鋪角的兩面牆整片鋪,裁切只在對牆,不置中。
   - 縫中心 c_k = k·T + P + ⌊gap/2⌋,T = P + gap。
   - 收邊太窄(c > D − 1.5·角材寬):最後一道縫往內挪到 ⌊D − 1.5·角材寬⌋。
2. **主支**:壓在板長邊縫上(915 向,間距 917),整支連續、不可斷開。
   - 主支線碰到獨立柱或柱邊料,就是排板衝突。要報錯,並列出不衝突的起鋪角與板長方向組合。
3. **記號與副支**:
   - 等分數 n = ⌈(板長 + 縫) ÷ 間距上限⌉,上限預設 450。
   - 記號從縫中心線起算:⌊base + m·(T/n)⌋,base = P + ⌊gap/2⌋ − T。
   - 副支照記號接,夾在主支或沿邊料之間分段。
   - 最後一個記號離對牆太近時往內挪。
4. **沿邊料**:外牆每條邊一支。與主支平行的是邊界主支,與主支垂直的是邊界材(I20/I21)。
   - 獨立柱四周一律放柱邊料。
   - 副支與主支的端面必須頂在角材上,不能直接頂 RC。
5. **板端縫承接**:兩側都要 ≥ 8 mm;不足時在縫下加一支副支。
6. **障礙**:模型裡其他實體(樑等)的 bounding box,若和骨架所在高度帶(完成面到完成面 + 板厚 + 角材高)相交,就報「骨架碰到樑」,並給出要把完成面降到多少。

**參數**:板寬 915、板長 1830、縫 2、起鋪角、板長方向、間距上限 450、角材 27×33、承接門檻 8、柱子四周放沿邊料(是/否)。

**規則檢查**:照 demo 的清單逐項顯示在 HtmlDialog。

## 模式 B:斷面設計(給定完成面 → 結構)

**輸入**:使用者畫一條正交折線(只有水平、垂直的邊),代表完成面的斷面,位在一個垂直平面上,選取這些邊。
- 兩端應接到既有的樓板底或牆面。
- 結構長在折線的哪一側,依 demo 的封閉規則自動判斷,另有「結構換邊」。

**輸出**:
- 面材貼內側。
- 每個轉角與兩端放縱向料:凸角 1 支,凹角 2 支。
- 每段面材後方放橫撐,接在兩端縱向料之間。
- 沿斷面法向拉伸長度 L:縱向料與面材整支連續;橫撐沿 L 每 ≤ 間距上限一支。

**參數**:面材厚 6、角材 27×33(可轉 90°)、L、橫撐間距上限 450。

**檢查**:正交、兩端接 RC、構件在輪廓內、互不重疊、橫撐間距。
