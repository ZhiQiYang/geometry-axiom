# 下角材 — SketchUp 2026 插件

第一版包含「平釘天花下角材」與「斷面設計」。核心為不依賴 SketchUp 的純 Ruby；輸入、規則、構件屬性及檢查結果一律使用 mm。只有 SketchUp 轉接層用 `.mm` 轉換 API 單位。

## 安裝

1. 下載本目錄的 [`releases/geometry-framing-0.1.0.rbz`](releases/geometry-framing-0.1.0.rbz)。
2. 在 SketchUp 2026 開啟「擴充功能管理員」，按「安裝擴充功能」，選取 RBZ。
3. 從「擴充功能 → 下角材」開啟所需模式。本版本是未簽署的開發預覽版；是否允許載入依安裝環境的擴充功能政策。

程式不連線、不安裝 gem、不修改模型內既有幾何。產生結果是新的頂層群組；每次產生可一步復原。

## 平釘天花下角材

1. 畫出或選取一個水平、正交的天花完成面；同一面的內圈視為獨立柱孔。第一版不處理斜面或斜邊。
2. 開啟「平釘天花下角材」。設定板寬／長、板縫、起鋪角、板長方向、角材尺寸、承接門檻與間距上限。
3. 「完成面標高」留空時使用所選面的世界 Z；明確填值則使用該標高。預設角材 27×33、板厚 6、板材 915×1830、板縫 2、間距上限 450、承接門檻 8。
4. 按「檢查選取」。穿柱時會列出不衝突的起鋪角及板長方向；碰樑時會顯示可降低至的完成面標高。修正後重新檢查，全部通過才能「產生角材」。

起鋪角使用所選面的局部平面座標：X 為較接近模型紅軸的正交邊方向，Y 朝圖下；未旋轉的房間對應世界 X／−Y。兩種板長方向可覆寫依房間較短向的預設。

輸出群組名稱為「下角材 平釘 <時間>」，依面材、沿邊料、主支、副支分組及分 Tag。每件構件是元件實例，保留角色、斷面、長度及產生規則。面材依輪廓及柱孔裁切；同一片裁切板可由多個矩形體組成，仍是一個元件。


樑等群組／元件以包圍盒保守檢查，未分組的獨立實體依連通面合併包圍盒。若所選完成面本身與其他原始實體連在一起，無法分辨自體與障礙時會拒絕，請先將完成面及障礙分組。

## 斷面設計

1. 在垂直平面畫一條相連、未閉合、沒有分叉的正交折線，表示完成面的斷面；選取該折線的所有邊。
2. 兩端必須接觸模型中的既有樓板／牆面。插件檢查幾何接面，不能鑑定該面是否真為 RC 材料。
3. 開啟「斷面設計」，設定面材厚、角材 u／v 尺寸、拉伸長度 L 與橫撐間距上限。「角材轉 90°」交換 u／v 尺寸；「結構換邊」反轉內側。
4. 按「檢查選取」，通過後「產生角材」。拉伸方向為 u 左側的水平法向，對話框會顯示座標說明。

第一次檢查斷面時，原生對話框會列出兩個端點的世界座標，請明確選擇起點。demo 的面材搭接依點列順序決定，插件不以建立順序或端點編號替你選方向。取消選擇不會產生構件；同一組選取沿用已選起點，換選取、模型或編輯路徑時重新選擇。 若要讓同一條折線反向，重新開啟「斷面設計」並選另一端為起點。

預設間接照明槽斷面為 `[[467,0],[467,148],[743,148],[743,351],[0,351]]`。u 朝遠離牆方向、v 向下。面材 4 塊、縱向料 6 支、每排橫撐 4 支；L=2400、間距上限 450 時有 7 排，共 **28 支橫撐**。

若兩端同接唯一樓板或同接唯一牆，使用該平面閉合。另一個未使用的座標軸只是平移基準，不冒稱存在第二個 RC 接面。無法唯一判定接面、只有一直立邊而無法定義斷面平面等輸入會明確拒絕。

## 開發與驗證

目標相容 SketchUp 2026 的 Ruby 3.2；本次命令列執行環境與原始證據記在 `test/evidence/` 及 PR。SketchUp API 參考：[HtmlDialog](https://ruby.sketchup.com/UI/HtmlDialog.html)、[Model operation](https://ruby.sketchup.com/Sketchup/Model.html#start_operation-instance_method)。

```powershell
ruby sketchup-plugin/test/run.rb --seed 20261013
ruby sketchup-plugin/test/run_mutations.rb
ruby sketchup-plugin/build_rbz.rb
```

打包腳本只封裝 `geometry_framing.rb` 與 `geometry_framing/` 內的 Ruby／HTML／CSS／JavaScript；不包含測試、規格或證據。使用 Ruby 標準庫 `zlib` 產生 ZIP 格式的 RBZ，固定檔案順序及 ZIP 時間戳，相同來源可重現相同雜湊。

`test/demo_oracle.js` 直接執行已確認 demo 的 JavaScript，產生固定 oracle；一般 minitest 直接讀取固定資料，不依賴其他分支。五房構件總數只計沿邊料／主支／副支，不含面材。突變 runner 在暫存副本實際移除三條規則，再確認指定測試失敗，不能以程式錯誤或測試無法載入冒充殺死突變。

## 規格來源與差異

鎖定 `ops/agent-board` 提交 `d2e75e567502433f3784c259f31c3a601131093d` 的 [SKP.md](https://github.com/ZhiQiYang/geometry-axiom/blob/d2e75e567502433f3784c259f31c3a601131093d/tasks/SKP.md) 及 [framing-mode-demo.html](https://github.com/ZhiQiYang/geometry-axiom/blob/d2e75e567502433f3784c259f31c3a601131093d/tasks/reference/framing-mode-demo.html)。demo 正規化 LF 後 SHA-256：`f3d13bc8c7af67a6d13179d478b3ed24f84b130c0df3d533cc5e0c85adf64565`。

- 規格摘要的斷面「4 支橫撐」是斷面種類／每排數量；3D 依 `pf3D` 排成 `ceil(L/cap)+1` 排，預設 28 支。
- demo 固定樑頂為樓板底，因此只比較樑底與骨架頂。插件處理一般模型包圍盒，依 SKP 的高度帶要求排除整體位於完成面以下的物件。
- demo 房間初始化自動降低完成面以避開低樑；插件以使用者選取面為完成面，遇碰撞回報建議標高，由使用者明確調整。
- demo 平釘板厚／角材高固定為 6／33；插件讓尺寸可調，沿用相同幾何公式。
- demo 的斷面 RC 檢查只有 `u=0` 或 `v=0`；轉接層先驗證模型的實際接面，再建立這兩個基準。

## 待使用者決定

- demo 沒有定義排板偏移參數。八種起鋪角／板長方向都穿柱時只回報無方案，不自行切斷主支、續接或移柱。
- 斷面拉伸方向目前遵照 `pf3D` 的正向；反向拉伸或雙向拉伸尚未定義。
- `pfChecks` 以 2D 斷面判斷重疊，不檢查不同橫撐排的 3D 重疊。L 小於角材較小邊時，`pf3D` 的橫撐寬仍保持角材寬，可能超出 L；本版保留 demo 行為，是否拒絕或裁短需決定。
- demo 的「每段有面材」「每個轉角與兩端有縱向料」兩項檢查恆為通過；本版保留該檢查語意，另用固定幾何及數量測試核對已確認範例。是否增加一般化的完整性判定需決定。
- 斜面、非正交房間、料長續接、吊筋與材料／結構強度判定不在第一版。

SketchUp 內驗收方式見 [`test_su/README.md`](test_su/README.md)。本次未在 SketchUp 內執行，不把命令列或瀏覽器 mock 測試當成實機驗收通過。
