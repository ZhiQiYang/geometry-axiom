# R19 閱讀 A：柱形成的短牆階與兩支壁邊材

2026-11-21 在 main `2562aee65c9f21a9ffdfd684100102d764bc2eb4` 核對。**13 mm 柱投影牆階上的雙材接法達 L4。** 兩支 27 mm 寬的壁邊材各沿固定外邊放置，端面有 14 mm 互頂，餘下 13 mm 對著裸 RC。預覽同時列出兩種接觸，確認後兩支一起落地，一次復原或重做可一起移除或恢復。[預覽畫面](10-preview.png) · [放置畫面](11-placed.png)

## 操作與觀察

1. 從獨立 App 的預設物件畫布進入「建立物件 → 知道尺寸 → 六面盒」。輸入寬 1000、深 1000、高 2500 mm，建立含地板的空間 1。預設示範面 1 保留，本次檢查空間 1 的天花面 2。[尺寸輸入](02-room-input.png) · [建立後的物件畫布](03-room-created.png)
2. 在「建立物件 → 柱」選空間 1，輸入寬 500、深 13、X 500、Y 0 mm。建成的柱 1 在平面上覆蓋 `(500,0)–(1000,13)`，由地板延伸到天花。[柱的輸入值](04-column-input.png) · [柱與空間](05-column-created.png)
3. 雙擊天花面 2，在「形狀」確認「柱 1 投影／切角凹」已勾選，按「套用 1 項投影」。天花外環由四點變為 `[(1000,1000),(0,1000),(0,0),(500,0),(500,13),(1000,13)]`。固定外邊 e2 及 e4 平行、相差 13 mm，兩者間的 e3 是柱形成的短牆階。[套用前可見柱 1 投影](07-column-projection.png) · [套用後的六點外環](08-column-cut.png)
4. 在「構件 → 角材 → 放置方式 → 兩支互頂壁邊材」依序選 e2、e4。兩支都填寬 A 27、厚 B 20 mm，選「沿輪廓圖向右（+u）」及「朝上（+n）」，按「預覽兩支互頂」。預覽期間面 2 的角材數仍為 0。[雙材表單](09-pair-input.png) · [兩支的來源、尺寸及接觸](10-preview.png)
5. 按「確認套用」，面 2 出現角材 4 與 5。按一次 Ctrl+Z，兩支一起消失。再按一次 Ctrl+Y，原 ID、截面與長度一起回復。[確認後](11-placed.png) · [復原](12-undone.png) · [重做](13-redone.png)

## 怎樣判定為閱讀 A

| 項目 | 畫面及原生預覽所列結果（mm） |
| --- | --- |
| 角材 4 | e2 上的完整固定段，長向 [0,500]，寬向 [0,27]，長 500 |
| 角材 5 | e4 上的完整固定段，長向 [500,1000]，寬向 [13,40]，長 500 |
| 中央端面 x = 500 | 角材 4 的 END 與角材 5 的 START 於 [13,27] 互頂，共 14；角材 4 在 [0,13] 接觸固定外邊 e3 |
| 兩支外端 | x = 0 的端面在 e1 有 [0,27] 固定接觸；x = 1000 的端面在 e5 有 [13,40] 固定接觸 |

依 I19 例外三及 R6(d)，成組共同驗證時，已算出幾何的另一支壁邊材可提供相向端面的實際接觸。此例留下的 13 mm RC 段短於 27 mm 料寬。預覽將木木接觸列為 14 mm，與上述區間交集相符。

本次涵蓋一個由實際 RC 柱投影產生的牆轉折。有關 #318 原圖的 39 mm 牆階、同一端面分別頂到多支角材、可貼一整支料寬的裸 RC，以及拒絕路徑，本次未驗。
