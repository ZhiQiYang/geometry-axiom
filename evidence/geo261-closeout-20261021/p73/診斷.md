## 根因與最小候選

`app.js:3519` 以 `toggleAttribute('hidden', noGeometry)` 設空態；`syncSpacePlanAnnotations():3638` 卻判 `svg.hidden`，SVG 元素沒有該 HTML property。ResizeObserver 在 `app.js:10658` 直接捕獲此函數，稍後回呼便越過原 guard，按空 viewBox 生成裝飾及零範圍 metrics。CSS 的全域 `[hidden] { display:none!important }` 確實遮住 SVG，沒有遮住其外的 metrics。

SSOT D5（`公理層.md:130–142`）規定空集合無有限範圍；DOM 契約要求空容器說明及加入入口，不渲染有尺寸房間矩形。此路徑在 main `adbaebf9` 與 R2 的相關來源區塊相同，見 `ssot-prerequisite-source-comparison.json`，目前證據支持既有產品空態生命期缺口，不是 GEO-261 新幾何錯誤。

`candidate.patch` 只做：

1. SVG 同步函數先判真正 hidden attribute 與 viewBox 存在，再取 CTM。非空幾何分支一定先設定 viewBox；不以成員數直接排除合法柱樑足跡。
2. `noGeometry` 時清空並隱藏 metrics；恢復有範圍空間時恢復 metrics。
3. 原 P73 同一題保留四個原條件，新增 metrics 空文字／hidden 條件並附子條件詳情，總數仍 69。不增加 sleep、不放寬 selector、不改 golden。

## 診斷與控制方式

`p73_probe.cjs` 是原始診斷工具，精確 hash `0984db53cb9523fcff527ab819f4a3e46323766bd1ebef393f5465929ff8cf5e`。`p73_probe-v2.cjs` 為候選正式工具，hash `f12ab05083a0b2f994b34ee78b3990c8873aa749309ea132267ecfd599f32faf`。兩支都沿用正式 CDP 啟動、隔離 profile、原始模組與原斷言。

v2 在 app.js 回應階段先核對服務來源 SHA-256，再精確替換兩個已審唯一片段，於 app 執行和 ResizeObserver 建立**之前**生效。所有收據分開列 actual/effective app hash；不宣稱服務 runtime 已包含候選。`withdraw-all` 的有效來源逐字等於原 app。此次完整 69 題仍執行磁碟原測試模組；候選新增的 metrics 斷言待正式套 patch 後再驗，外部轉換診斷已獨立驗 metrics。

真實轉換診斷建立一個有放置面的空間 989 與空間 990，走非空→空→非空，檢查格線與 metrics 消失／恢復，以及每階段等待與繪圖前後 dump 不變，共 6 個外部診斷斷言。

完整模組的 callback 控制明示在原空態設定完成後，手動呼叫產品原同步函數一次，模擬 ResizeObserver 的較晚排程。它不偽造條件值、不改 World、不改原四項斷言，也不聲稱精確重演原 fullcanvas 所有事件時間。
