# 交付預檢歷史快照

本包只保存當時 **5,646 檔／122,638,409 bytes 的預檢及補件快照**，不是最終總索引，也不是 E 驗證成功或全案結案證據。掃描途中新增的一份外層 JSON 已單獨補核；不帶 -v 的 ignore 檢查因此涉及 5,647 條當時路徑。後續檔案不在此快照保證範圍。

原報告與三份原結果逐 bytes 複製。命令與執行觀察是事後由工具對話轉錄，原執行前未另存腳本；轉錄 hash 不構成執行前凍結證明。沒有為封裝重跑掃描、產品測試或正式 E verifier。補核原件保存掃描中新加入的 JSON、歷史 README 原 bytes 及當時精確 ignore 暫存內容；後者改名為 .txt，沒有建立巢狀 Git 規則。

歷史 SHA256SUMS 外的 13 份補件不回改舊清單，由 root 最後 exact-set 索引涵蓋。本包的「原件清單.json」與 SHA256SUMS 只管理本包，不可當作 final-bundle 總 index。各來源檔保留原 bytes，副本統一為無執行權限的 0644，源碼僅 .txt。未修改其他凍結子包、repo 或 HEAD。
