# P-189 外層封裝核對與追加 peer

本附錄保存各輪封裝 copy-check、實際封裝命令／結束碼、codec 場景分類更正，以及 75f 在原子包凍結後完成的獨立 peer 與接受器純文字來源。子包的原件與 SHA256SUMS 都沒有重寫；linked-bundles.json 綁定其 manifest。

75f 候選 P-189 check 0；正式 L、codec 與 contact 前輪的失敗仍有效保存，不以候選結果改寫。75f 的 175 列包含 75 成功 load 與 100 歷史受控拒絕，不稱 175 全成功載入。36 個正反交錯樣本完整，N64 為 1.962570608125651，距 2x 門檻約 1.87147%；未作性能撤回負控制，亦未完成全量帳本／架構／七項正式驗收。

peer 是只讀事後驗收，不能冒稱重新取得執行時點狀態；頂層 session/chunk 紀錄若標示轉錄即保留該性質。外部包裝腳本的來源快照是資料，不是部署入口。本附錄本身的 copy-check 在其外部另存，避免自我雜湊循環；SHA256SUMS 涵蓋除自身外全部檔案。
