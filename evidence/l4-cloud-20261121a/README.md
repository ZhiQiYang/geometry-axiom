## R17 兩支互頂壁邊材

**夾具**：`scripts/r17-step.scene`（13 mm 牆階面，外環 `(0,0),(500,0),(500,13),(1000,13),(1000,1000),(0,1000)`，`origin 0 0 2500 u +x v +y`），與 P1-A 用的 `scripts/r17-rect.scene`（1000×1000 矩形）。兩份都只有一行 `surface`，經「檔案 → 開啟場景檔…」開啟。#419 路徑第 1 步寫「建立或開啟」，這裡走「開啟」；13 mm 牆階沒有用多邊形工具畫。

**操作路徑**（`scripts/walk_r17.js`）：

1. 檔案 → 新專案 → 檔案 → 開啟場景檔…（`r17-step.scene`）→ 點面 1 卡片 →「進入」。
2. 右欄「構件」→「角材」→「放置方式」選「兩支互頂壁邊材」。
3. 壁邊材 1：「固定外邊」選 e0；寬 A 27、厚 B 20、延伸方向「沿輪廓圖向右」、厚度朝「朝上（+Z，+n）」。壁邊材 2：按「點畫布選第 2 條邊」→ 滾輪放大 → 在畫布點 e2 的中點（面內 (750,13)）；其餘同第 1 支。
4. 「預覽兩支互頂」→ 核對「確認連動變更」對話框。
5. 「取消，保留原狀」→ 再按「預覽兩支互頂」→「確認套用」→ 面內「復原」→「重做」。
6. 工具列「選取 V」→ 點角材 1 →「編輯互頂組」→ 不改就預覽並確認 → 兩支厚 B 改 21 → 預覽 → 確認 → 再選 →「編輯互頂組」→「預覽整組刪除」→ 取消 → 再預覽整組刪除 → 確認 →「復原」。
7. 檔案 → 另存新檔… → 關掉瀏覽器 → 全新瀏覽器 → 檔案 → 開啟專案… → 進入面 1 →「選取 V」點角材 1 → 右欄「角材」子分頁。再試浮動列的「編輯…」「刪除」（都取消）。
8. 另開新專案 → 開啟 `r17-rect.scene` → 只選第 1 條邊就預覽（缺第二成員）→ 第 2 條選 e2 → 預覽（P1-A 不互頂）。

**結果：走得通**（`main-1b1c6674/r17/walk_r17.result.json`，20 項全部通過；截圖 `screens/R17-*.jpg`）。

- 第 3 步選完兩條邊後，場景、修訂號、身分帳、歷史都和開檔後相同，沒有任何角材。畫布點 e2 後，第 2 列「固定外邊」變成 e2，狀態列寫「第 2 支已選 e2；尚未提交，請核對兩列後按預覽。」
- 預覽的數值與 #419 第 4 步逐項相同：角材 1 長軸區間 [0,500]、寬向 [0,27]、世界原點 [0,0,2500]；角材 2 [500,1000]、[13,40]、[500,13,2500]；「新中央接觸：角材 1 END ↔ 角材 2 START；平面 500；實際接觸 [13,27] mm」。外端：角材 1 START 接外輪廓邊 e5、END 接 e1（[0,13]，FIXED）；角材 2 END 接 e3。兩支各 500 mm。
- 預覽與取消都是零寫入：場景、修訂號、身分帳、歷史深度與末筆、dirty 都不變；取消後狀態「已取消；場景保持原狀」。
- 確認後只多一筆歷史（修訂號 +1），場景多出 `requires boundary-pair/1`、`boundary-pair begin 1 2 … boundary-pair end` 包住的兩支 `timber`／`place`。第二次預覽的對話框文字和第一次完全相同。
- 一次「復原」同時移除兩支與組關係（場景回到開檔時）；一次「重做」同時還原。
- 選角材 1 時，右欄顯示「互頂組 1＋2」與「編輯互頂組」「整組刪除…」。編輯會載入兩支原本的邊與截面。原樣再確認：不新增歷史、場景不變。改厚 B 為 21：預覽標「同組重宣告」，確認後一筆歷史、兩支都是 `27 21`。整組刪除：預覽列出兩支都「新：不存在」；取消零寫入；確認後一筆歷史、兩支與組關係都消失；復原後回到刪除前。

## R02 PF-4A 網格對齊鋪排

**操作路徑**（`scripts/walk_pf4a.js`；第 1、2 步沿用 [11-13 R02 UI-1](../l4-cloud-20261113/README.md) 的一般入口）：

2. 工具列矩形工具在畫布拖出 400×300 的面 → 雙擊面卡片進入 → 右欄「屬性」→「面設定…」→「完成面與鋪排…」→ 勾「鋪排」→ 門檻欄「準備新的門檻欄位」→ 參數草稿預覽 → 確認 → 返回 → 填完成面（原點 0,0,0；U +X、V +Y、N +Z；結構側 +N）、鋪排（面材 100×200、長邊沿 v、原點 0,0、正排、板縫 3、門檻 1:1）→ 勾「設定派生宿主（PF-H）」→ h 明設 30 → 預覽 → 確認。
3. 再開同一表單（宿主定義已是「宿主 #1」）→ 勾「建立跟隨此鋪排的主格」→「主支偏好」選「沿 u」（預設是「請明選」）→ 預覽 → 取消。
4. 再開 → 勾主格、選沿 u → 預覽 → 確認 → 關閉表單 → 面內「復原」→「重做」。再開表單，什麼都不改按「預覽」。
5. 再開 → 鋪排原點 u 由 0 改 10 → 預覽 → 取消 → 再開 → 改 10 → 預覽 → 確認。
6. 回物件畫布看一眼 → 檔案 → 另存新檔… → 全新瀏覽器 → 開啟專案… → 進入面 → 同一表單。

- 第 3 步：表單出現「建立跟隨此鋪排的主格」，主支偏好的選項是「請明選／沿 u／沿 v／未設定」，預設「請明選」（不暗設）。預覽列出「原生列出 3 筆變更：鋪排 #1・原生派生結果變動、派生宿主 #1・原生派生結果變動、來源主格 #1・新增」，另有「主格與引用的參考線」表。預覽與取消都是零寫入（場景、`panel-fill-read` 修訂號、身分帳、歷史、dirty 都不變，正式主格 0 份）。

- 第 5 步：改鋪排原點的預覽在主格表列出主格 #1 的前後紀錄；取消零寫入。確認後一筆歷史，主格仍是 #1、定義行不變，u 軸 base 由 101 跟著變成 111（pitch 不變），鋪排原點 [10,0]。
