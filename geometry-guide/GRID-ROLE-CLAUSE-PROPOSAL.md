### D10 參考網格

```diff
 **D10 參考網格（ReferenceGrid)**：屬於某承載面 + 兩軸各一份線的定義……
+主網格另可宣告主支長度方向 `main_along = u | v`。這是格線的構件放置預設，不是已放構件，也不改格線座標、可見段或 D11 擋面。
+每條推導格線帶可追溯的預設角色與優先級：沿 `main_along` 方向的格線為 `primary / 2`，與其垂直的格線為 `secondary / 3`。`u` 座標格線沿 v 走，`v` 座標格線沿 u 走；不能用座標軸名稱直接當角材長度方向。
+未宣告 `main_along` 的舊網格仍可載入，但格線角色為「未設定」，不得從畫布方向或格線順序猜主支；使用者明確補上主支方向後才有角色預設。新建網格的圖形化流程須要求選定主支方向。
+DSL 擴充為 `grid <id> on <承載面> [main-along u|v|none] u ... [v ...]`；新網格仍須至少定義一軸。對既有 id 僅寫 `main-along` 可更新方向，省略時保留原值，`none` 明確清除；dump 只輸出已定義的方向，且重放後一致。
+格線預設只在沿該格線建立角材時帶入宣告；格線不擁有角材、不自動放置角材，也不因網格刪除而將角材改成其他角色。
```

### D15 角材角色與裁切優先級

```diff
 **D15 角材角色與裁切優先級**：每支角材宣告一個角色……
+以格線放置時，UI 可用 D10 的格線預設預填 `role primary|secondary`，但送進核心的 `timber` 宣告仍須明寫角色；使用者可明確改選角色或 custom priority，所選角色須照 I18–I22 驗證。格線預設不得覆寫已存在角材的角色，也不取代 D17 / I20 所定、沿適格外輪廓邊的 `boundary / 1` 規則；並非每條外輪廓邊都能放 `boundary`。
```

## 建議驗收

1. 一座同時有 u/v 格線的主網格，選 `main_along=u` 時，v 座標格線顯示主支 2，u 座標格線顯示副支 3；改選 v 則互換。
2. 點格線放角材時 UI 預填角色，正式指令仍明寫 `timber … role …`；手動改角色後不被錨點切換或重畫覆寫，且違反 I19–I22 時核心拒絕、World 不變。
3. 修改主支方向不改格線座標、不改既有角材角色與引用；儲存、讀回、undo/redo 保留方向。
4. 舊場景的無角色網格可讀，畫面明示「尚未設定主支方向」，不猜優先級。
5. 子網格相關驗收須待 D19 / I25 / R23 完整定案後另行新增。
