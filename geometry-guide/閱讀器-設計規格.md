## 1. 版面骨架

CSS Grid 三欄,頂欄橫跨。**主文欄是一條 63 個 `<article>` 的長捲軸**,不是單條容器。

```
.reader{height:100dvh;display:grid;
  grid-template-columns:var(--nav) minmax(600px,1fr) var(--ref);
  grid-template-rows:var(--top) minmax(0,1fr);overflow:hidden}
.reader.no-ref{grid-template-columns:var(--nav) minmax(0,1fr)}
```

三欄各自 `overflow:auto` 獨立捲動;主文欄 `min-width:0` 防止 grid 撐爆。

### 斷點階梯

審查修正 14 要求「≤1200px 起導覽即抽屜,主文維持 ≥600px」。
下表算術經 fresh-context 驗證員逐格重算(2026-09-18),初稿在例外區間上界錯了一次,已訂正:

| 寬度 | `--top` | 導覽 | 參照欄 | 主文實得 |
|---|---|---|---|---|
| ≥1700px | 72px | 250px 固定 | 34% | 剩餘 |
| 1201–1699px | 72px | 224px 固定 | 36% | 剩餘(1201 時 ≈ 545px → **見下方例外**) |
| 1000–1200px | 64px | 抽屜(預設關) | 35%(350–420px) | 650–780px ✓ |
| 650–999px | 64px | 抽屜 | 底部半高 sheet | 全寬 |
| ≤650px | 56px 單列 | 抽屜全寬 | 底部半高 sheet | 全寬 |

**例外處理**:1201–1699px 區間若「導覽 224 + 參照 36%」會讓主文低於 600px,
參照欄改為 `min(36%, 100vw - 224px - 600px)`;壓不到 320px 以下時,
改走 1000–1200px 那格的抽屜+內聯欄配置。

例外區間的**臨界點是 1287.5px**,不是 1300px:
主文 = `w − 224 − 0.36w` = `0.64w − 224`,令其 ≥600 得 `w ≥ 1287.5`。
所以 **1201–1287px 落在例外區**(1201px 時主文僅 544.6px),**1288px 起才安全**
(1300px 時已有 608px)。
**驗收要實測 1201px 與 1288px 兩個邊界**,不要相信推算——這個數字初稿就推錯過一次。

`≤999px` 的參照欄是**底部半高 sheet**(`max-height:50dvh`,`position:fixed;bottom:0`),
不是全螢幕覆蓋層 —— 目的是讓主文與引用同時可見(審查修正 14 的提案)。

JS 與 CSS 的窄螢幕判斷**只能有一個真相來源**:一律用
`matchMedia('(max-width: 999px)')`,禁止在 JS 另寫 `innerWidth < 1000`
(原型 `src/App.jsx:63,76` 與 `reader.css:25` 兩處門檻差 1px,是它的技術債,不照抄)。

## 4. 元件解剖

### 4.1 左側導覽

- 內距 `24px 12px 20px 24px`;`overflow:auto` 獨立捲動。
- 標題列:「規範導覽」15px/600 + 圖示。
- 三個分組(定義 D / 不變量 I / 推演規則 R),各為可收合 `<section>`:
  - 分組標題按鈕:caret + 組名 + **數量徽章(19 / 23 / 21)**。
    **數量常駐,不得只在 hover 出現**(審查修正 6:原型是 `.group-toggle small{opacity:0}`,
    觸控裝置永遠看不到)。`aria-expanded` 要正確。
  - **三組預設全部展開,全列 63 條**。**禁止任何硬編碼條號白名單**
    (審查修正 5:原型寫死 `['R6','R18','R19','R20','R21']`)。要做重點只能用資料裡
    真實存在的標記(如可追溯性燈號、樞紐)當篩選器。
- 條文項目:條號 + 標題(ellipsis 截斷),`min-height:42px`,左邊框 4px 顯示
  **可追溯性燈號色**;選取態(scroll-spy 判定)底色 `--accent-bg`、左邊框 `--accent`。
  - 燈號與選取態共用左邊框會打架 → 燈號改用 `border-left`,選取態用 `box-shadow:inset 3px 0 0 var(--accent)` 疊在內側。
- 底部:「公理層.md / 63 條規範」。
- 單頁模式下導覽項目是**錨點連結**(`href="#c-{id}"`),不是 JS 路由。

### 4.2 中欄(單頁長捲,63 個 `<article>`)

每個 `<article id="c-{id}">` 的固定順序 —— **63 條一律相同,不得有任何條號特例**
(審查修正 1:原型用 `activeId === 'R21'` 決定要不要出現某些區塊,其餘 62 條掉回另一套版面):

1. **eyebrow 行**:`分類 / 條號` + `公理層.md:{line}` + 可追溯性燈號徽章 + (被 ≥3 條引用時)樞紐徽章
2. **條文標題**(28px)
3. **條文原文** —— **預設展開,置於所有改寫之上**(審查修正 2)。
   - **不得放進預設收合的 `<details>`**:收合內容在多數瀏覽器 Ctrl+F 搜不到,會直接推翻拍板 2。
4. **白話解釋**:標籤「白話 · 非條文」+ 白話盒。可收合,預設展開。
5. **範例記錄**:標籤 + 數量 + 「全部展開/收合」按鈕 + `<details>` 清單。
   - **web bridge 實錄(R1/R4/R5)必須是可辨識的獨立區塊**,用 `--badge-transcript` 徽章。
     (原型把實錄併進泛用 examples 而丟失標籤,是 `sync-content.py:64-70` 的正則與
     `build_transcript()` 共用 `ex-wrap` 外殼所致,是意外不是取捨。)
6. **三向連結追溯**:原始碼函式名 / 夾具檔名 / 變異 mutant id,`<details class=trace>`。
7. **被引用**:backlinks chip 列表。

三種文本的命名**一次定案**,全站不得出現第二種叫法(審查修正 3):
**「條文原文」/「白話」/「重點」**。原型在 R21 叫「完整原文」、其他條文叫「條文原文」。

### 4.3 右側參照欄

- 標題列 sticky:「正在參照」+ **固定/取消固定**(可見文字「已固定 / 未固定」+ 圖示)+ 關閉鈕。
- 內容:條號 chip(15px)→ 標題(20px)→ 引文 → 白話子區塊 → 來源列 → **「查看 {id} 全文」為實心主按鈕** → 「返回原閱讀位置」為次要文字鈕。
  - 審查修正 8:原型把 56px 實心藍主按鈕給了返回/關閉,真正往前的入口卻是次要文字鈕,權重顛倒。
  - 返回入口**只留一個**(面板內),不要頁首再來一條。
- 單頁模式下「查看全文」= 同頁錨點捲動到該條;點擊前記下 `{id, scrollTop, 展開狀態}`,
  返回時還原捲動位置與展開狀態。
- **`pinned` 狀態不得與「目前沒有參照內容」不同步**(原型 `src/App.jsx:52,54` 的缺陷:
  窄螢幕進站時 `reference` 為 null 但 `pinned` 仍是 true,放大視窗後不會自動補開)。

### 4.4 搜尋

- 頂欄搜尋框 + `Ctrl+K` 聚焦。
- **現行的「隱藏不符合的導覽項」行為保留**;`Ctrl+K` 加上結果面板與方向鍵/Enter/Escape 導覽。
- **搜尋絕對不得對條文本體 `<article>` 套 `display:none`** —— 只過濾左側導覽。
  隱藏的內容 Ctrl+F 搜不到,會推翻拍板 2。

## 5. 互動行為

- **hover 預覽與點擊參照欄並存**(拍板 3):滑過條號 chip → 現行的浮出卡片;
  點擊 → 開右側參照欄。觸控裝置沒有 hover,點擊路徑必須自足。
- **scroll-spy**:主文捲動時更新導覽選取態(單頁模式取代原型的路由)。
- **錨點跳轉**沿用現行 `.flash` 高亮(`make_axiom_reader.py:694-698`)。
- **全部展開/收合**(現行已有)保留,並讓它同時作用於範例與追溯區塊。
- **鍵盤**:`:focus-visible` 統一 `outline:2px solid var(--accent);outline-offset:4px`;
  參照欄在 ≤999px 開啟時,主文加 `inert` 避免 Tab 跳進被遮住的內容;
  `Escape` 關閉搜尋面板 / 抽屜 / 窄螢幕參照欄。
- `prefers-reduced-motion:reduce` 時關閉所有動畫與平滑捲動。
- **`aria-controls` 不得指向尚未存在的 DOM id**(原型 `src/App.jsx:168` 的缺陷)。
