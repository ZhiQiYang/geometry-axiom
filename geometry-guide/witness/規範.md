# 見證圖規範(v1,2026-09-20)

> 每一張 `witness/<條號>.svg` 都由 `witness.py` 的**同一條程式路徑**依本規範產出。
> 沒有「這張特別畫」;要改畫法就改本規範與 `witness.py`,然後全部重出、全部重看。
> 使用者要求(2026-09-20):示意圖必須讓「一根一根角材怎麼排、誰停在誰身上」看得出來,
> 且所有圖用相同規範建立。

## 0. 兩個不變的前提

1. **幾何全部來自引擎**:主圖是 `current_geometry.c --no-window` 的 SVG 原樣裁切,接點格是同一份幾何的局部放大。
   `witness.py` 不畫任何一條幾何線,只加**標註**與**版面**。
2. **拓樸來自引擎輸出的反推,且必須唯一**:每個角材端面,在引擎文字輸出裡找「與端面共面、且沿軸涵蓋端面全寬」的
   對象——其他角材的側面、外輪廓邊、孔邊(D11 的三種來源)。找不到或找到多個 → 見證失敗,不出圖、不畫問號。
   反推結果另存 `<條號>.joints.json`,與 SVG 一起逐位元比對;**拓樸是見證本體,圖是它的呈現**。

## 1. 版面(固定三區,由上而下)

```
┌──────────────────────────────────────────────┐
│ ① 主圖:指定視圖(bottom/front/side/all),原比例      │
│    角材依角色著色;每個端面畫停止標記(不寫字,避免堆疊)      │
├──────────────────────────────────────────────┤
│ ② 接點列:每個角材端面一格,等比例放大(窗=8×料寬)        │
│    格標題 `t3·END→t1`(擋面參照只寫在這裡);順序 id 升冪,START 先 │
├──────────────────────────────────────────────┤
│ ③ 圖例:四種角色色、停止標記、擋面參照寫法(每張相同)      │
└──────────────────────────────────────────────┘
```

- 沒有角材的條文(D6、D10a、R7、R16、R17……)②為空列,印「本條無角材接點」;①③照常。不是另一套版面。
- `view=all` 時①是整張三視圖;②仍只在該條 manifest 指定的 `joint_view`(預設 bottom)上放大。

## 2. 記號(每張相同)

| 元素 | 畫法 | 來源 |
|---|---|---|
| 角材 `boundary`(層級 1) | 填色 `#e2a24a`(琥珀,實) | 角色由 `.scene` 的 `timber … role` 宣告(D15:角色是宣告) |
| 角材 `primary`(層級 2) | 填色 `#63b3ed`(藍) | 同上 |
| 角材 `secondary`(層級 3) | 填色 `#9ae6b4`(綠) | 同上 |
| 角材 `custom priority N` | 填色 `#d6bcfa`(紫),標籤附 `pN` | 同上 |
| 停止標記 | 端面位置一條垂直於長度軸的短粗線(長 = 1.6×料寬),同角材色;**整條在被裁料自己這一側**,不壓接觸面、不進對方料(物理:同一空間不能被兩個物體占用,標註也不得暗示) | 端面頂點(引擎輸出) |
| 擋面參照 | 只寫在接點格標題 `t3·END→t1` / `→e0` / `→h0e2`,**D18 寫法**;主圖不寫字(角落會堆疊) | §0-2 反推 |
| 邊、孔、參考線、網格 | 引擎原樣(藍邊、紅虛線參考線) | 引擎 SVG |
| 標籤字級 | 主圖 110mm(引擎既有);接點格依放大倍率縮放使視覺上等於 12px | — |

- 角材標籤保留引擎原有的 `角材N A0`,不重排。
- 所有數值標註(長度、座標)**不寫在圖上**——那是條文與夾具註解的事;圖只負責「誰在哪、誰停在誰身上」。

## 3. 接點格

- 一格 = 一個角材端面。窗口正方形,邊長 `8 × max(A,B)`,以端面中心為中心。
- 內容 = 主圖同一份幾何(同一 `<g>` 經 `<use>` 引用)+ 該端面的停止標記與標籤;其他標記不顯示。
- 格標題:`t<id>·START→<擋面參照>` / `t<id>·END→<擋面參照>`;格內停止標記比主圖粗(1.6 倍)。
- 順序:角材 id 升冪;同一支 START 先、END 後。一列最多 6 格,超過換列。
- 端面頂在外輪廓邊(只有 boundary 可以,I19)的格子,標題後加 `(RC)`。

## 4. 可判定的失敗(不出圖)

- 同一承載面任兩支角材 A0 footprint 正面積相交(I11;witness 自驗,不依賴引擎)。
- 停止標記侵入擋面對方角材的 footprint(標註層的碰撞自驗)。

- 端面找不到唯一擋面(§0-2)。
- 引擎 SVG 版面不是「前/側/仰」三個 `<g>`(版面變了要跟著改)。
- `.scene` 裡有角材沒有 `role`(I18 本來就會拒絕)。
- 主圖裡角材多邊形無法與引擎文字輸出的 A0 面一一對應(著色會錯,寧可不出)。

## 5. 與閱讀器

閱讀器嵌入時只換配色(深色),不改版面與記號;三區都在同一個 `<svg>` 裡,嵌入即完整。
