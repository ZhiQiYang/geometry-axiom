## 3. 真正的 bug（GEO-137，尚未修）

使用者一再指出圖上「藍色主支穿過琥珀色邊界材、穿過孔邊」，現實不可能兩物體占同一空間。前 agent 三次用座標驗證都說「沒穿透」——**驗錯了東西**：

- 引擎 CSS 有 `polygon, line, rect { vector-effect: non-scaling-stroke; }`。
- 停止標記是 `<line class="stop" stroke-width="…">` 畫的 → 粗度變成**螢幕像素**而非 mm。
- 圖縮小時，27 mm 的料只有約 5 px，8～40 px 厚的標記線就直接穿過整支料。放大看時相對變小，所以在 Chrome 放大檢查「看起來對」；用座標算時假設粗度是 mm，「算起來對」。**兩個都是假的。**
- 證據：把 `D15.svg` 的 viewBox 設成接點列（`0 5460 4500 2700`、寬 800px）在 Chrome 看，`t5·START→t1` 格藍色貫穿琥珀、`t7·END→h0e0` 格藍色穿過孔邊——與使用者截圖一致。
