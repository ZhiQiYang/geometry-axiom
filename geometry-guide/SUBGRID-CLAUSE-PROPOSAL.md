# 子網格系統：已核准條文與驗收條件

狀態：**使用者已於 2026-09-27 明示「批准 請開始實作」。以下逐條差異已採納至公理層，實作與驗收依本文件進行。**

日期：2026-09-27。工單：GEO-204。

## 1. 建議採用的操作

1. 開啟面內的主網格，在畫布點選一個格子。
2. 分別設定 u、v 等分數。預設各 2 等分；1 表示該方向不加內部線。
3. 畫布預覽局部子線，顯示父格範圍、實際間距、條數及「副支 3」預設。
4. 確認建立。之後可選取子格編輯、重新指定父格中的格子；子網格定義隨專案保存並支援復原／重做。整組或逐線顯示偏好沿用目前面內工作階段設定，重開專案時恢復顯示。
5. 沿子線放角材時預填副支 3，仍可明確覆寫角色。介面依面上實際主支軸提示方向衝突；子格邊界本身不提供材料支撐。

### 此次必須拍板的選擇

| 項目 | 本提案的選擇 |
|---|---|
| 範圍 | 一個子網格對應一個父格；u、v 可各自等分；只一層父子關係 |
| 何謂父格 | 主格兩軸格線與承載面外接邊界形成的相鄰矩形，包括靠邊格；面材來源亦按可見縫中心線分格 |
| 不規則面與孔 | 子線只顯示在父格與有效面的交集；沒有正面積交集的格子不能選 |
| 等分 | 整數 mm 精確等分，除不盡即提示並拒絕，不取近似值 |
| 局部放材 | 直接錨在子線的角材，其完整 footprint 必須留在父格內，並符合既有實際擋面、碰撞及角色規則 |
| 父格追蹤 | 保存四邊的來源參照。父格線數不變時按原索引跟隨移動並預覽；任一軸線數改變且仍有子格時拒絕 |
| 刪除 | 父格尚有子格時不可刪；子格仍被角材或參考線引用時不可刪；提示實際依賴項目 |
| 容量 | 全世界主格與子格共最多 16 組，每軸最多 64 條內部線；同一父格矩形最多一組子格 |

**來源界定**：使用者提供的《網格建立 v2》畫出「點一格、雙軸等分、子線預設副支 3」。邊格、孔裁切、依賴、容量與局部放材限制，是本提案補齊的決策，不是稿件已批准的規則。舊 GEO-105 的 `by_span` 全格批次方案與此稿不同；本次採較新的單格操作，批次條件等分、相位／交丁與巢狀子格仍另案待定。

## 2. 已核准逐條差異

下列 `+` 是核准新增文字，`-` 是核准替換文字。未列出的條文沿用現行 SSOT；正式文本見 `公理層.md`。

### D6a：子線可作為座標來源

```diff
- (b) 同面其他參考線（含 D6 的 DATUM 來源）的位置，或網格的（軸，索引）格線位置（D10/D10a)；
+ (b) 同面其他參考線（含 D6 的 DATUM 來源）的位置，或主網格／子網格的（軸，索引）格線位置（D10/D10a/D19）；
+ 引用子線的座標只引用該軸位置，不將父格範圍或預設角色附加給 D6 獨立參考線；獨立參考線仍依 D6 裁切可見段。
```

### D10：區分主格與子格

```diff
- 線段不存，用時由輪廓截出——可能多段、可能空段。
+ 主網格線段不存，用時由有效面輪廓截出——可能多段、可能空段。子網格的來源及局部範圍另依 D19。
+ 主網格與子網格共用 grid id 空間；同一 id 不可藉重宣告在兩種類型間轉換。
```

### D15：沿子線的角色預設

```diff
- 以 D10 格線放置時，介面可預填該線的 `primary / 2` 或 `secondary / 3`，
+ 以 D10 或 D19 格線放置時，介面可預填該線的角色；主格依 D10，子格兩軸皆為 `secondary / 3`，
```

後接現有「正式宣告必須明寫角色、可明確覆寫、仍須通過 I18–I22、不改既有角材」全文。**D17/I21 不變**：與實際主支軸平行的子線不能以副支角色放材；尚無實際主支軸時亦不能先放副支。父格的 `main_along` 不是實際主支軸。

### D19：子網格定義（新增）

```diff
+ **D19 子網格（Subgrid）**：依附一個 D10 主網格，定義只存自己的 grid id、父 grid id、父格四邊參照，以及 u/v 等分數。承載面由父格取得，展開座標與線段不存（D9）。父網格必須是主網格，不能再依附子網格。
+ 父格分界為：各軸主格推導座標，加上承載面有效範圍外接區間的 min/max，依座標排序去重。兩軸各取一對相鄰且不同的分界，形成閉矩形 C；其與有效面 F 的交集須有正面積。未定義或推導零條線的軸仍以 min/max 形成一個區間。
+ 四邊參照各為 min、max 或 line:<index>；索引指主格該軸的 0-based 線。恰與外接邊界同座標時，以 min/max 為標準參照。這些邊只限定局部範圍，不新增 D11 擋面。面材來源的父格依縫中心線形成，不以面材本體邊緣另切一份格子。
+ 設某軸兩界為 lo、hi，等分數 n。第 k 條內部子線位置為 lo + k × ((hi − lo) / n)，k = 1…n−1。只有內部線屬於子格；父格邊不重複生成。子線以（子格 id、軸、索引）引用，索引沿座標遞增；可見段為該線與 C∩F 的交集，可多段或零段。
+ 子格兩軸的格線皆預設 secondary / 3；只提供放置預設，不擁有或自動建立角材，不繼承父格 main_along，不改既有角材角色。
+ DSL：subgrid <id> parent <grid-id> cell u <lo-ref> <hi-ref> v <lo-ref> <hi-ref> divisions u <n> v <n>。
+ 重宣告須給完整定義，父 grid id 不變；可明確重選同一父網格中的格子及修改等分數，沿引用鏈重新推導並依 I8/I8a 提交。
```

### I8a：影響預覽納入子格（追加）

```diff
+ 改動主格、子格或有效面，使既有子格範圍／子線位置／可見段改變時，預覽須列出受影響子格的父引用、新舊矩形範圍、新舊線座標及可見段變化；即使沒有角材引用也要顯示。
+ 同時列出沿依賴鏈受影響的 guide 與角材；guide 列新舊方向／座標／可見段，角材沿用本條的新舊幾何與逐項違規要求。候選來源過期、取消、回滾與確認後重驗的紀律不變。
```

### I10：數量與類型（追加）

```diff
+ 每面最多一個主網格，可有多個子網格。全 World 的主格與子格合計上限為 16 組；各網格單軸上限為 64 條線，超限即拒絕，不截斷。
+ 本條 EXPLICIT/SERIES/PANEL_LAYOUT 及 main_along 的來源要求適用主網格；子網格的來源合法性依 I25，其推導座標亦須嚴格遞增且在承載面外接區間內。
```

### I13：子線錨法（追加）

```diff
- at-line——引用一條參考線（D6）或格線（D10/D10a 的（軸，索引））；網格是參考線的集合（D10），兩者在此不分家。
+ at-line——引用一條參考線（D6）或格線（D10/D10a/D19 的（軸，索引））；中線對齊的幾何約束相同，直接引用子線另受下列局部範圍限制。
+ at-line 的格線引用包含 D19 子格，沿用 at-line grid <id> <axis> <index>。直接引用子線時，角材的完整 footprint 必須包含於該子格矩形 C，並照常通過有效面包含、兩端擋面、碰撞及角色檢查。子格邊界不能代替實際擋面。
```

### I23：主格、子格與引用鏈（追加）

```diff
+ 本條適用主格與子格；依賴鏈包含主格 → 子格 → guide／角材，以及其後的引用。座標改動重新推導；仍被 guide／角材引用的子線索引不再生成，或刪除仍被 guide／角材引用的子格，均拒絕且保留舊 World。不得把引用改指到鄰線。無引用的子線可因減少等分數而消失，保留下來且仍被引用的索引按其新位置重算。
+ 主格仍有子格時不得刪除，也不得在仍有子格的交易結果中增減任一軸的推導線數；此限制同樣適用有效面變更及拆面造成的線數變化。先處理子格與下游引用，才可改動線數。
+ 線數相同的主格重宣告依既有索引語意視為線移動；須重新驗證父格四邊仍相鄰，並以 I8a 顯示其新舊範圍。這不宣稱父線具永久身份，也不按最近座標自動改綁。
```

### I25：子網格守門（新增）

```diff
+ **I25 子網格守門**：父主格須存在，四邊參照須可求值、符合 D19 標準形式、兩軸各為相鄰分界且 lo < hi，C∩F 須有正面積。子格承載面須與父格一致；同一父格四邊定義只容許一個子格 id。
+ u/v 等分數皆為 1…65 的整數，至少一軸大於 1。每軸 (hi − lo) 必須可被 n 整除；不可整除即拒絕，不捨入、不截短、不分配餘數。n=1 是合法零條內部線。
+ 合法子線的可見段為零不等於該索引不存在；保持定義與引用，沿線放材仍須通過 I13/R6。容量依 I10。
+ 新建、重宣告及上游變更均先建候選並全量重驗；父格失效、分界不再相鄰、除不盡、超限或下游失效均整筆回滾。錯誤須指出父／子格、軸、實際跨度、等分數或失效引用。
```

### R6：局部範圍參與選段（追加在 b 與 c 之間）

```diff
+ 直接 at-line 引用 D19 子線時，先驗角材整個寬度帶在 C 的橫向範圍內。未使用 between 時，於選段前保留完整包含於 C 長向範圍的 R6(b) 合法跨距；through 只能選這些區間。
+ 使用 between 時，依 R21 枚舉實際擋面配對，驗跨距包含於原有 R6(b) 合法區間，並在配對唯一性判定前排除未完整包含於 C 的配對；不能僅因原 R6(b) 區間超出 C 就排除一組完整在 C 內的合法配對。
+ 不把跨距硬裁到 C 邊界，也不把 C 邊界當作擋面；兩端依 (d) 與 I19 檢查，between 保留 R21(b) 的指名擋面唯一性例外。無合法局部跨距則拒絕；最終 footprint 再驗包含於 C∩F。原 at-face 的重疊篩選語意不變。
```

### R13：拆面時保留父子依賴（追加）

```diff
+ 主格與其全部子格視為一個父子集合，先在各候選片共同求值，再依本條「只一片合法則歸該片、兩片合法留原片、皆不合法拒絕」規則選片，不複製 id、不拆散父子。合法性包含 I10/I23/I25；guide 與角材仍依本條歸屬並通過同面引用及全量重驗，任一依賴不能成立即整筆回滾。
```

### R23：子格推導、保存與展示（新增）

```diff
+ **R23 子格推導**：先生成主格座標，求 D19 父格四邊，再依等分數生成子線，最後裁切 C∩F；所有引用該子格的 guide／角材在這之後求值。父格 main_along 的變更不改子格角色預設或既有角材角色。
+ dump／保存輸出父主格定義在前、子格定義在後，再按引用依賴輸出後續物件；子格不存展開座標或線段。讀回須恢復相同定義與推導結果；undo/redo 以完整交易為單位恢復整條依賴鏈。
+ 子格支援整組與逐線顯示切換。隱藏只改展示，不改幾何、引用、放材合法性或保存來源；隱藏線不留下畫布可點選的命中範圍。顯示偏好的保存範圍沿用現有面內參考線控制。
```

## 3. 可檢查的例子與取捨

- 父格 u=[1500,2500]、v=[300,600]，各 2 等分：生成 u=2000 與 v=450，各一條；子線只在此格內，孔內部分裁去。
- u 跨度 1001 mm、2 等分：拒絕並說明不能整數等分；可改選整除跨度的等分數，不能自動移線。
- 父 u 線從 [1000,1500] 改成 [1100,1600]：同索引移動，子格與下游一起預覽；任何角材不合法則不能套用。
- 父 u 線從 [1000,1500] 改成 [500,1000,1500]：仍有子格時拒絕，避免 line:0／line:1 改綁到另一格。此方案亦會阻擋遠處增線；若未來要放寬，需另定父線永久身份或明示遷移規則。
- 父格邊若落在主支中線，副支的端點可以停在格內的主支側面；若只有虛擬格線、實際擋面在格外，則不能沿子線建立跨出此格的材料。
- 由子線座標建立的獨立 guide 仍是 D6 的全長參考線；它不攜帶局部範圍。介面須區分「沿子格線放材」與「使用該座標建立參考線」。
