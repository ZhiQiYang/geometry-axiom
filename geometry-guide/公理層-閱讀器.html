參考網格（ReferenceGrid)D10公理層.md:46

D10 參考網格（ReferenceGrid)：屬於某承載面 + 兩軸各一份線的定義—— u 軸定義（U 座標集 = 沿 V 走的直線）、v 軸定義（V 座標集 = 沿 U 走的直線）。 每軸的定義三選一，兩軸互相獨立、可用不同來源（D9：只存定義，展開的座標不存）： 明寫（EXPLICIT）——逐一列出座標； 等差（SERIES)——起點 start、間距 step>0、條數 count，第 k 條 = start + k·step； 面材（PANEL_LAYOUT)——面材本體 panel、縫寬 gap、起算點 anchor，格線 = 縫的中心線（D10a)。 「該軸未宣告」與「該軸推導出零條線」是兩回事：前者是定義不存在， 後者是合法的推導結果（面小於一片面材）。 網格 = 參考線的集合，用（軸，索引）選線；索引 0-based，沿座標遞增方向數。 線段不存，用時由輪廓截出——可能多段、可能空段。

面材排法（PANEL_LAYOUT）的格線D10a樞紐公理層.md:57

D10a 面材排法（PANEL_LAYOUT）的格線：設該軸有效範圍的外接區間為 [lo, hi] （D4，與 I7 / I10 用的是同一個區間），週期 T = panel + gap，起算點 a。 第 k 片面材本體佔 [a+k·T, a+k·T+panel)， 第 k 條縫佔 [a+k·T+panel, a+(k+1)·T)，k = 0,1,2,… 第 k 條格線（縫中心線）座標 c_k = a + k·T + panel + gap/2。 產生第 k 條的條件是 a+(k+1)·T < hi：整條縫落在範圍內，且其後仍有非空的面材本體。 不滿足即停止——末端是裁切片，合法；不因「除不盡」而拒絕，條數本來就是推導結果。 拒絕條件（D1 全整數、R3 退化就拒絕）： gap 為奇數 → 中心線不是整數 → 拒絕； panel ≤ 0、gap < 0、a < lo、a ≥ hi → 拒絕； 推導條數超過單軸上限 → 拒絕（不截斷、不靜默丟線）。 起算點在宣告當下具體化並寫進定義（凍結，比照 R6(e)）：明寫 from c 取 c， 未明寫取宣告當下的 lo。之後承載面改變不重算 a—— 因此已存在的索引永不被重新編號，能變的只有尾端條數。

角材角色與裁切優先級（cut priority）D15公理層.md:86

D15 角材角色與裁切優先級（cut priority）：每支角材宣告一個角色，角色決定整數優先級—— 數字越小越優先：空間邊界（外輪廓邊、孔邊、柱面）0、boundary 邊界材 1、primary 主支 2、 secondary 副支 3、custom 自訂料明寫 priority N（N≥1）。 custom 的 priority 只參與 I19 的數值比較，不取得任何角色專屬的義務或權利 （無 I20 覆蓋義務、無 D16 延伸段、無 I22 豁免）。 語法：timber id [L] A B role boundary|primary|secondary|custom [priority N]（🔒 2026-09-15）。 角色是宣告；「是否真的在邊界上」是推導（R18），兩者不一致 = 拒絕，不改宣告去遷就幾何。 物理意義：優先級高的料連續、優先級低的料被裁斷；連續的邊界材釘在 RC 上 （I19 因此另立一款：只有 boundary 可頂外輪廓邊）， 被夾的主支長度成為模數，可整批預裁、可頂出下一支位置。

R21 明寫跨距兩端（between）：auto 角材可用 between <擋面參照> <擋面參照>（D18） 取代 through，兩者互斥（同時寫 → 拒絕）。 它是消解歧義的選擇器，不是放寬條件： (a) 被指名的兩個擋面各自仍須滿足 R6(d) 的「涵蓋端面全寬」與「非 FREE 邊」； 不涵蓋全寬 / 是 FREE 邊 → 拒絕，不因為明寫就放行； (b) 它取代的只有「恰好一個」這項唯一性要求——同一座標上有多個合法擋面時， 改由宣告指定用哪一個，不再是「多個 = 歧義拒絕」； (c) 兩端固定座標必須一小一大、區間非空；跨距仍須逐 cell 通過 R6(b) （整支 footprint ⊆ 有效區域、不撞已放角材）——between 不能穿過實體； (d) 角材參照 t<id> 指它的兩個側面之一：枚舉全部候選配對， 恰好一組能產生通過 (c) 的跨距 → 取它；零組 → 拒絕； 多組 → 拒絕並列舉全部候選（不猜，與 R6(c) 同一條規矩）； (e) I19 的裁切優先序照常適用——between 不是豁免； (f) 推導出的兩端與長度一樣在 place 當下凍結（R6(e)）。
