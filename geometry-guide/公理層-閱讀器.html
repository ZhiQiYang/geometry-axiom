D2 承載面框架（PlacementSurface.frame）：原點 + 三個單位整數軸 U、V、N，且 U×V=N。 局部座標 (u,v,w) → 房間座標 origin + u·U + v·V + w·N。
白話,非條文
承載面自己有一套座標系:一個原點加三根互相垂直的單位軸(U、V、法向 N)。面上任何一點 (u,v,w) 都能換算回房間座標。 有了這個,「貼在天花板上」和「貼在牆上」就變成同一件事——都只是某個面的 U、V 平面,差別只在那個面的原點與三根軸指向哪裡。

D3 空間邊界面（SpaceBoundarySurface)：純局部 2D 物件——不含世界位置。 內容：正交多邊形外輪廓、零個以上內孔、每邊 fixity（FIXED/FREE，不寫=全 FIXED)、 分類（UNSPECIFIED/ROOM_PLAN/WALL_ELEVATION)、ROOM_PLAN 專屬的柱/樑投影。
白話,非條文
空間邊界面是「純粹的形狀」:一圈正交多邊形外輪廓、幾個內孔、每條邊是不是釘得上去(FIXED / FREE),以及它是平面圖還是立面。它不知道自己在空間中的哪裡。 把形狀跟位置拆開,同一個形狀可以被不同位置引用,改形狀也不會動到位置。

D12 畫布座標（CanvasPos)：(類別, id) → (x, y)，類別 ∈ boundary / placement / space / column / beam。 純展示中繼資料——物件在無限畫布上的擺放位置；不參與任何幾何推導， 但屬於 World 的一部分：跟著場景檔存取、dump 輸出、重放還原。 邊界面無承載面 = 游離面（D3 本就允許）：合法物件，三視圖不畫它。

白話,非條文
