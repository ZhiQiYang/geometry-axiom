# R03 平釘天花：第一個產品片

基準：`fa83e6ad8444c569b9f2f5e91f2de9a5622a92cb`。本文件描述 #205 的待採入補丁，不宣稱產品已合併或完成 L4。SSOT 是同一基準的 `公理層.md`，本片不修改條文、決策佇列或既有 oracle/golden。

## 使用者可以獨立驗收的範圍

在面內明選一個已有合法框架的封閉面，沿既有「面設定 → 完成面／骨架…」入口選擇平釘天花模式。保存配方後，明選這一次的板材版本、X 參數與框架，預覽整組邊界材、主支和副支的位置、長度及承接結果。取消不改正式世界；確認把整組一般定義寫成一筆生成歷史。另存完整 `.gcanvas`，在新程序冷開後配方及一般物件仍在，載入、Undo/Redo 和來源重算不執行模板搜尋。

第一片限軸向矩形、無孔、World 無具型別柱／樑、結構側朝上的水平框架。既有格線或角材不得被覆寫。四種起鋪角和板長沿 u/v 是明示偏好；板長是材料的 `length` 欄位，不以哪個尺寸較大猜軸。尺寸、容量、來源、碰撞、完整性和逐側承接沿用原生守門，任何一步不合法便整組拒絕。容量不足不截短清單。

木工政策位於 `geometry-templates/woodworking/native/flat_ceiling.h`，H 層將其輸出組成既有核心可以驗證的定義。核心沒有引用此生成器，也沒有新增木工專屬分支。Python oracle 僅供測試逐值對照；產品不匯入 oracle、不讀 golden、不保存搜尋結果。

本片不提供凹室、孔、柱樑排法、全 64 排法自動搜尋、任意 R45 勾選建議、再次生成自動差分刪料、活模板 owner、施工釘法或載重強度判斷。這些未提供的功能不能由一般物件重建成功推論成已支援。

## 配方與骨架是兩個明示交易

依 D/I/R⟨FT1⟩，配方是專案附件，保存意圖、不可變模板版本、政策指紋、字面預設、來源槽與提示。它不是 World 物件或來源，也不能儲存求值長度、生成清單、搜尋路徑、token 或已通過旗標。

1. 「保存配方」是一筆只改附件的專案歷史。若缺材料或 X，先到既有編輯器明示建立；8 mm 只是建立 X 的預設值。
2. 生成前重新明選當下來源，不以配方提示、自動最近點或重用數字 id 代替選取。
3. 預覽及取消不改 World、附件、歷史或正式 id 高水位。先前已明示保存的配方或材料仍在。
4. 確認一次提交完成面、鋪排、衍生宿主、活 `from-fill`、參考線、一般角材及放置定義；不是對公開確認命令連按多次。
5. 一次 Undo/Redo 恢復整組生成；配方可另一步撤回。刪除配方不刪已生成物件。

完整專案與方案保存附件；`.scene`、dump、D25 和 definition-import 不攜帶配方。未知 schema／必要能力或已知版本政策指紋不合時，在替換現案前拒絕整份專案。schema 可讀但 generator 缺席時，保留唯讀配方，一般定義由通用能力重建，不改用另一模板版本。

## Oracle 對照與支援域

支援域逐次計算，不是列幾個尺寸白名單。候選須同時滿足不置中、不在對牆以外裁片、主支連續、目前 oracle 與本次要求的副支記號逐值相同，然後通過完整原生驗證。八個既有 golden 正例是 F3 次臥板長沿 X 的四角（各 47 支）和 F4 走道板長沿 Y 的四角（各 25 支）。新增正向回歸 3740×2000、板長沿 Y 的四角各 33 支，已逐支通過原生與原 oracle 對照，不改舊 golden。3720×2000 雖在原 oracle 得 28 支且 check 無失敗，最後一跨僅 12 mm，舊政策省略副支後真 R43 承接不足，故產品拒絕；oracle 通過不能取代完整原生驗證。

A 為板寬軸，B 為板長軸；表列固定完成面座標。起鋪角的上下左右指預覽圖（u 向右、v 向下），不是世界上下。測試須比每支的位置、種類及長度，並驗真正定義、框架和活來源，不以總支數冒充逐值一致。

3700 mm 舊案例保留為**拒絕對照**。3700×2000、gap=2、板長沿 X 左起時，舊 oracle 在 [1831,3659] 這格給出 2198/2565/2932/3299；本次 ceil 公式給 2197/2563/2929/3295，不能同時聲稱兩者逐值相同。板長沿 Y 時，舊 FT02 把末縫 3667 移至 3659，倒數第二片由 915 變 907 mm；該片不靠對牆，仍違反本次裁切限制。gap=3 與 940 mm 首縫退縮例亦不得冒充共同通過。

## 驗收及證據界線

補丁本身不是實作 PR，產品級別仍 L1。L2 需要後續實作 PR 的確切 head、T→P 及具名撤回原件；L3 需要真正 merge SHA 與必要 CI；L4 需要可用 App 上的實際操作原件。不可把條文、oracle 或 C0 的級別轉貼成 R03 產品級別。

L4 路徑：明選封閉面 → 面設定 → 完成面／骨架 → 平釘天花 → 明選來源／參數 → 保存配方 → 預覽整組 → 取消並比 dump、附件、dirty、revision、id 高水位和歷史 → 再預覽並確認一次 → Undo/Redo → 另存 `.gcanvas` → 新瀏覽器與新程序冷開 → 配方和一般定義保持、generator 呼叫為零。另驗 `.scene` 只重建物件。

瀏覽器測試與 golden 產生器交雲端 Claude 執行；本環境不啟動 Chromium，不手填截圖或成功值。mutants_results、架構 scan/receipt/report、正典閱讀器 HTML 由 CI 或 Claude 使用正式工具重產，不能用手寫摘要代替原件。

## 後續完整政策版本：需使用者拍板

本次要求與已鎖定 oracle 有四處差異：固定 M 治具或每格 ceil、主支遇柱分段或衝突、部分柱面直接承接或僅角材承接、FT02 非對牆裁片或僅對牆裁片。第一片不替使用者改鎖定決定，只交共同相容域。

- **A：完整產品沿用目前已核定 oracle 版本。** 保留其固定治具、柱處理、FT02 和偏好，明示本次較早規則摘要中的相抵觸部分不覆寫後來決策。建議 A，因可承接已核對的 #307/#327 原件與具名撤回。
- **B：本次四項規則成為新不可變模板版本。** 另建政策指紋及獨立 oracle／人工核對；舊 oracle、舊配方保留原義。不得原地修改版本內容，讓已保存專案無聲變義。

這個選擇不重開已拍板的 FT-S1 A，不另問累積退距上限，不變更公理。
