# 跨面共用基準：提案與正式交付驗收

狀態：2026-09-18 分支提案，供逐條審閱；不代表已合併或正式採納。
基線：`ZhiQiYang/geometry-axiom`，`3c827ea84bf3ecfedbda063bca1e77c1f5f066d5`。
規劃責任：datum_planner；實作及 Git 責任：datum_implementation。

## 目的與範圍

使用者只定義一個房間座標的定位基準，各承載面由該基準推導自己的參考線。
前／上共 X、前／側共 Z、上／側共 Y。卡片擺放、畫面比例與相機方向不参与幾何定義。
本期只使用既有房間整數座標與正交框架，沒有任意斜面、跨房間座標轉換、共用網格或自動視圖排版。

## 資料與推導契約

- `DatumPlane = id + room_axis(X/Y/Z) + position_expression`，是 World 物件。
- `position_expression` 為既有具名 spec 的有理線性和，整個和取下界後得到整數 mm。無自由 mm 常數項；有限值、求值及推導位置遵守 D1。
- GuideLine 定義來源二選一：原有 `LOCAL(placement_id, direction, expression)`；新增 `DATUM(placement_id, datum_id)`。
- DATUM guide 不另存局部方向、offset、端點或可見線段。世界基準不因局部 frame 改變而改定義。
- 設基準正軸單位法向為 n，位置 d，承載面原點 o、軸 U/V/N：若 n·U=s=±1，則局部 u=s(d−n·o)，線沿 V；若 n·V=s=±1，則 v=s(d−n·o)，線沿 U。
- 若 n·U=n·V=0，兩平面平行：d=n·o 時重合，否則不相交；兩者都沒有唯一交線，拒絕建立，已有依賴時拒絕該變更並回滾。
- D6a 局部引用的同面同軸限制保持。局部 guide 可依法引用同面 datum guide，不能直接借用其他面的局部座標。
- 線本體為無限直線。可見段為直線與 D4 有效範圍的交集，孔洞扣除；零段不是刪除，多段不是多個 guide。I5、I11、I19 等材料條件不放寬。
- 第一版不開放 datum expression 引用面邊、角材、其他 datum 或局部 guide；這些世界幾何來源的循環與座標語意另案定義。

## 變更與交易契約

datum 重宣告、datum 所引用 spec 改值、承載面 frame 改動，都在候選 World 重算：
spec → datum → 全部面的 datum guide → 依賴 guide → 角材及其擋面依賴遞移閉包。

沿用 I8/I8a：已放角材受影響時必須預覽。預覽逐項列出承載面、角材、新舊中線／長度、失敗條號與預期／實際。
跨面預覽應額外給出新舊世界定位（局部中線不變但 frame 移動時也能識別變化），以及受影響 guide 的方向／位置。
確認時只准套用使用者看過的候選：參與驗證的幾何或引用定義改變使 preview 過期，必須拒絕並重新預覽；不能靜默重算後套用另一份結果。純 canvas-pos 展示變更不使幾何預覽失效（D12/I14）。
零違規確認後再次全量驗證，全部一起提交；取消、失敗、過期均不改正式 World。撤銷／重做以整筆交易為單位。
刪除仍被 guide 引用的 datum 必須拒絕，不能偷偷刪除下游或轉成局部自由數值。

## 與現有規則的交界

| 條文 | 本期處理 | 不可混淆之處 |
|---|---|---|
| D6/D9/I7 | 參考線存在與可見性分離；面外線合法 | 不能因不可見就自動刪除引用 |
| D6a/D6b | 原有局部引用維持；datum 首版僅具名 spec | 不能一併開放所有世界幾何來源 |
| D10/D10a/I10 | 網格生成及有界序列規則保持 | 網格是有生成規則的集合，並非無限延伸任意索引 |
| I23 | 被引用的生成索引消失仍拒絕 | index 不存在與 guide 存在但看不見不同 |
| R13 | 分片以各片實際可見裁切結果分類，兩片皆可見留原片、只有一片則改掛、兩片皆不可見拒絕拆分 | 放寬 I7 不能把所有片誤判為合法歸屬；拒絕的是未定歸屬操作，非既有隱藏 guide |
| R13/D6c | datum guide 改掛只改 placement，仍引用相同 datum | 不複製 datum，不在兩片各生成新 guide 身份 |
| D12/I14 | 畫布位置純展示 | 對齊卡片不會建立或改變 datum |
| R4/I9 | dump 依賴定義先於使用者，保留來源 tag 和 expression | 不存推導後 offset 冒充共同基準，不恢復已廢除語法 |

R13 未涵蓋的自動複製、多片共用同一個 guide 身份、隱藏線任意歸片不在本期；操作拒絕應指名不能歸屬的 guide。
新條號用 D6c／I7a 等附屬號，不使用已預留的 D19／I24／I25／R22／R23。

## 正式驗收矩陣

| 編號 | 條件 | 最低可核對證據 |
|---|---|---|
| A1 | X／Y／Z 三組共享位置正確；不同原點、軸交換與負向軸正確 | 確定座標的核心案例及世界座標結果 |
| A2 | 平行不相交和重合皆拒絕；重宣告不得留半套 | 錯誤碼／條號與 before/after World 一致 |
| A3 | 面外線可建、可存、可被合法 expression 引用；顯示零段／穿孔多段保持同 id | 核心導出結果及 UI 檢查 |
| A4 | 隱藏線不授予面外放料權；原局部同面同軸引用仍守門 | 針對性拒絕案例 |
| A5 | 改 datum、spec、frame 涵蓋跨面依賴鏈；含局部中線未變而世界姿態改變 | 預覽明細包含全部受影響面與角材 |
| A6 | 成功確認原子提交；違規／取消／過期不改；undo/redo 恢復整筆 | 序列化快照與橋接／UI 操作證據 |
| A7 | dump→load→dump 相同；導出來源與依賴不丟；當前合法舊場景仍可讀 | round-trip 及受影響既有門檻 |
| A8 | 新建基準、選取承載面引用、修改基準有實際可操作 UI | 瀏覽器走完建立→引用兩面→預覽→取消／確認 |
| A9 | I10/I23 生成規則未被 I7 放寬；R13 不丟資料或改错歸屬 | 已有受影響案例與一個隱藏 guide 拆片拒絕案例 |
| A10 | 公理／白話／唯一正典閱讀器同步，保留未變段落身份與批註 | 五道 assert；clauses 的 source 與獨立讀取公理解析結果比對 |
| A11 | 分支／draft PR 可審閱，main 不變 | base/head SHA、逐條 diff、實際測試命令與結果、已知未完成項 |

測試只覆蓋上述有風險行為及 repo 既有必要門檻，不以大量重複測試取代公理推導。未完成項必須在驗收中標為未通過，不能用文件宣稱代替實作證據。

## 逐條修改清單

1. D6：區分 LOCAL/DATUM 定義；直線本體與顯示裁切分離。
2. D6a：限制對象明確為 LOCAL，保留同面同軸與無裸 mm。
3. D6b：具名值可作 D6c 來源，重宣告仍走交易。
4. 新增 D6c：World 軸向無限基準面、最小引用式來源及精確交線公式。
5. D9：共同基準不存各面的交線，DATUM guide 不存推導位置。
6. D10a：移除「與 I7 同一區間」的過期交叉敘述，I10/D4 保持。
7. I7：移除 guide 必在外接區間限制；保留 D1、引用存在、同面同軸、環拒絕。
8. 新增 I7a：唯一交線、datum 引用存在、不可刪除仍被引用 datum。
9. I8/I8a：跨面重算與預覽，框架世界姿態、過期預覽及原子操作。
10. I10/I23：明確為網格生成限制，不受 guide 顯示裁切改動影響。
11. R2/R4/R5：共用來源修改、來源式序列化、拖曳不得暗中拆掉共用關係。
12. R13：保留片歸屬依可見段判定；不可見不當成通用有效性，無歸屬拒絕。
13. D12/I14：補充跨視圖對正不構成幾何引用（純說明，無新資料模型）。

## 待確認但不阻止本期最小子集

- datum 未來是否可引用世界幾何位置／另一 datum／不同房間坐標系。
- 隱藏線在拆片時是否應自動保留原片、複製或要求指定片；本期沿用拒絕不猜。
- 是否增加共同網格與任意斜基準；本期不做。
- 手機實際 iOS 瀏覽器／附件預覽結果不以桌面模擬取代；若只有模擬驗證，交付明列。

## 條文到執行證據的追溯要求

正式交付需逐項記錄「條文 → 核心函式／資料定義 → 對應驗證與實際結果」。
D6c / I7a 的交線求解、D6 / I7 的定義與裁切分離、I8 / I8a 的交易與跨面依賴、R4 的序列化應在 C 核心生效；不同應用經同一命令與核心使用該領域子集。
UI 僅蒐集指令與呈現結果，不另寫一套 datum 座標規則。
`axiom_matrix.py` 的條號註解掃描不是正確性證明，且其既有 `SRC` 只讀 `current_geometry.c`，不代表新增 `.inc` 有完整涵蓋。
本期不擴大重構整個架構，但驗收不得只拿註解映射或測試全綠代替該對照。
