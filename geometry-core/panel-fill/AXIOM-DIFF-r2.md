## 2. 既有條文的精確修訂

### E1：§四第一、二項改為有限納入

原文（AX 1145–1148）：

```text
- 施工面材實體、完成面（FinishSurface）與完成面高程 —— 未來的層。
  D26 可保存面材厚度作為型錄資料，D20 已定義通用擠出厚度；
  兩者都不等於已定義施工面材的層次、完成面或高程依附語意。
- 樑投影的輪廓裁切：依完成面高程決定，本層只存資料不裁切。
```

替換為：

```text
- 完成面的位置、方向、輪廓及開口，面材試排與縫位、幾何承接比對，
  以及經明確確認建立的板縫貼板角材與邊材，限 D41–D45／I52–I57／R41–R46（`panel-fill/1`）。
  試排板片是推導結果，不是 D7 角材、施工實體或材料合格證明。
  載重、撓度、固定件、吊筋、與樓板連接、施工順序、主支承載判定及板中間支撐的自動反推仍不在本層。
- 完成面障礙集合中的 RC 柱、樑，依 R41 對面材層、貼板角材層各自自動裁切。
  既有 D3／D4 的柱樑投影、R7–R12 apply-proj 快照與手動流程保持原義；
  不因新增 FinishSurface 自動重算或改寫舊場景。
```

§四斷面拉伸段末句（AX 1178）「本節第一項『施工面材實體、完成面』仍是未來的層」改為
「完成面與試排僅依本節第一項的獨立能力有限納入，不屬於斷面拉伸能力」。其餘斷面排除項維持。

「主支承載判定」是 r1 新增的字。R45 在板縫下放的連續 `primary`，幾何上就是主骨：D15 寫明優先級高的料連續、被夾的料長成為模數，
平釘天花的板縫位置就是主骨位置、主骨通長不切（flat-nailed-ceiling §二原則 3、4）。所以這不是「primary 不等於主骨」，
而是**偏離 🔒Q46 字面**：Q46「只做貼板一層、主骨排除」預設了上下兩層，平釘是單層共平面（§二原則 2、§六-2），字面無法成立；
r2 的讀法是「放在主骨位置的連續料照放，只排除吊筋、與樓板連接與承載判定；本層不證明其吊掛與承載」。B4 補上的壁邊材同樣超出 🔒Q45「只做板縫下」的字面。
兩者都標為偏離 🔒 的暫定裁決（依授權 L），須使用者確認；SSOT 條文不必因此改字。〔P10、P11〕

### E3：D10 增加一種主格來源（只改 D10，不改 D29）

AX 153「每軸的定義三選一」改為含鋪排的新列舉（L1）；並在 AX 182（from-binding 段末）之後新增 from-fill 段。全文見 `axiom-patch.md` P-05／P-06。要點：

- 主格可整格以一份 D42 鋪排為來源，只存鋪排 id 與可選 main_along；兩軸格線取自 D43 縫中心線。
- 所在承載面必須是**該鋪排的**衍生承載面；其他承載面不得引用鋪排來源。
- 格線身分（軸，signed k），被錯開軸另含 band；比照 from-binding 的無限主格處理範圍、可見段與查詢容量。
- I10「座標序列嚴格遞增」對本來源以完成面框架的 c_X(k) 判定（T_X>0 恆成立）；s=−1 時板背框架的 v 座標隨 k 遞減，不因此被拒。（R2-C-a）
- 本版鋪排來源主格不得作 D19 子格父格，不適用 D19a。〔P2〕
- D29、D30、I37 一字不改（B5）。可重用的對齊網格改由 R44 末段的「D29 值快照」取得。

### E4：D4 增修「衍生承載面」變體（B2、B3）

AX 49 之後新增一段。全文見 `axiom-patch.md` P-03。要點：

- 衍生承載面與一般承載面**共用同一 id 空間與型別**；D6、D7、D10、I13、R4 的「引用承載面 id」不必改。
- 只保存：id、變體標記、來源試排 id、h 的具型別來源、D12 畫布位置。**不存** boundary_id、rect、frame、輪廓、孔、fixity。
- frame 與有效範圍每次依 R41 由「來源試排的完成面、板厚 t、障礙集合」與 h 求得，不可直接編輯，不另存輪廓副本（R41 成立）。
- h 的來源型別同 D7 的 B（直接整數、D6b、D26 timber 的 B、D31 尺寸欄位），不含 D28 面套用欄位。〔P8〕
- 每份試排至多一個衍生承載面；不可在一般／衍生變體間轉換；來源試排建立後不可改指。〔P4〕
- 有效範圍可為零個或多個分量；外輪廓邊／孔邊以 R41 的衍生邊鍵引用。〔P3〕
- 不作 D5／D21 成員、D20／D38 宿主、D30 邊界；不接受 D28 面套用、apply-proj、R13 拆分。〔P4〕

dump／保存時這種 D4 記錄只輸出上列保存欄位；輪廓、孔、fixity、frame 皆不輸出，重放時重算（I56、R4 增句）。

### E5：D7 交叉註記（B3）

AX 130 之後加一句：宿主為衍生承載面時，B 的有效值須等於該面的 h、B 向須朝 +N（結構側），見 I53。
理由：D7 的 B 是沿承載面法向的截面高（`current_geometry.c` 的 A0 = local Z=0 接觸面、B 沿 ±N 延伸），即 R41 的 h。

### E6：I13 增句（鋪排主格的 band）

AX 646 之後加一句：引用鋪排來源主格被錯開軸的線時須寫 band；band 為另一軸的板列索引 p（D43）；
角材沿線範圍須落在 [c_Y(p−1), c_Y(p)] 經 R41 映射到板背框架後的閉區間內（s=−1 且 Y=v 時為 [−c_v(p), −c_v(p−1)]，R2-C-b）；band 邊界不是擋面。

### I53 分層與障礙

```text

```

物理依據：
- **開區間（B1）**：Q47 寫明的理由是「撞到樑是物理衝突……手動會允許建出重疊的非法狀態」，衝突的是兩個實體共佔空間，也就是正體積重疊。
  板背恰貼樑底時，板可以連續通過、直接鎖在樑底；角材頂恰貼樑底時，角材可以連續通過並固定在樑底。這兩種都不是衝突。

  它讓角材層 [t, t+h] 對整個衍生承載面只有一個範圍，遇障礙判定因此唯一。混用不同 h 的角材在物理上做得到，但本版拒絕，不是物理定律。

## 5. 新增推導全文

### R41 空間層次與衍生承載面

```text
設完成面原點 O、框架 U、V、N、結構側 n=s·N、板厚 t（I52）、衍生承載面的 h（I53）。
障礙 k 的 AABB 在完成面框架為 R_k×W_k：R_k=[u0,u1]×[v0,v1]，W_k 是沿 n 的 q 區間（q=s·w）。
面材層取 q∈[0,t]，貼板角材層取 q∈[t,t+h]。某層遇障礙 k ⇔ int(R_k)∩int(F)≠∅，
且 W_k 與該層 q 區間的開區間交集非空（I53）。
每層的有效區域 G_層 = reg(F \ ∪{R_k | k 遇該層})；遇障礙者在該層裁切，否則該層從障礙旁或下通過。
水平完成面等價於比較 z 區間；垂直完成面沿其 n 計算，不能偷改成只比 z。
板背框架為 (O+t·n, U, s·V, n)，仍是右手系（U×sV=sN=n）；完成面座標 (u,v) 映射為板背座標 (u, s·v)。
衍生承載面的有效範圍是 G_角材層 經此映射的結果。它依內部連通拆成分量（只以點相接者是不同分量）；
每個分量須能表為一個簡單外環加互不相接、不接外環的簡單孔環（I2）；
不能時為退化，候選整筆拒絕（R3），不猜、不以 bbox 填補。G 為空是合法結果，其上任何角材依 I5 不成立。
衍生邊 = 各環上方向相同、fixity 相同的極大直線段；繼承自 F 邊者沿用其 fixity，障礙裁切產生者為 FIXED（同 R7）。
衍生邊鍵：邊界上每一點的來源，是含該點的 F 邊（外環 e<i>／孔 h<i>e<j>，依 D41 所引 D3 的索引），
或障礙投影矩形的一側（c<id>／b<id> 加 u−、u+、v−、v+，板背框架）。
每個來源在 G 邊界上的留存部分，依走向（F 邊依其 D3 頂點序；障礙側邊依板背框架中沿該側座標遞增的方向）切成極大連續段，從 0 編號，並記其總段數。
衍生邊鍵 = 沿環的正規走向（板背框架中外環逆時針、孔環順時針）依序列出構成該邊的（來源、段號、總段數）；
來源全序：F 外環邊（依 i）＜F 孔邊（依 i、再依 j）＜柱 c（依 id）＜樑 b（依 id），同一障礙依側別 u−＜u+＜v−＜v+；同一位置有多個來源時依此全序排列，衍生邊鍵之間依此全序作字典序比較。
at-face、D18 擋面、D6a(a) 及 R18 的 boundaryEdge 對衍生邊一律保存鍵；
候選中恰有一條鍵完全相等的衍生邊，解引用才成立；零條或多條 → 拒絕並列出，不找最近邊。D6a(a) 在衍生面上只引用衍生邊（以鍵）的該軸座標；正交輪廓的頂點座標必等於與之相接、垂直於該軸的衍生邊座標，故不另定頂點引用，頂點引用即拒絕。
多分量或多跨距逐分量、逐段保留；R6 多解仍須明示選段。
衍生承載面不另存輪廓副本，也不另做一套放置／碰撞引擎；其上的放置、碰撞、擋面一律用既有 D7／I／R。
```

〔P3〕衍生邊鍵把「總段數」放進鍵裡，是刻意的嚴格：新加一支樑把某條被引用的牆邊切成兩段時，舊鍵不再相等，交易拒絕，
使用者須在同一交易內明確重選引用。這與 I23(b)〈失去指涉即拒絕〉(協調 agent 對 I23(b) 的概括，非條文逐字、非使用者原話；同句見決策佇列 PF-0 暫定表 P3 列理由要點欄)同一紀律，代價是編輯障礙時較常被擋。
〔P5〕退化即拒絕，與 R7「角點相切 = 退化拒絕」、R10「孔跨切線 = 拒絕」同一態度；只以點相接的分量不焊接，與 D23 同一態度。

### R42 板片、裁切與縫位

```text
所有排板量在完成面框架求值，再依 R41 映射；奇數 g 的 ⌊g/2⌋ 在完成面框架取，不在板背框架另取
（s=−1 時兩者會差 1 mm，以完成面框架為準）。
每一軸用 D43 的式子；以 signed (i,j)∈Z² 列舉本體與 G_面材層 有正面積交集的板片（交丁時被錯開軸再依板列奇偶平移 δ）。

既有有限 D10a 仍只列 k≥0 且 a+(k+1)T<hi 的線，不改其 from／停止條件。
在相同起點、同一框架與共同列舉範圍，板縫中心必與既有 PANEL_LAYOUT 及 D29 REPEAT_PANEL 逐條完全一致。
```

### R43 每側承接判定

```text
承接角材 = 以該試排的衍生承載面 id 為宿主的全部已放角材；依引用判定，不依幾何巧合：
其他承載面上的角材即使恰位於同一平面也不計。尚無衍生承載面時承接集合為空。
足跡經 (u,v_d)→(u,s·v_d) 映回完成面框架後與板片比較。
對每條有效板縫段，以所有足跡邊界在縫向上的座標切成開子段；在每個開子段上，沿垂直縫的方向，
分別量兩側板邊進入「足跡聯集 ∩ 該側板分片」的連續覆蓋寬度 d_L、d_R：自板邊起算，
遇板縫空隙、孔、障礙裁切區或足跡間斷即止。
該子段 d_L≥X 且 d_R≥X 才標「已承接」，否則標「承接不足」並列出該子段與兩側實值；
整條縫段的判定是逐子段結果，不取平均。X 以精確有理數比較，不四捨五入。
縫線上只有一側有板的部分不是有效板縫，不判定（顯示「外緣非兩板縫」）。
這只是幾何承接比對，不證明釘距、載重、跨距或固定強度。
```

全長逐側（PR5）、足跡聯集是把 Q39 變成確定 oracle 的精確化；r1 依主迴圈裁決照採。

### R44 來源網格重算與值快照

```text
鋪排來源主格依 D43 在完成面框架求兩軸及交丁段座標，再映射到板背框架（u 不變，v_d=s·v）。
```

### R45 建議、預覽與建立

```text
輸入依 D45 明選。主支軸 = 所選 primary 縫線的走向；與面上既有 primary／boundary 所定的主支軸不一致 → 整批拒絕（D17、I21）。
候選世界依序：
(1) 該試排尚無衍生承載面時，以所選 B 來源為 h 建立之；已有者其 h 須等於 B 的有效值，否則整批拒絕（I53）。
(2) 該面尚無主格時，建立 from-fill 主格，main_along 取主支軸；已有主格而不是本試排的 from-fill → 整批拒絕並說明。
(3) 邊材：對各分量外環上每條 FIXED 衍生邊，與主支軸垂直者產生 boundary 候選，與主支軸平行者產生 primary（邊界主支，I21）候選；
    皆以 at-face 引用該衍生邊鍵、B 向 +N、長度方向取該軸正向、through 取該邊區間低端 +⌊邊長/2⌋。
    已有 coversEdge 的 boundary 覆蓋之垂直邊，或已有 onBoundary 角材之平行邊，不重複產生。
    FREE 邊不產生，並列為「FREE 邊無邊材」。孔環上的邊不產生邊材。
(4) 板縫：在完成面框架把每個有效板縫段（primary 軸與 secondary 軸的縫線；被錯開軸含 band）與 G_角材層 各分量取交集，
    交集中每一個正長度極大區間各產生一個 at-line 候選，through 取該區間映射到板背框架後的低端 +⌊長/2⌋；
    R6 結果（線、band、跨距）相同的候選合併為一。
候選依「(3) boundary → (3) 邊界主支 → (4) primary → (4) secondary」的順序，同類依衍生邊鍵或（軸、k、band）遞增，
逐一以 R6 求值，後者看得到前者；各條結果與不成立的條號逐項列出。
建議不自動補板中間支撐、吊筋或與樓板連接，也不預設通過。
正式建立集合由使用者從候選中明選，在同一 fresh 候選中依同一順序全量驗證；集合有任一違規即整批不提交，不部分提交。
確認成功後一次提交衍生承載面（若新建）、主格（若新建）與一般 D7 角材；Undo／Redo 恢復整個同一步。
```

原 R45「建議不足不自動補主骨、邊界材或中間支撐」中的「邊界材」依 B4 刪除；「主骨」依 E1 說明改寫為「主支承載判定」不在本層。
〔P6〕順序、through 取值、交集分段、去重與自動建立主格，都是為了讓同一輸入只有一個候選集合；沒有這些規定，R6 的「多段無選擇器 → 拒絕」與「同線重複 → I11 碰撞」會讓結果取決於實作。

物理對照：沿牆的 FIXED 邊得到壁邊材（垂直主支軸者是 boundary、平行者是邊界主支），主支在兩端頂到邊界材側面；
穿過房間的樑切出的外環邊同樣得到邊材，Q47 例「角材在樑兩側停住」因此成立，而不是被 I19 拒絕。

**R2-S1 的修正理由**：有效板縫段是面材層的結果，角材卻放在角材層的衍生面上。Q47 的 248 型（面材從樑下通過、角材層遇樑）時，
面材層的縫段整段跨過樑帶，衍生面卻在樑帶處斷開；r1「每段一個候選、through 取段中點」會讓中點落在樑帶上的那段失敗，另一側完全沒有候選。
r2 先把縫段與 G_角材層 各分量取交集，每個正長度極大區間各給一個候選，樑兩側因此各有一支；PF20 是對應牙齒。
