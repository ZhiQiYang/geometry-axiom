# 工程規格正式整合：公理修改提案

日期：2026-09-28。狀態：**使用者已核准，條文採納、正式整合與本輪驗收完成。** 完整畫布回歸 1027 通過、0 失敗；驗收證據與第一版限制見 `geometry-web/docs/PROJECT-AUDIT-20260928.md`。

本提案補上 `geometry-web/docs/ENGINEERING-SPEC-PLAN.md` F01–F12 的正式整合缺口。提案時工程規格是獨立原型，正式 Canvas 的網格及角材沒有材料版本引用。以下是使用者已核准採納的 `公理層.md` 具體修改；唯一 SSOT 已更新，正典及見證由既有管線同步，不新增第二份閱讀器。

## 使用者會得到的操作

在正式面的「網格」設定中進入工程規格，編輯面材尺寸（工作預設 915 × 1830 × 6 mm，可改 910 × 1820、9 mm 或自訂）、選擇長寬方向、明設縫寬與起算點，預覽後建立網格。材料與做法保存於同一份 `.gcanvas`，重開後仍可查看來源、另存新版、選擇更新指定面；既有角材只有經明選綁定才套用截面，角色與位置引用保持。

材料厚度是型錄資料，不會因此產生板材實體。角材尺寸缺漏保持未設定；不猜品牌、型號、截面或支撐條件。

### 5. 新增 D26–D28：材料、做法與套用

插入定義節末尾、第二節之前：

```diff
+ **D26 材料版本（MaterialVersion；engineering-spec/1）**：由穩定 id、正整數版本、內容指紋、
+ 名稱、種類與具型別資料構成。種類為 panel 或 timber；panel 必有正整數 mm 的 width / length
+ 及可選的正十進位 mm thickness；未指定厚度明寫未設定，不阻擋只使用長寬的排格。
+ timber 必有正整數 mm 的 A / B。參與幾何的數值遵守 D1。
+ thickness 以十進位字串精確保存，僅為型錄資料；不得靜默取整或因此宣稱支援小數幾何。
+ 可另存品牌、型號、來源備註；缺值保持缺值，不猜測。名稱不是身分，同名不同 id 可並存。
+ 已發布版本不可改寫，改內容建立新版本；封存不使既有引用失效。未發布草稿不是可引用版本。
+ 指紋由有版本的確定序列化規則對完整發布內容（排除指紋本身）計算，匯入須重算；不能僅信外來指紋。
+
+ **D27 工程做法版本（MethodVersion；engineering-spec/1）**：由穩定 id、正整數版本、內容指紋、
+ 名稱與引用固定材料版本的設定構成。面材可提供 width / length；邊界材、主支、副支各有獨立材料引用，
+ 不以一個選材欄位混用三種角色。可明存整數非負 gap、板材長寬對應 u / v 的排列與主支方向預設。
+ 未指定欄位保持未設定；發布可重用做法不等於它足以建立每種幾何，套用時仍逐欄驗完整性。
+ 材料升版不自動改做法，做法升版不自動改面。已發布做法的不可變、封存及指紋規則同 D26。
+ 支撐限制可作帶來源的備註，不作力學合格聲明；本期不據它自動放置構件或選等分數。
+
+ **D28 面套用與尺寸來源（EngineeringApplication / DimensionSource；engineering-spec/1）**：
+ 每個承載面最多一份有穩定 id 的套用，引用一個固定做法版本，並保存明選的面軸排列、
+ 面覆寫、建立起點的選項、主支方向預設及明確綁定清單。更換做法是重宣告，不另留兩份互相競爭的套用。
+ 已建主格的具體 anchor 只存在 D10a 的主格定義中；套用的起點選項只供新建時取值，
+ 明選更新起點時修改同一主格 anchor，不在套用保存另一個可獨立變動的有效起算值。
+ 主格 panel / gap 及角材 A / B 的來源各為：既有直接整數、D6b 名稱、D26 固定版本欄位，
+ 或本承載面套用的具名欄位。來源含型別、完整 id / 版本 / 欄位；不以名稱或目前列表順序配對。
+ 來源種類為材料版本引用時，格線 panel 只能接面材 width 或 length，角材 A / B 只能接 timber 的相應截面欄位。
+ gap 使用明設縫寬；直接整數、D6b 及覆寫按目標欄位驗值，不受上述材料引用型別限制。
+ 沿用套用的欄位依序求值：明示物件覆寫 → 明示本面覆寫 → 指定做法版本的設定 →
+ 該設定明指的材料版本欄位。這是同一來源路徑的查找，不把其他未選材料當成備援。
+ 覆寫只准明定欄位；覆寫是附屬物件／面與欄位身分的定義，可移除以恢復沿用，仍須预覽重驗。
+ 首版面覆寫限 gap、width / length 軸向對應、三角色 A / B 及主支方向預設；
+ 物件覆寫限已綁定主格各軸 panel / gap 或已綁定角材 A / B。幾何值仍為有意義的具名欄位，
+ 不以隱藏全域預設補缺。具體起算點是單獨的明示設定，依 D10a 保持。
+ 套用時明選建立／更新哪個主格、綁定哪些已放角材，或只提供未來新建預設。
+ 未選角材不自動綁定、不改角色；主支方向預設更新不追改既有角色。被既有引用連帶影響者仍須重算與列出。
+ 角材綁定保存所選的 boundary / primary / secondary 材料槽位；若與既有角色不符，拒絕並請使用者另作明確處理。
+ custom 角色本期不綁定上述三槽位；可保留直接截面或明選相容材料版本欄位，不因此自動改角色。
```

## 實作邊界與驗收

- 採用新能力 `engineering-spec/1`；核心場景保存協定及 `.gcanvas` 新版在能力協商後啟用。舊格式仍沿原路重放。新格式不能被舊版服務假成功接收。
- 發布內容的標準化、id / 版本、整包預覽 API、錯誤碼與測試夾具須先在實作設計中固定；指紋使用 SHA-256，排除衍生幾何與 UI 草稿。不得邊寫多套不同的序列化規則。
- 起算點／方向在套用面上明示，縫寬不可隱含補 0；空白顯示未設定。材料915 × 1830 × 6只作可見工作預設，不擅改已存在的專案。
- 正式工程規格入口放在目前面及檔案選單，與既有網格編輯器共用同一來源；不另開一個示意世界取代實際工程。
- 驗收以 PLAN 的 A01–A16 為最低要求：有效與非法資料、真來源重算、覆寫／恢復、新舊版隔離、子格／角材依賴保護、多面失敗整批不變、預覽過期、容量、離線保存重開、匯入衝突、舊工程及窄版操作。
- 新增見證與核心／bridge／保存契約測試、正式 Canvas 真瀏覽器流程；同步唯一正典並跑三道重建與檢查。任何未通過項明列，不以原型測試冒充正式驗收。

## 不夾帶的後續功能

本次不擴充 SERIES 任意引用式、相位／交丁、多格或巢狀子格、自動骨架、板材實體與裁切清單、採購、力學計算、已保存空間模型自動跟隨來源。這些若納入需有各自規格與驗收；不從「全部補齊」推定未定幾何規則。
