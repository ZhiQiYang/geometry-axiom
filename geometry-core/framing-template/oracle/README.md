# 下角材幾何 oracle(平釘天花,第一版)

這是下角材模式(#205、#221)的**可執行幾何參考**。規則不再只靠文字描述:每一支角材的座標由 `framing_oracle.py` 算出;任何實作(核心、模板、介面,不論哪個 AI 寫的)都要對同樣的房間與參數,逐支產生相同的角材,不同就算錯。

## 物理目標(使用者 2026-10-15 講明,見決策佇列補登第 16 項)

| 編號 | 目標 | 程式怎麼做 | 自動檢查 |
|---|---|---|---|
| G1 | 面材每條邊都有支撐 | 板縫下放主支、板端縫下放副支、RC 邊放邊界角材 | C3:每條面材邊內側 X mm 的帶子都在角材上 |
| G2 | 副支間距不超過上限 M,各格盡量一致 | 每格 n=⌈L/M⌉、m=⌈L/n⌉,從板端縫起算,餘數放最後一格;沒有板端縫時從起鋪牆起算 | C4:角材之間的空檔 ≤ M−w |
| G3 | 主支整支連續 | 主支線穿過 RC 又回到室內(柱、凸出)就判排板衝突 | C5:每條縫恰好一支主支 |
| G4 | RC 邊界都有角材,端面只頂角材 | RC 邊放角材;與主支平行的 RC 面角材沿線延伸到兩端牆 | C6:主支與副支的兩端都頂在角材上 |
| G5 | 不碰撞、不入 RC | 任何正面積重疊都判排板衝突 | C1、C2 |
| G6 | 從起鋪角整片鋪,只在對牆收邊,不置中 | 縫距 = 板寬+縫 | — |
| G7 | 最後一條縫太靠近對牆時往內挪 | d > D−1.5w 時挪到 ⌊D−1.5w⌋,留約 40 mm 收邊板;第一條縫也一樣 | C1(不挪就碰撞) |

不處理:樑高度、交丁、角材怎麼固定(與幾何無關)。

## 檔案

- `framing_oracle.py`:建構與檢查。建構時遇到碰撞,就把該排法判成「衝突」並寫明原因;檢查與建構分開實作,檢查失敗代表程式本身有錯。
- `rooms.json`:F1–F5 五個房間與參數(915×1830 板、縫 2、角材寬 27、上限 367、承接 8)。
- `selftest.py`:
  1. 六個突變(拿掉挪縫、格數無條件捨去、少一支副支、柱邊不放角材、主支偏 15 mm、允許主支被切斷),各自都必須被對應的檢查抓到。
  2. 矩形房寬 300–4000、深 300–6000 逐 mm 掃描(18,804 案),全部可施工且通過全部檢查。
- `render.py`:畫成 HTML(每個房間 8 種起鋪角與板長方向)。

## 執行

```
python selftest.py
python render.py rooms.json framing-oracle.html
python framing_oracle.py rooms.json > framing-oracle.json
```
