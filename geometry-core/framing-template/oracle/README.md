# 下角材幾何 oracle(平釘天花,第一版)

這是下角材模式(#205、#221)的**可執行幾何參考**,由 Claude 依使用者講明的物理目標推演並寫成程式。規則不再只靠文字描述:每一支角材的座標由 `framing_oracle.py` 算出。
- 實作(核心、模板、介面,不論哪個 AI 寫的)對 `rooms.json` 的房間與參數,要逐支產生與 `oracle-golden.json` 相同的角材。
- 8 種排法的「可施工/衝突」判定也要一致。

## 依據與授權

- 物理目標:使用者 2026-10-15 講明的原則,原話見 `決策佇列.md`「2026-10-12～15 使用者後續拍板」第 16 項。
- 同一處也記載使用者的要求:這類細節由協調 agent 依物理目標自行推導,不再反覆詢問使用者。
- `PROPOSAL.md` 原本列為「待使用者決定」的幾何題(窄收邊挪縫、沒有板端縫的錨點、第一條縫挪動、凹口主支),依此改為由本 oracle 推出,現行答案見 PROPOSAL §2.0「現行規則」。
- 存檔表示法等不影響幾何的題目,仍屬實作細節。

**凹角處的表示法(2026-10-16 P-145)**:
- 原本〈與主支平行的 RC 面一律沿線延伸到兩端牆〉,在外牆凹角處會穿過凹角。原生核心對這種排法一律拒絕:沿牆料超出它貼的外牆,報 `V_EXTENSION`;另一面的邊界材端面頂到它,報 `V_CUT_PRIORITY`。使用者的 F1 客廳(L 形)與 F2 主臥(壁柱)都受影響。探針見 #240。
- 核心 I22 接受的唯一排法(I19 的部分見下面 2026-10-18 補正):沿牆料停在牆端;凹角另一面的邊界材越過凹角延伸,停在路上第一支角材的側面;沿牆料的端面頂在這段延伸上。核心 I22 明定延伸段的端面「可以頂任何優先級的側面」,所以停在主支、沿牆料或另一支邊界材(例如壁龕口兩側的牆段端對端接起來)都合法;R19(e) 的「停在長主支側面」是其中一例,不是唯一。C8 只要求延伸段端面頂到角材或牆,而延伸段不能穿過角材(C1),所以停的必然是路上第一支。
