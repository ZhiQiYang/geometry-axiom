# K2a 第 2 輪審查要點（原樣）

> 結論：須先改。共 6 項，沒有阻擋項。審查員說改完只需核對這 6 處，不必再做全面審查。
> 以下正文照收，不改寫。

- **S1:第 1 輪的 F3(孤兒判定)在來源引用上重現**
  - pin 只比對 id 加內容指紋(`grid-system-workspace.js:27、30-36`)。系統、配置、參數卡的 id 都是「現有最大值 + 1」(`web_bridge.c:391-407、484-491`),刪掉最大號之後,同一個號碼會再被配出來。
  - 裁決:
    - 「曾經缺失 → 永久」這條規則擴大到每一個來源引用。
    - 缺失過的引用只能明選另一個物件來替換,不能用同一個 id 重新取得。
    - 補一條 M14 的來源版驗收。
- **S2:第 1 輪的 F6 只修了一半,原生的參考預覽根本不輸出新建的角材**
  - 證據:`reference_bridge.inc:50-52` 的註解寫明只保留 before;`:96` 呼叫 `json_candidate_timbers(…,false)`。
  - 裁決:
    - B8 的受影響檔案加上 `geometry-web/reference_bridge.inc`,讓預覽包含新建列,或加一個 change 欄位。
    - BR16 要斷言新建列確實來自原生預覽。
- **S3:R⟨K2a-2⟩ 的「實例整塊求值、不與外部角材交錯」和 I9/R6 的放置順序語意衝突**
  - 原生的實際行為:新建的角材用 `++next_order` 排到最後(`assembly_generation.inc:77-78、:115`);`reference_eval_timber` 會先求值同一面上順序較早的料。
  - 裁決:
    - 刪掉「整塊求值」與「不交錯」的寫法。
    - 明寫新建的 owned 角材接在 World 末端,主支在前、副支在後。
    - SELF_SUPPORT 的依賴閉包只算兩種:明示的引用,以及實際被選為端面的擋面。
- **S4:孤兒的復原有破口**
  - 前端歷史上限是 32 筆(`project-store.js:719-720、755-756`)。超出這個窗之後,復原走「只復原核心」的退路,而這條退路會保留現有的附件(`:862-887`)。
  - 裁決:加一句「前端歷史窗外的核心復原,不解除孤兒狀態」。
- **S5:舊介面會讓孤兒靜默復活**

  - 裁決:A4 的接受條件加上「且該份不是孤兒」。
- **S6:能力宣告互斥**
  - `project-store.js:283-284` 拒絕同時宣告 `grid-editor-draft/1` 與 `/2`,數量上限是登記表筆數減一;`/2` 又綁在第 13 版格式家族上(`:322-324`)。
  - 裁決:A7 的改動清單列入這兩處。
