## 獨立審查修正

- 殼引用 carrier 與朝向，區分材料外法向及空腔外法向。
- 正交布林可有同一材料分量的外殼＋內腔殼。
- 同根中仅共邊／點的體積分量不共用拓撲頂點。
- 固定標準切分含擠出後全部世界邊界，不能只看原始局部輪廓。
- EMPTY 可再次參與布林；A\A=EMPTY 與依賴成環分開。
- partial 以根為原子，UNSUPPORTED 與 INVALID 不可降級混過。
- KEEP 只共享切分，不共享消面；相交物件身分與完整面保留。
- 來源特徵、路徑、排序、必填體積／null 與 JSON 正規化固定，避免不同合法編碼產生不同標準摘要。
- 殼面使用必填 purpose，顯式區分 boundary 與 calculation-cap；計算封口可追溯，不能冒充 RC 牆體。
