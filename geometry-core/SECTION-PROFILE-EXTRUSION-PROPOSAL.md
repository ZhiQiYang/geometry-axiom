4. 角材**可以貼邊**、**可以旋轉 90 度**；角材剖面**放在輪廓外就與斷面衝突**（使用者認為這規則很單純）。
5. 產出：可推演 3D 模型並預覽，與「空間定義後推演 3D 模型」的預覽功能相似。
6. **拉伸方向**：「人看向螢幕，人往螢幕的方向拉伸」。斷面畫在螢幕平面上，拉伸方向是從觀看者往螢幕裡面（遠離觀看者）。座標慣例的形式化見 §1.3。

9. **斷面構件（角材剖面）在斷面內的位置以直接座標填寫**，不使用引用式定位（2026-10-08 使用者：「角材直接填座標就好」；即 Q38b）。

## 1. 物理模型

### 1.1 這個物件是什麼

以間接照明燈槽為例：沿牆或天花板邊緣跑一段固定的 L 形剖面。施工上，骨架由數支**同向的長料**構成，每支料的長軸都沿燈槽走向；在任一垂直於走向的切面上，看到的是 L 形輪廓與輪廓內幾個角材的矩形截面。這正是「斷面 × 直線拉伸」：

- **斷面輪廓**就是這個斷面本身的形狀（🔒3：特定幾何形狀的斷面，不是完成面）。斷面內的一切都在這個形狀內；構件剖面若能超出形狀，這個斷面就不是這個形狀了。
- **角材剖面**是輪廓內的矩形（例如 27×33）。拉伸後，每個矩形成為長度 L、長軸沿拉伸方向的長料。
- 與現有面內工作區（D4/D7/R6）的根本差別：面內角材的長軸**在面內**，長度由兩端擋面推導；這裡角材長軸**垂直於斷面**，長度就是拉伸長度 L，斷面內沒有「兩端」。

### 1.2 每條規則的物理理由（已用「先模擬、再自我反駁」檢查）

| 規則 | 依據（物理理由，或「定義推論」） | 自我反駁與結論 |
|---|---|---|
| 構件剖面在形狀內（🔒4） | **定義推論**：斷面即此輪廓形狀（P-S1），斷面內的構件剖面必在形狀內。超出形狀的輸入與定義矛盾，不是另一條規則。 | 不需物理理由，也不是選項。 |
| 貼邊允許（🔒4） | **定義推論**：形狀是閉區域，邊界屬於形狀，所以邊界接觸屬於在內。 | 實務上角材通常就貼著輪廓邊放，與此一致；與 I5（閉區域包含）同義。 |
| 只可旋轉 90°（🔒4） | 角材截面是矩形，選「A 朝哪邊」決定抗彎方向（抗彎吃受力方向的高度）；這是實際會做的選擇。任意角度斜放在正交燈槽裡幾乎沒有用途。 | 反駁：只給 0°/90° 會不會漏掉 180°/270°？矩形截面轉 180° 後佔用的矩形相同，只差局部面的編號；**放置幾何上只有兩種方位**。任意角度會產生非整數頂點，違反 D1 與 R27 的正交前提。**成立**。 |
| 剖面互不重疊（🔒7） | 兩支實心料不能占同一空間（守恆）；拉伸後兩支長料若截面重疊，就是整段 L 都互相穿過。 | 反駁：貼齊要禁止嗎？不要——兩支料面對面釘合（例如 L 形轉角兩支並排）是常見做法，交集面積為 0。**成立**，定義為「正面積交集」。 |
| 拉伸方向垂直於斷面 | **定義推論**：斷面就是垂直於長軸的切面；若拉伸方向斜於斷面，垂直長軸的切面就不是這個形狀，畫出來的也就不是斷面。 | 斜切料端屬於「轉角斜接」，🔒1 已排除。拉伸軸 = 斷面法向。 |
| 鏡射不需要另設旗標 | 拉伸體沿長軸對稱：把拉伸方向反過來，並把原點移到另一端，得到的長料集合，等於斷面在平面內左右鏡射。 | 推論：同一斷面用在房間對側的牆時，靠「反轉拉伸方向」就夠，不需要鏡射參數。§5.4 的簡易版即以此決定牆在左或右。 |

標為「定義推論」的列由定義直接決定，不列為選項或待確認事項。不在此模擬內、因此不由本提案推論的事：燈槽的懸臂強度、固定件、料長續接、板材厚度。這些需要實務查證，本提案不給數值（見 §7）。

### 1.3 座標慣例（由 🔒6 + D1 推出）

- 斷面局部座標 `(u, v)`，整數 mm（D1）。**u 向右、v 向下**，與現有局部介面慣例一致（D30「局部介面沿用 u 向右、v 向下」）。
- 拉伸軸 `w = u × v`（右手系，D1/D2）。螢幕上 x 向右、y 向下時，右手系的第三軸指向**螢幕裡面**，正好就是 🔒6 說的「人往螢幕的方向拉伸」。所以拉伸佔 `0 ≤ w ≤ L`，沿 **+w**。
- 這個慣例沒有自由度：只要接受「u 向右」，右手系加上「往螢幕裡拉」就迫使 v 向下。若改成 v 向上，要往螢幕裡拉就必須用左手系，違反 D1。
- 與空間座標的對應：定位時給承載框架 O/U/V/N（D2，`U×V=N`），世界點 = `O + u·U + v·V + w·N`，拉伸沿 +N。世界 +Z 朝上（D25）。若要讓「圖面上方」對應「世界上方」，就要 **V = −Z**（v 向下 ↔ 世界向下）；這是簡易版的預設（§5.2）。
- 驗算（下文 AC09 會用）：拉伸軸 N=+Y、V=−Z ⇒ `U = V×N = (−Z)×(+Y) = +X`。觀看者面向 +Y、頭朝 +Z 時，右手邊是 +X——圖面的右就是世界的右，與「人看向螢幕」一致。

## 2. 草案條文

### 一、定義

**P-S1 斷面（SectionProfile）**：World 獨立物件，保存 id、名稱（非身分、可重名）與局部 2D 外輪廓。
輪廓頂點為 (u,v) 整數 mm，正交、閉合（合法性見 P-I1）。不含世界位置、不含拉伸長度、不含 D3 的 fixity、分類或柱樑投影。
座標慣例：u 向右、v 向下、拉伸軸 w = u×v 指向畫面內側（🔒6）。
**斷面即此輪廓形狀；斷面內的構件剖面必在形狀內（邊界接觸屬於在內）。** 這是定義本身，不是額外規則。設 F 為輪廓圍成的閉區域（含邊界）。
斷面不是完成面（🔒3），也不是材料；它本身不產生材料體積。

**P-S2 斷面構件（ProfileMember）**：屬於一個斷面，保存 id、斷面 id、截面 A×B、方位與左上角座標 (u0, v0)。
構件剖面是所屬斷面內的矩形，依 P-S1 必在 F 內（邊界接觸屬於在內）。
方位只有兩值：`A 沿 u`（剖面矩形寬 A、高 B）或 `A 沿 v`（寬 B、高 A）——即 🔒4 的「旋轉 90 度」。
A / B 的來源沿用 D7 / D28 的既有型別（直接整數、D6b、D26 timber 欄位、D31 尺寸欄位）；旋轉不交換 A/B 的身分，只改它們對應的軸，因此材料引用不受旋轉影響。
**長度不宣告**：構件長度 = 所屬拉伸件的 L（P-S3）。這與 D7「長度是環境推導的結果」同一原則，但推導來源是拉伸件，不是 R6 擋面。
構件不是 D7 角材，不取得角色、裁切優先級或擋面身分（型別取捨見 Q38a）。
**位置以直接座標填寫（🔒9）**：保存剖面矩形**左上角**（u 最小、v 最小的角點）在斷面局部座標中的 `(u0, v0)`，單位 mm，u 向右、v 向下（§1.3）。剖面矩形 `R = [u0, u0+寬] × [v0, v0+高]`。不保存對輪廓邊或其他構件的引用，也不收具名位移。
選左上角而不選中心的理由：(1) 角點座標加上 A、B 一定是整數；以中心為參考點時，27 這類奇數寬會落在半 mm，需要另定取整（I13 的「多的 1mm 在 + 側」）。(2) 貼邊最常見，以角點填寫時，貼邊直接就是輪廓頂點座標（例如貼左上就填 (0,0)）。(3) 與 D3 輪廓頂點同一種座標，使用者在同一張圖上讀得出來。這是寫法建議，不是新拍板題。
旋轉 90°（方位 `A 沿 v`）只改寬高，不改參考點：`(u0, v0)` 仍是**旋轉後**占用矩形的左上角，寬 = B、高 = A。介面若以中心為軸旋轉，必須重算並寫入新的左上角；核心不保存「旋轉中心」。

**P-S3 拉伸件（ProfileRun）**：World 獨立物件，保存 id、斷面 id、長度 L 的來源，以及可省略的定位（P-S4）。
第一版只有直線拉伸（🔒1）。局部材料集合：每個構件 m 為 `S_m = {(u,v,w) | (u,v)∈R_m, 0≤w≤L}`。
斷面包絡 `E = {(u,v,w) | (u,v)∈F, 0≤w≤L}`（F 為輪廓閉區域）只是參考幾何，不計材料量。
同一斷面可被多條拉伸件引用（例如房間四邊各一段燈槽；取捨見 Q38i）。

**P-S4 拉伸件定位（ProfilePlacement）**：省略 = 未定位（🔒2）。
進階表示：原點 O（斷面局部 (0,0) 的世界位置）與 D2 框架軸 U、V、N，`U×V=N`，拉伸沿 +N。
簡易表示：宿主承載面、宿主面內的拉伸方向、宿主面上的基準點偏移、圖面上方方向；它求值後**必定**得到一組進階表示（P-R3），所以簡易是進階的子集（🔒8）。參數表見 §5。

**P-S5 未定位拉伸件**：合法物件。只在自己的局部座標 (u,v,w) 預覽，不宣稱世界位置，不出現在任何空間的 3D 結果中（Q38f）。之後加上定位 = 重宣告，走 I8 交易。

### 二、不變量

**P-I1 斷面輪廓合法**：同 I2 對外輪廓的要求（≥4 頂點、每邊軸平行、閉合、非自交、無零長邊）；頂點符合 D1。第一版不收內孔（Q38g）。
**P-I2 構件剖面 ⊆ F（由 P-S1 定義直接推出）**：構件剖面落在形狀外，與斷面定義矛盾，該輸入不成立而被拒絕；這不是獨立的衝突規則。判定為 R_m ⊆ F（P-R1）。診斷碼建議 `V_PROFILE_OUTSIDE`，指名構件與超出的範圍。
**P-I3 構件互不重疊（🔒7）**：同一斷面任兩構件的 R_i ∩ R_j 面積 > 0 即拒絕；交集只有邊或點（面積 = 0）合法。定義與 I11「零面積 = 合法接觸」相同。診斷碼建議 `V_PROFILE_OVERLAP`，指名兩構件與交集矩形。
**P-I4 截面、方位與座標**：A、B 求值後為正整數 mm（D1）；方位只能是兩值之一，其他角度拒絕。
`u0`、`v0` 為整數 mm，可為負（輪廓不必以 (0,0) 為角），並受 D1 範圍限制；小數、分數或超界輸入一律拒絕，不取整、不夾到範圍內。`u0+寬`、`v0+高` 也須在 D1 範圍內。
**P-I5 長度（定義推論）**：拉伸成長料，L 必須大於 0；D1 全整數 mm，所以 L 為正整數 mm，下限 1。0、負數、非整數均拒絕，不取整（同 D1 對參數來源的紀律）。拉伸件所有生成頂點須在 D1 範圍。
**P-I6 定位合法**：U、V、N ∈ {±X, ±Y, ±Z}，兩兩正交且 `U×V=N`（I1）；O 與所有世界頂點符合 D1。簡易表示的宿主必須存在且是已放置的承載面；拉伸方向必須是宿主面內的軸；圖面上方方向必須垂直於拉伸方向，無法套用預設時必須明選，不猜（R3）。
**P-I7 交易與依賴**：建立、修改、刪除斷面／構件／拉伸件／定位，都走 I8 候選交易，重驗 P-I1–P-I6 的完整依賴閉包，全過才提交，否則整筆回滾。
**修改斷面輪廓時，構件座標不跟著動（🔒9 的後果）**：候選世界以原 `(u0, v0)` 對新輪廓重驗 P-I2／P-I3。
不在新輪廓內的構件（與 P-S1 矛盾）以及重疊的構件，在影響預覽中標成衝突，列出構件、原矩形、超出或重疊的範圍與條號；有任何衝突 → 不得提交，World 不變。
不自動搬移、裁切、刪除構件，也不幫構件「保持貼邊」。使用者要嘛改構件座標，要嘛改輪廓，要嘛在**同一筆**交易中一併修改，再重新預覽。
輪廓改了、構件仍合法時照常提交；預覽仍列出「原本貼某邊、現在不再貼邊」的構件，作為提醒，不是違規。
會改變世界位置的操作（宿主承載面、L 或截面的具名來源）比照 I8a 先預覽：逐項列出受影響的構件與拉伸件、新舊剖面矩形、新舊世界範圍，以及每項違規的條號與預期值/實際值。
刪除仍被構件或拉伸件引用的斷面、或仍被簡易定位引用的宿主承載面 → 拒絕，除非同一顯式交易一併處理依賴者。
**P-I8 隔離**：斷面構件不進入 D11 擋面、I11 同面碰撞、I18–I22 角色規則，也不被 D7 角材的錨法引用。第一版拉伸件之間、拉伸件與空間、柱樑、面內角材之間**不做碰撞檢查**（與 I30「不擴大既有碰撞檢查域」同一態度）；畫面也不得宣稱已檢查。
**P-I9 能力與保存**：新增能力 `section-profile/1`，依 I32 宣告。場景及完整專案須保存全部斷面、構件、拉伸件與定位，包括未定位的拉伸件與零構件的斷面；未知能力拒絕，不降級。

### 三、推演規則

**P-R1 剖面矩形求值**：讀方位得寬、高（`A 沿 u`：寬 A、高 B；`A 沿 v`：寬 B、高 A）→ 取保存的 `(u0, v0)` → `R = [u0, u0+寬] × [v0, v0+高]` → 驗 P-I2（R ⊆ F，閉區域）與 P-I3。設 `u1 = u0+寬`、`v1 = v0+高`，兩構件 i、j 的交集面積 > 0 ⇔ `max(u0ᵢ,u0ⱼ) < min(u1ᵢ,u1ⱼ)` 且 `max(v0ᵢ,v0ⱼ) < min(v1ᵢ,v1ⱼ)`；任一向取等號就是貼齊（面積 0，合法）。
全部是整數加減與比較，不需取整；奇數尺寸不造成半 mm。
**P-R2 拉伸求值**：每個構件產生一個長方體，局部範圍 `R_m × [0, L]`；有定位時以 `O + u·U + v·V + w·N` 轉成世界座標。斷面包絡依 R24 同法產生參考棱柱；L 形不得換成外接矩形。構件體積精確等於 `A·B·L`。
**P-R3 簡易 → 進階**：給宿主承載面 H（frame o_H、U_H、V_H、N_H）、拉伸方向 d ∈ {±U_H, ±V_H}、基準點 (p, q)、圖面上方方向 up：
N = d；V = −up；U = V × N；O = o_H + p·U_H + q·V_H。結果須通過 P-I6。這是唯一的求值路徑，簡易表示不另存一份可獨立變動的 O/U/V/N（D9）。
**P-R4 預覽輸出**：沿用建模請求（D24 role=geometry、target=solid-set）的形式；每個構件一個物件，身分為（拉伸件 id、構件 id），另附包絡物件，標為參考角色、不計材料量。輸出列出構件數、每支 A×B×L、方位與世界範圍（未定位則為局部範圍）。這是核對清單，不是料單。
**P-R5 重算**：L、截面來源、斷面輪廓或宿主承載面改變時，依 P-I7 重算全部依賴的拉伸件，不凍結舊幾何（與 2026-09-18 R6(e)「凍結反轉為重算」同軌）。
構件的 `(u0, v0)` 是直接座標，不屬於重算對象（🔒9）：輪廓改變只重驗、不改座標；截面 A、B 改變時，以同一左上角重算 R（矩形向右、向下伸縮），若因此落到形狀外（與 P-S1 矛盾）或與其他構件重疊，依 P-I7 擋下。

### 四、不在本層（本提案明確不做）

- 折線或曲線路徑；轉角斜接、搭接、兩段燈槽在轉角的交接（🔒1）。
- 料長續接：L 大於市售料長時，仍推導成一支邏輯長料，不切段、不排接頭（公理層「四、不在本層」已排除料長續接）。
- 料單、裁切清單、數量彙總。
- 固定件、吊筋、施工順序、載重與懸臂強度。
- 面材、板厚、完成面（🔒3；公理層第四節本來就排除完成面）。
- 拉伸件之間及與空間、柱樑、面內角材之間的碰撞（P-I8）。
- 任意角度的方向或斷面內旋轉（Q38d 若採建議）；斷面內孔（Q38g 若採建議）。

| 層 | 需要新增 | 理由 |

| C 核心 World（`current_geometry.c` 及 include） | SectionProfile、ProfileMember、ProfileRun（含定位）三種物件與各自的 id 空間及容量；P-I1–P-I7 的驗證；DSL 讀寫、dump、重放；I8 候選交易與 P-I7 的影響預覽 | 定義是 SSOT（R4、D9）；驗證不能只在前端做 |

## 4. 待拍板題目

🔒 第 6–9 條已拍板：拉伸方向、重疊定義、「簡易／進階兩版都要有、簡易 ⊂ 進階」的框架，以及構件以直接座標定位，都不再列為題目。下面是仍需使用者決定的部分。

### Q38a：構件的型別
- (A) **新型別 ProfileMember**（建議）：只有截面、方位與位置，長度取自 L。
- (B) 擴充 D7 角材，加一種「沿斷面法向」的放法。
- 建議 A。理由：D7 角材整套規則（承載面、at-line/at-face、兩端擋面、角色與優先級 I18–I22）都建立在「長度在面內」上；斷面構件沒有擋面也沒有面內兩端，硬套只會產生大量「不適用」的例外。代價：現有角材清單（TIMBER-SCHEDULE）不會自動含斷面構件，日後做料單時要明確合併。

### Q38b：構件在斷面內怎麼定位 —— 🔒 已拍板（2026-10-08 使用者：角材直接填座標）
- 見 §0 第 9 條與 P-S2／P-I4／P-I7／P-R1／P-R5。原本「引用式」的建議已撤回。
- 與公理層既有原則的關係：D6a「禁止來歷不明的數字」只管參考線位置引用式，I12 只管 D7 角材錨法；斷面構件是新型別（Q38a），使用者明示採直接座標，不構成違反，但精神上的差異記在 §8 R2。

### Q38c：定位參數表（§5）是否採用
- 建議採用 §5 的簡易版與進階版兩張表；🔒8 的框架已鎖，這題只確認具體參數、預設值與衝突處理。

### Q38d：方向只允許軸對齊，還是允許任意方向
- (A) **只軸對齊**（建議）：N 為 ±X/±Y/±Z 之一，斷面平面內只能轉 90° 的倍數。
- (B) 任意方向向量或任意角度。
- 建議 A。理由：D1 全整數、D2 框架軸為單位整數向量、R27 正交布林只支援軸對齊；任意角度會產生非整數頂點，需要新的精確幾何層。燈槽在正交房間中沿牆走，軸對齊已涵蓋主要用途。

### Q38e：簡易版的宿主引用是即時引用，還是建立時取值
- (A) **即時引用**（建議）：保存宿主承載面 id，宿主移動時依 P-R3 重算並走 P-I7 預覽。
- (B) 建立時取值：UI 用宿主算出 O/U/V/N 後只存進階表示，另存「來源宿主」作備註。
- 建議 A。理由：符合 D9「只存定義」以及 2026-09-18「凍結反轉為重算」的既有決定。另外，宿主範圍建議限 World 中已放置的承載面（D4，含 D5 空間成員）；「已建立空間模型」是 .gcanvas 中的快照（SPACE-MODELING.md），不是 World 定義，只能以 B 的方式取值後轉成進階。

### Q38f：未定位拉伸件的保存與預覽
- 建議：存在 World、隨場景保存；在斷面工作區以局部 (u,v,w) 預覽，標明「未定位」；不出現在任何空間 3D 預覽，也不參與世界座標輸出。理由：🔒2 要求可以未定義；比照 D3 游離面「合法但三視圖不畫」。

### Q38g：斷面輪廓的形狀範圍與最小尺寸
- 建議：只收正交多邊形（I2 外輪廓要求）、第一版不收孔、除 I2「無零長邊」與 D1 之外不加最小尺寸；容許零構件的斷面。理由：燈槽類斷面是實心包絡，構件需要的空間由 P-I2 自然把關；孔的語意（槽口？管線？）尚無實例，等有案例再定。替代：直接重用 D3 的孔規則，代價是要定義「孔是什麼」。

### Q38h：L 的來源與是否設料長上限
- 單位、下限、上限不是題目：L 為正整數 mm、下限 1、上限 D1，是定義推論（P-I5）。
- 建議：來源為直接整數、D6b 或 D31 尺寸欄位（同 D28 的來源型別）；不設與市售料長相關的上限。理由：L 是設計決定，具名來源讓「改它會動到什麼」看得到；料長屬於續接，不在本層。

### Q38i：斷面與拉伸件的關係
- 建議：分成兩種物件，一個斷面可被多條拉伸件引用（各自有 L 與定位）。理由：同一燈槽斷面常用在房間的多面牆上，分開才不必重畫；代價是轉角處的重疊不檢查（P-I8），預覽須標明。替代：一對一，模型較簡單，但重用時要複製斷面。

### Q38j：已定位的拉伸件是否進入空間的 3D 預覽
- 建議：第一版在斷面工作區自己的 3D 預覽中，以世界座標顯示；併入「從面建立空間」的模型，留到下一個切片，比照 GEO-208 的角材「明選納入」流程。理由：空間模型是快照、拉伸件是即時定義，兩者合併要先定義快照語意；不在第一版混用。

### Q38k：UI 入口與 GEO-219 減項
- 建議入口：在既有「建立」選單（`create-menu-entry`，與參數、組構規則同層）加「斷面」一項；3D 預覽重用 `model-viewer.js`，不另做檢視器；操作說明只用首次出現、可關閉的教學卡。
- 建議減項：把檔案選單的「空間模型庫」改成「3D 模型庫」，同一入口列出空間模型與已定位的拉伸件，不另開「斷面庫」——新增一項、合併一項。
- 若使用者不接受這個合併，須另指定減項；依 GEO-219 寫不出減項不得開工。

## 5. 定位參數（🔒8 框架；具體內容待 Q38c）

### 5.1 共同語意

斷面局部 (u,v,w) → 世界：`O + u·U + v·V + w·N`，拉伸佔 w ∈ [0, L]。簡易與進階最後都求成同一組 (O, U, V, N)；兩者只差在**怎麼給**這組值。

### 5.2 簡易版

| 參數 | 意義 | 單位 | 預設 | 合法範圍 | 衝突時 |
|---|---|---|---|---|---|
| 宿主面 host | 燈槽依附的牆或天花板：World 中已放置的承載面 | id | 無，必選 | 存在且已放置的 D4 承載面 | 不存在、未放置 → 拒絕；刪除宿主 → 拒絕（P-I7） |
| 拉伸方向 dir | 沿宿主面的哪個軸走，即「沿那面牆」 | — | +U_H | {+U_H, −U_H, +V_H, −V_H} | 非宿主面內軸 → 拒絕 |
| 基準點 (p, q) | 斷面 (0,0) 落在宿主面上的位置，宿主局部座標 | mm | (0, 0) | 整數；建議要求落在宿主有效範圍閉區域內 | 出範圍 → 拒絕；不自動夾到邊上 |
| 圖面上方 up | 斷面圖「上」對應的世界方向 | — | +Z（dir 為水平時） | 垂直於 dir 的四個軸向之一 | dir 為 ±Z（例如沿牆垂直走）時沒有預設，必須明選；與 dir 平行 → 拒絕 |
| 長度 L | 拉伸長度 | mm | 無，必填 | 見 Q38h | 非正整數或超出 D1 → 拒絕 |

使用提示：斷面圖畫成「牆在左」時，要讓燈槽靠在牆上，就選讓牆落在觀看者左手的 dir（觀看者站在起點，往拉伸方向看）。反方向等於左右鏡射（§1.2）。所以簡易版不需要鏡射參數。

### 5.3 進階版

| 參數 | 意義 | 單位 | 預設 | 合法範圍 | 衝突時 |
|---|---|---|---|---|---|
| 原點 O (x, y, z) | 斷面 (0,0) 在 w=0 處的世界位置 | mm | 由簡易版轉來時為其求值結果，否則必填 | 整數，D1 | 超界 → 拒絕 |
| 拉伸軸 N | 拉伸方向（往畫面內） | — | 由簡易版轉來時沿用 | {±X, ±Y, ±Z}（Q38d 建議） | 非軸向 → 拒絕 |
| 圖面下方 V | 斷面 +v 的世界方向；等同「斷面在平面內的旋轉」 | — | −Z（N 為水平時） | 垂直於 N 的四個軸向之一 | 與 N 平行 → 拒絕；N 為 ±Z 時必須明選 |
| 圖面右方 U | 由 U = V × N 推導，不可直接輸入 | — | 推導 | — | — |
| 長度 L | 同簡易版 | mm | 沿用 | 同 Q38h | 同簡易版 |

斷面在平面內的旋轉以 V 的四個選擇表達（0°/90°/180°/270°）；這與 🔒4「構件可轉 90 度」是不同的東西：前者轉整個斷面，後者轉單一構件。

### 5.4 互轉

- **簡易 → 進階：無損。** P-R3 的求值結果就是進階的四個欄位，世界幾何逐點相同（AC10）。轉換是明確操作：解除宿主引用、改存絕對值，經 P-I7 預覽後提交；之後宿主移動不再帶動此拉伸件——這是刻意的語意改變，預覽必須寫明。
- **進階 → 簡易：有條件。** 使用者必須明選宿主面 H（系統不猜宿主，R3）；僅當 N 是 H 面內的軸、O 落在 H 的平面與有效範圍內、V 等於某個合法的 up 選擇時才可轉換，並反解出 (p, q)。不符合時拒絕，保持進階並列出哪一項不成立。例如原點離開牆面（懸空或內縮）的燈槽，就只能用進階版表示。

現有「空間定義 → 3D 推演預覽」的結構（只摘結構）：
- `geometry-web/space_modeling.py`：把面與選項轉成核心宣告（Declarations 負責 id 分配與容量檢查），組成建模請求，呼叫建模執行器產生並驗證模型套件；`_timbers` 示範「明選根物件、全部完整才成功、不回 partial」。
- `geometry-core/modeling/`：`engine.py` 解析請求與延伸定義、`geometry.py` 產生擠出／實體幾何與正交切分輸出、`__init__.py` 的 `build_package` / `verify_package` 負責套件建立與重算核對。
- `geometry-web/model-viewer.js`：只負責呈現套件的 `derived.objects`，不重建來源幾何。
- `geometry-web/space-workspace.js`：「更新預覽 → 核對摘要 → 勾選確認 → 建立」的流程與過期預覽守門。
- `geometry-web/project-store.js`：`.gcanvas` 保存模型與共用復原歷史。

可重用：
- 3D 檢視器整支重用；顯示開關的模式比照「空間邊界／材料牆／角材結構」。
- 建模套件（D24/D25）、R29 輸出、`verify_package` 的重算核對：拉伸件是新的根物件種類，不是新的輸出格式。
- `geometry.py` 的擠出幾何：每個構件就是「矩形截面擠出 L」，與 D20 / R24 同形；包絡即 L 形截面擠出。
- 預覽 → 確認 → 提交的流程與過期守門（space-workspace），以及 I8a 式影響預覽的列表格式。
- 多邊形繪製（`polydraft.js`）可畫斷面輪廓；I2 與 I5 的判定可重用。

不可直接重用：
- D20 擠出實體需要承載面與兩個規格名，每個構件都建一個承載面會吃掉核心的面容量（目前 16 個），所以不建議用 D20 來實作構件。
- 空間模型是快照、拉伸件是即時定義，兩者的保存語意不同（Q38j）。

## 8. 風險與歧義

- **R1 型別分裂**：斷面構件與 D7 角材是兩種長料；現有角材清單、骨架顯示及日後料單都要明確合併，否則使用者會以為燈槽料「不見了」。
- **R2 自由數字**：構件座標 (u0, v0)（🔒9 使用者已選直接座標）、簡易版的 (p, q) 與進階版的 O 都是直接數字，與 D6a「禁止來歷不明的數字」的精神有張力；D6a／I12 的適用範圍不含本物件，D2 框架原點本來也是直接座標，所以不違反條文。代價：改輪廓時構件不會跟著動（P-I7），貼邊的設計意圖不被保存，只靠預覽的「不再貼邊」提示。日後若要加引用式，屬於新提案，舊座標不自動轉換。
- **R3 宿主刪除**：P-I7 建議拒絕刪除仍被引用的宿主；替代做法是自動轉為進階（快照），但那會默默改變語意，本提案不建議。
- **R4 板厚**：🔒3 說斷面不是完成面，系統不會扣板厚。若使用者把輪廓畫成完成後的外形，貼邊構件會少掉板厚的位置——模型「合法」但與現場不符。教學卡要說明輪廓代表什麼。
- **R5 轉角重疊不檢查**：同一斷面在房間四邊各拉一段時，轉角處會互相穿過，第一版不報錯；預覽必須標示「未檢查拉伸件之間的碰撞」。
- **R6 v 向下的直覺**：由 🔒6 推出的慣例 v 向下，與工程圖「高度向上為正」相反。介面可以把標尺顯示成向上為正，但保存與條文一律是 v 向下；兩者不得混存。
- **R7 未定位物件沒有「上方」**：局部預覽沒有世界 +Z；檢視器預設視角要以 w 軸為準，不能假設 +Z 朝上。
- **R8 單支邏輯長料**：L 超過市售料長時，3D 仍顯示一支連續料；不得把它說成可直接下料。
- **R9 宿主範圍**：簡易版只能依附 World 中的承載面；使用者在「已建立空間」模型上看到的牆，可能在 World 裡沒有對應的承載面（模型是生成快照）。這會讓「貼在某空間的某面牆」在 UI 上找不到宿主，需要 UI 引導或另定快照宿主語意。
- **R10 容量**：C World 是固定容量陣列，三種新物件都要配額；未拍板前不估數字。
