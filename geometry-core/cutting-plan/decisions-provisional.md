# K1 岔路與暫定採用（r1）

- 狀態一律為 **暫定（依 2026-10-09 授權 L）**。須經對抗審查後才寫入 SSOT；使用者可逐條推翻。
- 標「定義推論」的列不是真正的選擇：答案可由定義或物理推出。仍列出，是為了讓審查者看見排除了哪些替代方案、為什麼排除。
- 「如何推翻」一欄寫明推翻時要改的條文、檔案或測試。
- r1 依審查裁決改動的列標「r1」：P5、P12、P14、P15、P20，以及新增的 P29–P36。
