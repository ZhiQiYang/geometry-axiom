# PF-0：空間完成面、鋪排與貼板角材的逐條差異提案

狀態：**可審閱的條文提案，尚未寫入公理或實作產品。** 基準為 `1eb6ccbbef58e4c94c2f3a377db95cfd2dd848e8`。本文件不修改 [公理層](../公理層.md) 或正典閱讀器。

依據是 [#128 正文](https://github.com/ZhiQiYang/geometry-axiom/issues/128)及 [PR129](https://github.com/ZhiQiYang/geometry-axiom/pull/129)／其 [2026-10-05 決策原文](https://github.com/ZhiQiYang/geometry-axiom/blob/1269e6bcc5d6928c6f51da5148a44c89d068cf7d/決策佇列.md)。2026-10-08 唯讀核對時兩處均無追加評論。已採納方向不重問；本次把方向轉成可檢查的定義、交易、引用與退化條件，**新增精確語意仍須逐條審閱採納**。

編號暫接目前最大號 D40／I51／R40，使用 D41–D45／I52–I57／R41–R46；採納前須再次確認未被其他條文占用。`panel-fill/1` 是提議能力名，尚未註冊；不搶先分配 `.gcanvas` 格式號。

## 2. 既有條文的精確修訂

### E1：§四第一、二項改為有限納入

原文：

```text
- 施工面材實體、完成面（FinishSurface）與完成面高程 —— 未來的層。
  D26 可保存面材厚度作為型錄資料，D20 已定義通用擠出厚度；
  兩者都不等於已定義施工面材的層次、完成面或高程依附語意。
- 樑投影的輪廓裁切：依完成面高程決定，本層只存資料不裁切。
```

建議替換為：

```text
- 完成面的位置、方向、輪廓及開口，面材試排與縫位、幾何承接比對、
  以及經明確確認建立的板縫貼板角材，限 D41–D45／I52–I57／R41–R46。
  試排板片是推導結果，不是 D7 角材、施工實體或材料合格證明。
  載重、撓度、固定件、主骨、吊筋、與樓板連接、施工順序及板中間支撐的自動反推仍不在本能力內。
- 完成面指定障礙集合中的 RC 樑，依 R41 對面材層、貼板角材層各自自動裁切。
  既有 D3／D4 的投影、R7–R12 apply-proj 快照與手動流程保持原義；
  不因新增 FinishSurface 自動重算或改寫舊場景。
```

§四斷面拉伸段末句原文「本節第一項『施工面材實體、完成面』仍是未來的層」建議改為：「完成面與試排僅依本節第一項的獨立能力有限納入；不屬於斷面拉伸能力。」其餘斷面排除項維持。

### E2：D26 厚度的適用界線

保留原文「thickness 以十進位字串精確保存，僅為型錄資料；不得靜默取整或因此宣稱支援小數幾何。」在其後新增：

```text
支援 panel-fill/1 的執行器得由 D42 明確引用 panel 固定版本的 thickness，
按 I52 驗證後用於完成面層次；沒有該能力或沒有明確引用時仍只是型錄資料。
本能力的幾何輸出仍受 D1 限制；非整數 mm 厚度不得取整後放行。
```

### E3：D10／D29 增加一種明確來源，不改舊公式

D10 的主格來源說明與 D29 定義各新增以下適用文字：

```text
支援 panel-fill/1 時，可明選 D43 的鋪排來源模式，保存鋪排 id、來源軸與明確排列對應，
不另存可獨立編輯的 panel／gap／anchor／phase 或縫位陣列。
來源移動或更換後依 R44 重算；不得按最近座標改綁失效的線引用。
此模式不改原 LOCAL／SERIES／PANEL_LAYOUT／from-binding 或 legacy-finite 定義，
也不擴大來源子網格對 REPEAT_PANEL／交丁的支援範圍。
```

D10a／D10b 原公式及有限／無限範圍規則不改。新鋪排用同一排板／縫位計算原語；第 R42 條明確區分列舉範圍，避免把無限鋪排的裁切結果冒稱既有有限主格的新語意。

## 3. 新增定義全文

### D41 完成面（FinishSurface）

```text
完成面是獨立的設計表面定義，保存 id、名稱、D3 邊界引用、D2 框架及結構側符號 s∈{−1,+1}。
邊界的外輪廓與孔作為局部有效範圍 F；名稱不是身分。位置及方向由框架明示，沒有高度預設。
完成面局部 w=0，結構側單位向量 n=s·N。它不自動變成 D5／D22 成員，不把畫布位置當空間位置。
另保存明選的 D14 樑引用集合；集合內每支樑依 R41 自動判定，不保存逐樑強制通過／裁切旗標。
未指定的樑不按位置或名稱猜入集合；建立時須可檢視本次納入的障礙及來源。
包樑側面、底面各是另一份完成面，不由本物件自動補齊。
```

障礙採顯式集合是沿 D22「不自動補入附近柱樑」的**提案選擇**，不是把 Q47「自動判斷高度」改成手動裁切。任意斜面不在 D2 的單位整數軸內；本案不偷偷改成浮點框架。

### D42 面材試排（PanelFill）

```text
試排保存 id、完成面 id、D26 panel 固定版本引用、起排點 (a_u,a_v)、長邊沿 u 或 v、
縫寬來源、直排或交丁模式及交丁相位差來源；不保存逐片實體、裁切結果或支撐結論。
板寬、板長及厚度取自同一明選材料版本。起排點在建立／明確移動時具體化，
輪廓改變不自動重置起排點。縫寬與相位差沿 D28／D31 的既有具型別尺寸來源。
直排不含相位差；交丁只有一個被錯開軸與固定相位差，依 D10b 奇數帶加差、偶數帶不加。
排板 lattice 是推導定義；F 的範圍、開口及 R41 面材層裁切決定可见整片與裁切片。
完整覆蓋指 F 中每處均被推導為面材或明定板縫，開口與障礙裁切區除外；
不能把帶縫誤寫成板材幾何本體在每一點連續覆蓋。
```

### D43 鋪排來源網格與縫引用

```text
鋪排來源網格引用一份 PanelFill；來源身分為 (layoutId, axis, signed k)，
交丁段另含另一軸的帶索引。顯示裁切不改來源身分，空段不刪除引用。
格線由 R42 的縫中心線推導；不得保存另一份可編輯的推導座標。
有效板縫是相鄰板片之間的正長度接縫段，外輪廓／孔邊不是兩板接縫。
無相位差的來源線仍可無限延伸；有效板縫段與供顯示的面內線段須分開表示。
既有 guide、grid 與角材引用此來源時仍沿原引用與影響預覽契約，不以畫面最近線重配。
```

### D44 承接門檻與結果

```text
每份試排明確引用一個 D31 dimension 欄位作為承接門檻 X，初始建立值為 8 mm。
建立時顯示欄位名稱及引用；不得在執行器藏一份可覆蓋引用的 8 mm 常數。
X 為正的有限精確尺寸；它只作比較，不生成幾何座標，保留 D31 有理數語意。
改名／排序不改引用，缺失／型別不符使結果未定，不以 8 mm 靜默補值。
承接結果依 R43 逐縫段判定，區分已承接、承接不足與無法判定。
承接不足顯示紅色及實際兩侧寬度，不阻擋合法試排的建立、修改或保存。
```

**此處建議選 D31，而非 D6b**：D31 以固定 id／field id 引用，可顯示名稱、明選共用或另建、保留精確尺寸，改名不改綁；D6b 亦能表達單一整數常數，但名稱即身分、整數限制不同。#128 明寫此機制尚未採納；這是唯一需要在兩個既有機制間選擇的事項。初始 8 mm、可調與不足不拒絕已決，不重問。

### D45 板縫貼板角材建議

```text
建議是未提交的候選操作集合，來源為明選試排的有效板縫、D44 門檻及明選角材規格／角色。
只涵蓋直接貼板一層、板縫下的 D7 角材，不含板中間支撐、主骨或吊筋。
不得預先建立正式 id、角材或 history。預覽列出每條建議及未能成立的條號。
確認建立後是一般 D7 角材，保存對縫來源／衍生承載面的引用；截面及角色明示，長度依 R6 求得。
不因來源是板縫就豁免 I19 端部角色、footprint 包含、碰撞或擋面唯一性。
```

## 4. 新增不變量全文

### I52 幾何、材料與来源完整性

```text
完成面所引邊界須滿足 D3／I2，框架須滿足 D1／D2；引用存在、型別正確、依賴無環。
面材 width／length／thickness 均須已明設且為正，實際空間輸出須為 D1 整數 mm。
小數厚度不得取整、缺厚度不得用名稱推測；該次層次求值拒絕，固定材料版本本身仍可保留。
縫寬非負，相位差依 D10b；零縫寬保持 D10a 原有合法性，不暗增最小施工縫。
容量不足時明確拒絕完整求值，不以部分板片／截短格線冒充完整鋪排。
```

### I53 分層與障礙

```text
面材層由完成面沿結構側至板背，貼板角材層由板背再沿同向延伸明選截面高。
兩層分別與 D41 的樑集合求交；有交集者在該層作邊界，無交集者不裁切该層。
不因另一層遇樑就兩層一起裁掉，也不提供逐樑手動豁免。
本提案依 Q47「高度範圍有交集」的字面，採閉區間相交：僅在端面接觸也算遇樑。
此端點解釋須隨條文審閱；不得以未說明的 epsilon 改成另一種接觸政策。
```

### I54 比對與建立不得混用門檻

```text
承接不足是比對結果，不是取消使用者設計的理由；紅色試排仍可保存。
非法幾何／未知來源不得偽裝成承接不足後放行。
若使用者確認建立建議角材，該角材須通過全部既有 D7／I／R 規則；
不得以「Q40 不拒絕」略過產品既有幾何拒絕。
```

### I55 引用與交易

```text
完成面、材料版本選用、試排、門檻或樑引用變更，均在候選 World 重新求值完整下游依賴。
凡移動已被角材引用的線、邊或世界框架者，先走 I8a 預覽；零違規並明確確認後才一次提交。
門檻變更只改比對結果而不改幾何時，不偽造角材移動；仍更新依賴的比對狀態。
未知或已失效的候選不能提交；取消、拒絕或失敗保留原 World、正式 metadata 與 history。
刪除被引用來源不得暗換成快照；須明確解除依賴或拒絕整筆操作。
```

### I56 保存與能力

```text
正式保存包括完成面、邊界／框架及障礙引用、試排設定、固定材料版本與必要參數的完整閉包。
不保存逐片裁切幾何、承接顏色或建議候選作為第二份真相；重開重新推導。
已確認 D7 角材依原格式保存其定義及位置引用，不因「只保存試排設定」而丟掉。
未知 panel-fill 能力、遺失或不合型別的引用拒絕，不降級成圖形或靜默丟附件。
新包拒絕時原專案不變；舊包沒有本能力時完全走舊 reader／求值路徑。
```

### I57 單一計算與共存

```text
鋪排與既有 PANEL_LAYOUT／D10b 共用同一組精確週期、縫中心與奇偶帶計算，
不得各自維護近似公式。有限主格、無限排法與完成面裁切只是不同的列舉／裁切範圍。
不自動將舊網格、手動 apply-proj、斷面構件或一般角材升級為 FinishSurface。
```

## 5. 新增推導全文

### R41 空間層次與樑邊界

```text
設完成面原點 O、結構側 n=s·N、板厚 t、明選 D7 放法的截面沿 n 高度 h；不從 A／B 名稱猜高度。
板背框架為 (O+t·n,U,s·V,n)，局部有效輪廓同步映射 (u,v)→(u,s·v)，仍保持右手系。
面材層為 {p+q·n | p∈F_world, 0≤q≤t}，
貼板角材層為 {p+q·n | p∈F_world, t≤q≤t+h}。
各層與已引用樑 AABB 求交，按 I53 端點政策，再把相交區投回該層局部輪廓作有效邊界。
水平完成面等價於比較各層 z 區間；垂直完成面沿其結構側計算，不能偷改成只比 z。
角材層的板背承載面及邊界是有來源的衍生視圖，不另存可獨立編輯的輪廓副本；
其位置、有效範圍及新生樑邊 fixity 可由來源完整重算，樑邊依既有投影規則為 FIXED。
多片或多跨距須逐片／逐段保留，不以 bbox 填補樑或孔；R6 多解仍須明示選段。
```

板背採衍生承載面是 #128 的建議而非原先已採納部分；此條把它寫成待審閱方案。實作須提供既有角材查詢的同一 typed surface 介面與來源閉包，不能另做一套放置／碰撞引擎。

### R42 板片、裁切與縫位

```text
對一軸，T=panel+gap；第 k 片本體區間 [a+kT,a+kT+panel)，縫中心 c(k)=a+kT+panel+floor(gap/2)。
奇數 gap 保留 D10a 的低座標側取下界；不能另用浮點半縫。
鋪滿以 signed k∈Z 列舉與完成面相交的板片，再扣孔及面材層障礙；非空分片保留完整輪廓。
長邊沿向決定兩軸板規格；交丁沿 D10b 的另一軸奇偶帶施加固定差，負索引亦依其 parity。
每片以 (layoutId,i,j) 作推導追溯鍵；裁切分片不是新正式物件，不以面積或 bbox 合併不同分片。
既有有限 D10a 仍只列 k≥0 且 a+(k+1)T<hi 的線，不改其 from／停止條件。
在相同起點與共同列舉範圍，板縫中心必與既有 PANEL_LAYOUT 逐條完全一致。
```

### R43 每側承接判定

```text
在每條有效接縫的每個非零長度子段，取直接貼板層合法角材 footprint 的聯集。
沿垂直該縫的方向，分別量板縫兩侧板邊進入此聯集的連續覆蓋寬度 d_left／d_right，
不把板縫空隙、孔、樑空段或另一高度角材算入承接。
兩側在整個子段均≥X 才標已承接；任一處不足即標出該不足段與兩側實值，不能用平均值通過。
寬度 X 以精確有理數比較，不四捨五入。邊緣只有單片時標「外緣非兩板縫」，不假造第二侧。
這只是幾何承接比對，不證明釘距、載重、跨距或固定強度。
```

全長而非平均、footprint 聯集及外緣分類是把 Q39 變成確定 oracle 的**新增精確化提案**，尚未聲稱使用者逐字採納。

### R44 來源網格重算

```text
依 PanelFill 定義求兩軸及交丁段的來源座標，再用完成面／衍生承載面框架作精確映射。
主格只引用該來源及必要的明確軸對應；依賴方向為完成面／材料／參數→試排→網格→角材，拒絕反向成環。
來源改變按原身分重算，引用消失或型別不合則拒絕並列出，不找最近線代替。
會移動既有角材的修改依 I55／I8a；不可只刷新畫面而留下舊 native 引用。
```

### R45 建議、預覽與建立

```text
使用者明選試排、貼板規格與合法角色後，僅沿有效板縫建立候選 at-line／grid 引用。
```
