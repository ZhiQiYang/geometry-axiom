# 畫布網格系統：條文差異與實作契約

> 2026-09-28 更正：本文件的有限排法版本沒有滿足使用者所指的無限網格。現行修訂與驗收以 `INFINITE-GRID-PROPOSAL.md`（GEO-215）為準；本文件保留上一版及舊檔相容語意。

## 操作範圍

在空白物件畫布建立、命名、編輯、移動及刪除獨立網格系統；定義與卡片位置可保存重開。由系統明確選擇已存在的承載面套用；同一定義可引用到兩面，每次有自己的局部原點。來源更改須預覽所有受影響的套用與後續依賴，確認才提交，支援整筆復原。

第一版沿用明寫、有限等差、面材加縫三種數值排法；不自動遷移既有面網格。網格系統本身的面材排法是明示數值，不另接材料／做法版本；既有面內工程來源功能保持。第一版兩軸對應承載面的同名軸，不提供旋轉或鏡射。卡片內是排法示意，不創造隱藏承載面、邊界或實際材料。

## 逐條差異

### D9：新增來源定義

```diff
+ 獨立網格系統（D29）與主格套用引用亦屬於定義；套用只保存來源 id 及局部原點，
+ 由來源求得的軸定義、座標與線段都是衍生快取，不另作來源保存。
```

### D10：主格增加明確來源

```diff
+ 主格可改以 D29 網格系統 id 與局部原點為來源；兩軸排法及 main_along 從系統取得。
+ 此時仍屬於一個承載面，適用本條、D10a、I10、I23；不能另存直接排法或工程尺寸綁定。
+ 既有直接定義的網格維持原義；不得把畫布新建網格系統解讀為自動轉換既有網格。
```

### D12：新增可獨立擺放的類別

```diff
- **D12 畫布座標（CanvasPos)**：(類別, id) → (x, y)，類別 ∈ boundary / placement / space / column / beam。
+ **D12 畫布座標（CanvasPos)**：(類別, id) → (x, y)，類別 ∈ boundary / placement / space / column / beam / grid-system。
```

### 新增 D29

```diff
+ **D29 獨立網格系統（GridSystem)**：World 層獨立物件，保存 id、名稱、兩軸排法與可選 main_along；
+ 不依附承載面，不包含邊界或材料。名稱為非空 UTF-8（至多 96 bytes），名稱不是身分，可重名。
+ 兩軸各為未定義、EXPLICIT、SERIES 或 PANEL_LAYOUT；至少一軸有定義。
+ EXPLICIT 保存嚴格遞增的整數座標；SERIES 保存 start、正 step、正 count；
+ PANEL_LAYOUT 保存正 panel、非負 gap 及明示的相對起算點 anchor，全部按 D1。
+ 第一版上述欄位為直接數值；不接受工程來源、任意算式、旋轉、鏡射或巢狀網格系統。
+ 系統在沒有套用時已是合法可保存物件；PANEL_LAYOUT 在未指定範圍時只有排法、沒有實際條數。
+ 卡片僅顯示排法示意，不把示意視窗存作幾何範圍；卡片移動不改局部座標或套用。
+ 主格套用保存自己的 grid id、承載面 id、系統 id 與兩軸整數原點；系統 u/v 對應承載面的 u/v。
+ EXPLICIT 座標、SERIES start、PANEL_LAYOUT anchor 各加該軸原點；step、count、panel、gap 保持。
+ 套用的面材 anchor 因此具體決定，不隨面邊改變；明改系統 anchor 或套用原點才重新求值。
+ 同一系統可供多個主格引用；每次套用保留自己的身分與原點，系統不擁有角材。
```

### I10：現有限制的適用範圍

```diff
+ 本條承載面、範圍及主格／子格數量要求適用套用後的 ReferenceGrid；獨立網格系統另依 I37。
+ 從系統套用的 EXPLICIT／SERIES 仍須全部落在範圍內，不能裁掉超界座標以改變既有索引。
```

### 新增 I37

```diff
+ I37 網格系統：系統 id 使用獨立 uint32 空間（含 0），最多 16 份；每軸有限座標／條數上限為 64。
+ 拒絕缺名稱、無效 UTF-8、超長名稱、兩軸皆空、非遞增、非法數值、運算溢位或越過 D1 範圍。
+ main_along 可未設定，否則依 I10 要求具有對應格線來源；不猜主支方向。
+ 套用須引用已存在的系統與承載面，並遵守每面最多一個主格及全部現有幾何／依賴限制。
+ 系統、套用新增與修改均在候選世界驗證；來源修改重算所有套用、子格、guide 與角材。
+ 任一依賴不合法則整笔回滾；圖形介面先顯示 I8a 影響預覽、確認同一候選後提交。
+ 已被主格引用的系統不得刪除；不級聯刪掉套用。刪除主格仍須通過其既有依賴檢查。
+ 系統來源的主格不得用普通 grid 軸或 main-along 宣告、工程來源綁定覆蓋；明確 from-system 宣告可變更套用來源或原點。
+ 仍有工程尺寸綁定的既有主格不得轉成系統來源；必須先明確解除原綁定，不得隱含清除來源或覆寫。
```

### 新增 R32

```diff
+ R32 網格系統求值與保存：先讀系統定義，依各套用原點形成軸定義，再依 D10／D10a 求座標與可見線段，
+ 然後求子格、guide 與角材；可見段仍依真實輪廓扣孔，不以卡片示意代替。
+ dump／場景／專案保存先輸出系統再輸出套用，包含未使用的系統、名稱與 canvas-pos；不輸出衍生軸快取。
+ 重開恢复相同身分、來源、原點及推導結果；失敗保留當前世界；undo／redo 整筆還原。
+ DSL：grid-system <id> name-hex <UTF-8十六進位> main-along u|v|none u <排法或none> v <排法或none>。
+ 排法沿用 grid 的 explicit／series／panel 語法；系統 PANEL_LAYOUT 必須明寫 from <相對anchor>。
+ 每次系統宣告包含完整兩軸與名稱；不把省略欄位解讀為保留或隱含預設。
+ 套用：grid <id> on <承載面> from-system <系統id> origin <u> <v>。
+ 刪除：delete grid-system <id>；展示：canvas-pos grid-system <id> <x> <y>。
+ 名稱編碼只供無歧義協定與保存，介面顯示原始名稱；不得把控制字元注入後續 DSL。
```

## 驗收

G01 空世界建立、編輯三種排法，不暗建面；中文含空白名稱、兩軸及可選角色可重開。
G02 卡片列舉、選取、框選、移動、刪除、篩選與桌機／390px 入口可操作。
G03 同一來源套兩面，來源引用及不同原點保持；矩形與 L 形／孔輪廓依核心裁切。
G04 來源修改列兩份套用的新舊格線，確認原子更新；取消、過期預覽與失敗回滾不改世界。
G05 不可刪被引用來源；普通軸編輯與工程綁定不能覆蓋系統來源。
G06 保存後清空再正式重開，來源、位置、名稱、原點及幾何保持；復原／重做完整恢復。
G07 舊場景及既有面內網格不變，核心與完整 cdp_test 回歸、正典三道驗證通過；執行證據另記。
